# 化学系课程资料整理（进行中）

本目录是独立的化学系研究包，等待后续整合；不修改网站数据或其他分支。数据获取日期为 2026-10-27。

## 范围与官方资料

- 化学系 2025 秋、2026 春开课教学班：分别 226、351 个，共 577 个班、145 个不同课程代码；以开课院系为准，部分课程涉及其他专业或研究生层次。
- `化学系2026培养方案_14专业及公共.zip` 收录官方查询列出的 14 份化学系专业方案与公共方案，含官方原始 JSON、离线可读 HTML 和本地图像。完整培养方案应将公共方案与所选专业方案一起阅读。ZIP 中 HTML 为根据官方数据生成的阅读版本，并非官方 PDF。
- `official_evidence.json` 按课程整理教学班、教师、学分、人数快照、方案课程关联及大纲正文。当前教务索引未提供各班人数上限，不能用人数快照直接计算选课偏好。440 个班次返回非空大纲，136 个班次接口报错，1 个班次返回空正文；有正文的覆盖 141 个课程代码。不存在的大纲和接口错误不代表没有学生评价。
- `alias_registry.json` 记录课程和教师全名、别名、拼音及首字母；重名和歧义仅供检索候选，须核对课程、老师、学期及上下文。
- `programs_manifest.json`、`official_evidence_audit.json`、`scope_audit.json` 保留来源定位及核验结果。原始官方接口路径以 `programs` 目录为基准，ZIP 内容根目录是 `raw`、`images` 和 `printable`。

## 离线预览

打开 `化学系课程研究预览.html` 可按课程代码、名称、教师和拼音首字母查看当前证据，并按培养方案（公共方案与所选专业方案合并）、教务课程类型及代码前缀筛选。预览由 `generate_preview.py` 从本目录数据生成；当前收录一批已核读、可以定位的知乎、小红书和蛋壳评价摘要；旧代码和历史教师须按记录单独看待，课评尚在补充。

当前阶段的六群查询概况见 `chat_search_manifest.json`：使用登记的课程、教师及其别名检索 105,771 条可读文本，对 1,393 条命中消息进行相邻上下文核对，没有确认化学课的修读评价；这不是对每条原始消息的人工通读。群聊原文与成员身份不进入共享目录。

物理化学II历史课件另有个人离线包：本机保存在 `D:/danxi/课程评价整理_20261023/补充核验/化学系_20261027/offline_resources/物理化学II历史课件_个人离线.zip`；35份PDF及校验信息见 `offline_materials_manifest.json`。源页注明教学用途、不得商业使用，离线PDF不随仓库重传。

树洞与蛋壳摘要位于 `danke_review_summaries.json`、`forum_discussion_summaries.json`；`course_syntheses.json` 记录学生评价判断所依据的来源 ID，以及仅基于对应教学班大纲的说明，`course_resources.json` 存储已核对的课程资料链接。树洞课评中的问课、未经确认的选课建议与修读体验分开标注。

树洞高频截断后的分时段进度快照见 `forum_split_coverage.json`，课程未确认的讨论线索见 `forum_unmapped_leads.json`。

公开平台逐课状态见 `public_web_coverage.json`，公众号相关官方转载与搜索边界分别见 `wechat_public_sources.json`、`wechat_public_coverage.json` 和 `wechat_search_manifest.json`。课程族信息或教师姓名不一致的来源须继续核对，不能自动套用现授班。

## 课评检索与待完成工作

课评检索尚未完成，不能把当前清单当作完整课评库。持续核对旦夕蛋壳课评、树洞讨论（包括模糊搜索）、知乎、小红书、微信公众号、六个群聊和可用课程资料。按课程代码、课程全名与别名、教师全名与拼音查询；课程历史代码、平行班、旧教师和当前教学班分别标注。遇到搜索结果达到分页上限应续查或细分时间段，阅读原帖和上下文后再归课。

原始群聊、账号、令牌和个人身份信息不放入此目录；群聊只整理必要的匿名概述。公开平台内容以注明来源的简短概述及可用链接为主。树洞和蛋壳内容也须核对原文权限、隐私和完整性。课程没有找到学生评价时，应在完成检索及核读后标记，而不是用大纲替代学生评价。

后续整合时应为每门课按大纲、资料、学生评价、比较总结四部分组织，并标明实际来源、教师、学期及资料缺项。课程与教师的对比必须有可核对的对应证据。
