## 急诊医学（MED50014）
- 学分 2 ｜ 总学时 32 ｜ 2025-2026学年2学期 ｜ 负责人 练士贤 ｜ 主讲 司炎辉,刘保池,练士贤,黄仁政,申捷,张勇,沈银忠,童汉兴,赵锋,李文伟,樊贞瑜,唐俊,张璐 ｜ 大纲版本 2025
- 原文：`附属公共卫生临床中心/2025202602-MED50014.01-急诊医学.doc`

**课程简介**：本课程聚焦急危重症的快速识别、紧急救治与多学科协作，涵盖心肺脑复苏、创伤急救、中毒处理、常见急症（心脑血管意外、严重感染等）诊疗核心内容。通过理论授课、病例研讨结合的方式，培养学员快速评估病情、制定急救方案的能力，掌握急诊流程规范与关键技术。课程兼顾医学专业学生与临床医护人员，强调“时间就是生命”的急救理念，助力提升急危重症救治成功率，适配临床急诊岗位实战需求。 /

**教学内容及进度（节选）**：（按照教学周编排，应包含每节课教学内容及教学目标，如有作业及考核要求，请一并列明） / 第一周 急诊医学概论：2课时（90分钟） / 1、掌握：急诊医学的学科范畴是贯穿院前急救，院内急诊，危重病监护过程中的心肺复苏，现场急救，创伤急救，急性中毒，急危重病，儿科急诊，灾害救援的理论和技能。 / 2、熟悉：急诊医疗服务体系的组成和急诊医学专业特点。 / 3、了解：我国急诊医学的发展阶段和急诊医学的专业特点。 / 第二周 创伤急救：2课时（90分钟） / 1、掌握：创伤的基本生命支持包括通气，止血，包扎，固定和转运。多发伤的定义，特点和救治原则。 / 2、熟悉：损伤控制理论，复合伤的临床特点及救治原则。 / 3、了解：创伤急救网络体系。批量伤员分拣方法。挤压伤的临床特征及处理原则。 / 第三周 急性出血：2课时（90分钟) / 1、掌握：咯血和呕血的常见病因和鉴别诊断,治疗原则。 / 2、熟悉：咯血的临床特点,消化道出血的临床特点.失血量评估和急诊处理方法。 / 3、了解：消化道出血的常见原因,鉴别诊断,救治要点。 / 第四周 休克：2课时（90分钟） / 1、掌握：休克的诊断标准和鉴别诊断。 / 2、熟悉：休克的临床分期和临床分级。休克急诊救治流程。 / 3、了解：各类休克的特点和急救处理方法。 / 第五周 急性中毒（总论）：2课时（90分钟） / 1、掌握：中毒的临床特点，诊断与鉴别诊断，中毒急救处理原则，包括如何清除毒物，应用特效解毒药物和对症治疗。 / 2、了解：毒物的吸收，代谢及排泄，实验室检查。各种毒物引起中毒的发病机制。 / 第六周 急性中毒 （农药，工业毒物）：2课时（90分钟） / 1、熟悉：有机磷中毒，灭鼠剂中度，百草枯中毒镇静催眠药中毒，急性酒精中毒的特点和临床表现。 / 第七周 灾害急救：2课时（90分钟） / 1、掌握：灾害的定义，灾害急救特点和流程。 / 2、熟悉：自然灾害与人为灾害分类。突发公共卫生事件的定义，特点和分类。 / 3、了解：灾害的急救流程。地震灾害，洪水淹溺，交通事故，矿难灾难的急救原则。 / 第八周 急性发热：2课时（90分钟） …
