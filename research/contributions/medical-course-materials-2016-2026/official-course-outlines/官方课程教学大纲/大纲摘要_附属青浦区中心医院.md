## 外科微创学（MED50026）
- 学分 2 ｜ 总学时 32 ｜ 2026-2027学年1学期 ｜ 负责人 严斌 ｜ 主讲 范隆华,崔恒官,严斌,陈浩,李慧峰,陈斌,郭宝磊,陈海林,傅阳,刘祥璐,彭翔,周海洲,刘新育,沈育锋,张胜超,朱宝成,朱慧芳 ｜ 大纲版本 2025
- 原文：`附属青浦区中心医院/2026202701-MED50026.01-外科微创学.doc`

**课程简介**：本课程总论部分详细介绍了微创外科观念的形成，以及现代微创外科的发展，微创外科技术如腹腔镜、胃肠镜、输尿管镜、胸腔镜、关节镜、介入等技术的特点及其应用，同时结合各专业的解剖特点，详细介绍了临床各专业普通外科、神经外科、泌尿外科、骨科、胸外科、血管介入微创外科、机器人外科、麻醉科等专业微创知识，通过微创学的历史、现状与演变，培养学生救死扶伤的医学人文理念和发展创新的科研理念，在我国微创外科的发展成果中培养自强自信、求实创新的精神；最后结合腹腔镜模拟实训室，掌握常用腹腔镜基本技能，加强学生的动手实践的能力 /

**教学内容及进度（节选）**：（按照教学周编排，应包含每节课教学内容及教学目标，如有作业及考核要求，请一并列明） / 第1，2学时：外科微创学总论 （2学时） / 了解外科微创学的概念和发展史：外科微创观念的形成，以及现代外科微创的发展，外科微创技术如腹腔镜、胃镜、肠镜、介入技术等； / 熟悉外科微创学的优缺点； / 外科微创学在治疗及诊断上的应用：血管介入治疗技术、主动脉瘤的介入治疗、主动脉夹层动脉瘤的介入治疗、颈动脉狭窄的介入治疗、动脉硬化闭塞性疾病的介入治疗、原发性下肢静脉曲张的介入治疗。 / 第3，4学时：外科微创学及腔镜基础（2学时） / 了解外科微创学的发展史，了解微创外科与传统手术外科的异同，了解微创外科的培训过程，了解外科微创学各专科常见的手术体位； / 熟悉外科微创学的发展过程和应用范围，熟悉腔镜的基本技术及操作步骤，熟悉不同的通道建立方法； / 掌握外科微创学的概念，掌握腹腔镜系统的组成和常见的操作器械，掌握腔镜的基本原理和特点。 / 第5，6学时：普外科微创学 （2学时） / 了解3D腹腔镜、N.O.T.E.S手术、达芬奇机器人、远程机器人微创手术的发展，了解常见的普外科微创手术体位及手术要点； / 熟悉外科微创学在普外科临床中的应用范围，熟悉常见的普外科微创术式，熟悉手助腔镜外科的应用； / 掌握普外科微创学发展的趋势，掌握常见的普外科微创学的手术适应症（肝胆胰脾、胃肠外科）及优势，掌握微创减重外科、疝外科手术的分类。 / 第7，8学时：胸外科微创学 （2学时） / 了解外科微创理念在胸心外科领域的具体应用和实践； / 熟悉胸外科微创发展史，理解医学实践与科技进步的辩证关系； / 掌握胸腔镜外科和机器人胸外科技术的基本原则。 / 第9，10学时：泌尿外科微创学（2学时） / 了解泌尿外科腔镜技术发展史； / 熟悉开展泌尿外科微创手术的常用设备、路径，重点熟悉经皮肾镜、输尿管镜碎石术和泌尿外科腹腔镜技术； / 掌握泌尿外科微创手术原则。 / 第11、12学时：微创内镜学 （2学时） / 了解胃镜技术；结肠镜技术；胆道镜技术；十二指肠镜技术；内镜技术的发展，胶囊内镜技术；小肠镜技…
