# 复旦医科课程资料（2016–2026）

本目录整理公开来源课程介绍和带来源标记的课程讨论摘要，供 PR 人工复核。它没有写入网站课程目录，也没有把未经复核的材料标为已核实评价。

## 本次纳入

- `course-overviews/`：两份基于学校/院系公开页面整理的课程介绍与课程安排说明，保留来源链接。
- `course-reviews/`：五份课程讨论整理件。外部网页保留来源链接与短摘；树洞/旦克部分保留匿名平台编号、日期等可追溯标记，不附平台原始响应或整帖全文。
- `SHA256SUMS.txt`：校验本目录提交的说明和整理件。

## 培养方案原件

用户本地资料包列出 2016–2026 年医科培养方案 228 份（每份均在其培养方案清单中找到）。由于本 PR 尚未确认这些 Word 原件的公开再发布许可，**原件没有提交到 GitHub**。课程方案目录和当前可用版本请从[复旦教务处官方培养方案目录](https://jwc.fudan.edu.cn/bkjxpyfa/list.htm)打开；本仓库 `public/data/faculty-resources.json` 也保留医科对应的官方来源卡片。方案适用年级、专业方向和招生类别不同，使用前应按官方原站核对。

## 去重与复核

- 这批培养方案文件按 SHA-256 检查没有完全相同的文件；与当前 PR 已跟踪文件也没有同哈希文件。由于原件未公开提交，不发布逐文件哈希清单。
- 五份课程讨论整理件之间没有检测到重复的短引文；跨文件重复出现的官方/MOOC URL 是各自语境的来源引用，保留在对应段落。
- PR 中原有工医开课班次表保持不变；该表已按“规范学期＋选课序号”合并工医交叉重复班次，并排除与现有网站班次重复的记录。培养方案文件是历史及专业方案，不与开课班次表混并。
- 本目录的课程讨论仍是未由维护者独立复核的个人陈述；来源标记只用于追溯，不代表样本有代表性，也不等同于平台许可或开放版权。请在合并到网站或生成总体结论前复核课程归属、学期、班型、上下文和重复经历。
