# 复旦医科课程资料（2016–2026）

本目录包含医科培养方案、官方课程教学大纲、公开来源课程介绍和带来源标记的课程讨论整理件，供学校课题和本 PR 复核。资料未写入网站课程目录；课程评价仍需维护者复核。

## 官方资料

- `official-programs/fudan-medical-programs-2016-2026.zip`：2016–2026 年 228 份培养方案 DOCX 和原目录 `培养方案清单.csv`。
- `official-course-outlines/官方课程教学大纲/`：741 份从教务系统“全校开课查询”导出的审核通过版《复旦大学课程教学大纲（2025版）》DOC 文件，按开课院系保存；包含来源目录中的 `_index.json`、741 行 `大纲索引.csv` 和 28 份院系摘要。
- `program-file-manifest.csv` 位于培养方案 ZIP 旁边，列出每份 DOCX 的相对路径、大小与 SHA-256；`outline-file-manifest.csv` 列出 741 份大纲 DOC 的相同信息。
- `SHA256SUMS.txt` 校验本目录所有交付文件（不含该校验文件本身）。

按提交者说明，复旦教务处已批准这些官方课程材料用于该校课题及本次公开发布。原件仍由学校/原作者保有相应权利；本包不声称这些资料采用开放许可证。培养方案可从[教务处官方培养方案目录](https://jwc.fudan.edu.cn/bkjxpyfa/list.htm)核对，适用年级、专业方向和招生类别以官方原站为准。

## 整理资料

- `course-overviews/`：两份基于学校/院系公开页面整理的课程介绍与课程安排说明，保留来源链接。
- `course-reviews/`：五份课程讨论整理件。外部网页保留来源链接与短摘；树洞/旦克部分保留匿名平台编号、日期等可追溯标记，不附平台原始响应或整帖全文。
- 课程讨论是个人经历与观点，不代表有代表性的样本或已核实评分；并未合并到网站课程目录或评分数据。

## 去重与验证

- 228 份培养方案 DOCX 及 741 份大纲 DOC 均按 SHA-256 检查；在各自材料组内没有完全相同的重复文件，与该 PR 原有跟踪文件也没有同哈希文件。
- 培养方案清单 228 行且每份 DOCX 均在清单中；大纲索引对应 741 份 DOC；清理一条导出路径中的不可见控制字符，并同步修正清单与索引路径。
- 五份课程讨论整理件没有跨文件重复短引文；重复出现的官方/MOOC URL 是各段独立引用，予以保留。
- PR 中原有工医开课班次表保持不变；它已按“规范学期＋选课序号”合并工医交叉重复班次，并排除与现有网站班次重复的记录。培养方案与大纲不和开课班次表混并。

输入目录中的 3 份树洞/旦克平台原始检索 JSON 未放入 Git 历史：它们包含第三方平台响应内容。教务处对校方课程文件的授权不代表平台原始学生内容的转载许可；原始 JSON 留在用户本地归档。
