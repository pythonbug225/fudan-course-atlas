# 医科课程评价平台来源快照

根据项目提交者确认，树洞与旦克平台管理员允许将相关课程评价用于本课题公开，并要求标明来源。数据来自 `05_平台原始检索记录/树洞旦克/` 中的三份检索记录；原始文件名、文件大小、SHA-256、采集时间与涵盖区段见 `source-manifest.json`。

## 文件

- `treehole-reviews.jsonl`：13296 条唯一树洞楼层记录，按 `hole_id` 与 `floor_id` 合并重复检索命中。
- `danke-reviews.jsonl`：99 条旦克课程评价记录，保留课程、教学班、评价 ID 和时间字段。
- `danke-courses.jsonl`：66 条旦克课程检索条目与教学班信息，汇总命中来源。
- `source-manifest.json`：输入快照校验值、记录数、来源区段及脱敏说明。

每条评价都保留平台名称、来源 ID、原始时间以及输入文件、检索区段和检索词路径。输入数据没有稳定的公开帖子 URL，因此不构造链接；树洞记录以 `hole_id`/`floor_id` 溯源，旦克记录以课程/教学班 ID 和评价 ID 溯源。

## 隐私与去重

保留所有唯一评价正文。删除抓取账号和回复者账号标识，并遮盖检测到的手机号、邮箱与 18 位身份证号。树洞重复命中共合并 6048 条，重复来源保存在 `source_captures` 与 `observations`；同一楼层 ID 未发现正文冲突。旦克评价按课程、教学班与评价 ID 去重。

这些内容是学生个人经历和观点，不代表具有代表性的调查结论或已核实的成绩数据。
