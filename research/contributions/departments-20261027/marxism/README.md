# 马克思主义学院课程名称查询单

[课程名称查询单.json](课程名称查询单.json)是仅含课程名称的JSON字符串数组，供后续检索使用。目前有148个去重名称：

- 2025秋和2026春马克思主义学院开设教学班的课程，共137个不同名称，来源为[两学期全部教学班](summaries/两学期全部教学班.json)。
- 2026级望道班及马理论—人工智能双学士培养方案中，开课院系明确标为马克思主义学院的课程，额外补入11个名称，来源为[培养方案课程索引](final-report-20261028/官方培养方案/培养方案课程索引.json)。

名称保留官方原文，去除首尾空白后按完整名称去重。同名不同课号只保留一个名称；需要区分课程身份、学期或班型时，请查阅上述源数据。此清单覆盖上述两学期和已取得的2026级方案，不代表马院历年开设课程的完整目录。培养方案中的课程不一定在上述两个学期开设。
