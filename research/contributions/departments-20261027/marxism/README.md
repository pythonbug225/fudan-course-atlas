# 马院课程名单

[马院课程名单.json](马院课程名单.json)是仅含课程名称的JSON字符串数组，供后续检索使用。目前有148个去重名称：

- 2025秋和2026春马克思主义学院开设教学班的课程，共137个不同名称，来源为[两学期全部教学班](summaries/两学期全部教学班.json)。
- 2026级望道班及马理论—人工智能双学士培养方案中，开课院系明确标为马克思主义学院的课程，额外补入11个名称，来源为[培养方案课程索引](final-report-20261028/官方培养方案/培养方案课程索引.json)。

名称保留官方原文，去除首尾空白后按完整名称去重。同名不同课号只保留一个名称；需要区分课程身份、学期或班型时，请查阅上述源数据。此清单覆盖上述两学期和已取得的2026级方案，不代表马院历年开设课程的完整目录。培养方案中的课程不一定在上述两个学期开设。

[课程完整研究报告](final-report-20261028/README.md)

## 原始数据

- [官方教学大纲页面及逐班查询响应](raw-official/syllabi-20261027/README.md)：407份大纲页面和465份查询响应，附来源及文件校验清单。
- [2025秋、2026春课表和2026级培养方案目录原始接口响应](raw-official/)；[2026级培养方案 Word 原件及接口数据](official/)。
- [树洞和课评区采集快照](final-report-20261028/原始证据发布版/)：685份实时查询、7份历史课评与关联数据，逐文件校验信息见其中的 manifest.json。
- [公开平台检索台账](final-report-20261028/公开平台检索台账.json)和[已核读来源](final-report-20261028/外部平台已读来源.json)记录外部平台的检索与来源；并非平台全部内容的原始快照。

接口响应和大纲页面以 gzip 压缩保存，公开版本对个人联系方式、账号和访问凭据等做了必要脱敏，因而不保证与采集文件逐字节一致。课评采集和公开平台检索均存在报告中列明的覆盖边界。
