# 马克思主义学院官方教学大纲原始快照

本目录保存2026年10月27日采集的2025秋和2026春马院教学班官方教务系统响应：465份 `.check.json.gz` 为逐班大纲可用性查询结果，407份 `.html.gz` 为当时成功读取的大纲页面。文件名前的数字是教学班 ID；未出现 HTML 的班级可查阅对应查询结果及[大纲读取台账](../../final-report-20261028/官方培养方案/大纲读取台账.csv)。

解压 gzip 后可读取 JSON 或 HTML。为避免公开联系方式和访问凭据，页面经过文本脱敏，236份页面发生了处理，文件不是逐字节原件；查询结果仍保留查询时的状态。`manifest.json` 分别记录采集文件、脱敏后内容和 gzip 文件的 SHA-256，供核对来源及发布内容。大纲页面是采集时的快照，不代表未来教学安排。

课表响应、培养方案原件和课评快照的入口见[马院目录](../../README.md)。
