## 四种关系

| 类型 | 方向 | 含义 |
|---|---|---|
| 方案配图联系 | 有向 | 2026官方课程体系图中的清晰课程箭头；保留方案和配图位置，不称为选课先修。 |
| 建议知识准备 | 有向 | 根据题名和学科训练逻辑给出的学习准备；逐条写出技能联系，尚无逐班大纲证明。 |
| 内容联系 | 无向 | 课程主题、方法、材料或实践场景存在联系；未认定内容完全重合。 |
| 同名异号 | 无向 | 标出名字相同而课号不同的课程，便于核查；不表示课程替代或学分互认。 |

目前在27份保存的官方培养方案中未找到具名的“必须先修”条款，也未取得逐班教学大纲。因此**图谱没有已确认的强制先修边**；这不等于学校、专业或具体教学班没有先修要求。四张体系图已直接核读；其中15条明确课程箭头录入。其他配图和实践活动没有被冒充为已经完整结构化。

## 怎样使用

先在课程列表中选课，看左侧入边、右侧出边和下方相关课程。点击任意关系可看理由、证据位置和方案适用范围。方向图展示同一主题的课程；“总览”用于切换主题，避免把285门课挤成不可读的连线。方案新增78课默认隐藏，可开启“含2026方案列课”查看。

本科与研究生分层显示；同名课程保留独立代码。方案列课节点不声称已在2025秋或2026春开课，也不按JCM/MJC或数字大小推断层次。培养方案中的学期和难度等级没有被转换为强制先修关系。
