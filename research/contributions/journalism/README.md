# 新闻学院：2026级方案与2025秋—2026春课程研究

本分支集中保存研究报告、课程查询名单、官方原件、实际读取的原始课评正文与检索台账。统计截至2026-10-29的已保存材料，打包日期2026-10-30；不是新一轮检索。

## 报告与查询名单

- [新闻学院课程名单.txt](新闻学院课程名单.txt)：203个去重名称，每行一个课名，没有教师、课号或评价字段。
- [完整离线研究报告 ZIP](reports/新闻学院完整研究报告.zip)：下载并解压后打开“新闻学院课程研究/研究报告.html”，包括全部依赖文件、27份培养方案Word和后续补充页。
- [研究报告HTML源文件](reports/研究报告.html)、[续查补充HTML](reports/续查补充.html)：GitHub不直接运行HTML；完整离线链接请使用上面的ZIP。
- [官方352班课程目录JSON](official/course_catalog.json)、[CSV](official/course_catalog.csv)：207个课号，122位教师，课程全名去重203个；本科、研究生、本研融通均包含。

## 原始数据

- [61条旦挞原评](raw/danke-reviews.jsonl)：原始标题、正文、评分、创建/更新时间及原课程字段。原平台期别保持原值，不把正文自述学期写回源字段。
- [309个课程组保存响应](raw/danke-course-groups.jsonl)：保留course_list和review_list；无评价课程组也保留。原抓取阶段的fetched_unread字段是当时状态，后续全文核读状态另列。
- [781条树洞原始楼层及上下文](raw/forum-read-and-cited-floors.jsonl)：按楼层ID去重，766条公开脱敏正文，15条因删除、限制声明或私人信息等原因仅留元数据。阅读数量包含提问及排除用上下文，不等于独立学生或课评样本量。
- [官方原始材料ZIP](official/official-originals.zip)：27份原始培养方案JSON、27份Word、两学期原始开课接口及方案列表；内附成员SHA-256。原件与结构化课程目录分别保存。
- [查询结果ID与分页台账ZIP](ledgers/search-result-index.zip)：原查询、时间、页数、停止状态及返回楼层ID；未把机器命中写作已读。无关及未核读结果池正文没有整池公开。
- [摘要、检索变体和研究数据ZIP](derived/research-data-and-summaries.zip)：派生数据；其摘要字段不是上面raw文件的替代品。
- [原始数据范围及脱敏记录](raw/raw-manifest.json)、[文件哈希清单](file-manifest.json)。

树洞三阶段分别整理21、20、19组课程讨论；同一洞、同一作者或同一楼层可涉及多门课，不能相加当独立样本。最后一批额外核读120个单楼，并不代表读完其整洞。宽泛查询仍有未翻完项，外部平台覆盖仍有限。历史教师、班型、学期与2025秋／2026春目标班次分别看。
