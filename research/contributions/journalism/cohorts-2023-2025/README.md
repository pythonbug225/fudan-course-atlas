## 怎样理解先修关系

- **官方明确先修**：只有原文明确要求先修某课程才采用该类型，并保留原文位置。没有此类边表示本批材料未证实，不表示学校没有要求。
- **官方方案图联系**：只编码已直接核读的清晰箭头；含义限于对应培养方案图，不转换为选课资格。
- **建议先学**：根据该年级准确课程名称与一般学科训练逻辑整理的知识准备顺序，属于推断。
- **内容联系**：课程主题、方法或实践场景相邻；不是逐班大纲比对，也不证明内容完全相同。
- **同名异号**：保留不同课号，不自动合并，不表示学分替代。

每条边的 `program_ids` 限定适用方案；检索某方案时不会展示其他方案独有的边。不同方案的官方图可能出现相反方向，例如2025广告学普通本科与战略传播本硕方案中的“智能创意与表现／营销传播策划”；请先选具体方案阅读，不把全年级混合视图当成先修排序。同课号不同名称分成独立节点。课程表中春/秋等字段不被当成年级顺序。

## 下载与可追溯性

每年 `official/` 保存官方目录响应、逐方案 JSON、官方 Word、提取文字和嵌图。原始 JSON 以 `.json.gz` 无损压缩，解压后的字节与下载时的 `raw_sha256` 校验值一致。`course-graph/` 提供完整列课索引和每条关系依据。全部文件可离线读取；课程名单仅列新闻学院开课或 JCM/MJC 专业课程名称，完整的公共和跨学科列课在节点数据中。

来源：[复旦教务培养方案查询](https://fdjwgl.fudan.edu.cn/manager/bizType/2/page-center/major-program-search-view?skipAuth=1)。每份方案的来源地址和下载校验记录见 `official/programmes.json`、`official/coverage.json`。原件版权及使用范围仍归各自官方来源。

## 复现

在下载的本目录运行：

```text
python scripts/build_cohorts.py
python scripts/validate_cohorts.py
```

构建读取已保存原件与 `relations/` 中的逐年人工关系。`scripts/fetch_official.py` 用于重新获取公开官方快照；重新抓取后需重新核读关系，不能直接沿用旧审计。
