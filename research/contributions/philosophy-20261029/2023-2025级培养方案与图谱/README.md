## 数据与关系口径

图谱节点以入学年级和原表课号为准，涵盖方案列出的跨院系课程。模块和课程之间的连接来自培养方案。正式先修需要大纲或官方规则明确写出，年级修读顺序和替代条款按出处标注。2023 级另有两条要求修过一门数理逻辑课程的记录，以“官方先修领域”显示。多门先修的组合方式按原文记录。

建议先学和内容联系沿用已有哲学系图谱的知识主题。两端课名须匹配且同属至少一份当前年级方案。普通课、荣誉课和同名异码课保留独立节点。数字代表已整理的关系记录，同一对课程可适用多个方案或大纲版本。

使用 Python 标准库运行 `python build_cohort_graph.py` 可以从已归档资料重建图谱。
