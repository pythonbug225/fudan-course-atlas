# 小红书公开站点索引检索记录

依据 `official/course_catalog.json`：全目录有87条开课记录；剔除毕业论文、学年论文这2个非课堂课程记录，按剩余85条逐条检索。课程名称、课程代码、教师和学期均直接抄自该官方目录，不自行补写别名。

## 实际检索方式与结果

- 生成85条目标记录的精确课程名查询；同一门课跨学期重复、且课程名和教师完全相同的记录复用同一次查询，因此实际发出81条唯一查询，分21批（20批各4条，最后1条）。重复的记录仍各自保留在 `public_index_search.csv`，关联学期、课程代码和批次。
- 实际查询式统一为：`site:xiaohongshu.com 复旦 "课程官方全名" "教师全名"`。多位教师时把目录中的每位姓名都放入查询。
- 81条唯一查询的21个搜索批次均返回工具提示 `Empty search results / No results were found for the provided queries`。因此85条目录记录状态均记为 `zero_hits`；没有发现可读帖子候选，没有打开帖子，也没有生成帖子摘要。
- 先前对12个代表性课程/教师组合的公开搜索有少量复旦官方教师资料/校方专题和小红书企业营销页面结果，但未发现目标课程评价笔记；这些初探词列于下方。它们与本轮85条目录全名检索分开。
