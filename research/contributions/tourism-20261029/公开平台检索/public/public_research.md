# 公开平台检索：复旦旅游学系 2025秋 / 2026春

## 结果

公开 web 检索未找到可核实的知乎或微信公众号课堂体验材料，不能据此断言平台上没有内容或已穷尽全网。

- 按官方课程表逐一检索了 **83 组课程名 + 任课教师**。每次只检查一页搜索响应，最多记录前 4 条链接，共捕获 326 条链接；其中没有知乎、公众号或搜狗微信文章 URL。
- 另做 **8 个知乎/公众号域名定向探针**，搜索接口均返回空结果。
- 按上下文观察到的简称及若干拼音变体做 **7 个别名查询**，捕获 28 条链接；未命中可核实的课堂体验文章。
- 对课程表中 **27 位教师**做中文姓名 + 拼音查询，捕获 54 条前两名结果；多为师资主页、论文和其他同名结果。
- 早期探索词见 JSON 日志。它们在多 query 批次中返回混合结果，无法按单个词可靠拆分计数，所以没有混入上述计数。

JSON 日志保存了每个结构化 query、响应返回数、记录的标题与 URL、分页终止原因和别名拼音词。

## 具体边界

本轮使用公开 web 搜索，不是已登录 Edge 站内检索。主代理报告 Edge 启动/当前 URL 检查失败，并明确要求我停止浏览器及原生 UI 操作；因此没有绕过该阻碍另用 UI 自动化。搜狗微信页面也被 web open 判为不可访问。

搜索结果只核对单次响应中最多前 4 条链接（教师拼音查询最多前 2 条），没有遍历全部搜索结果页。搜索工具无法返回总索引命中数；日志中的数字是本次响应中捕获的链接数，**0 个目标平台链接**仅限于已查看的结果，不代表平台上不存在内容。
