## 范围和先修关系

2023、2024级各有普通本科与留学生主修方案2份；2025级除这2类外，另有历史学系管理的历史学—旅游管理双学士普通/留学生方案2份，均单独标明适用对象。部分方案引用公共目录，有的展开全部候选、有的只给规则；这些结构差别不代表每名学生需修全目录，也不据此称公共模块“没有课程”。

本批已核查8份方案正文、Word文本和结构化先修字段，未发现可确认课程对课程硬性先修的条款。图中分为**本年级方案数字学期在先、建议先学、内容联系、模块收录**。前者按同一具体方案独立校验，其他是编辑判断或目录归属；全部保留非强制标记。未明确的硬性条件保留待核，不能把空字段或课程模块顺序当作没有先修。

既有2026图谱只提供一份版本化的主题关系编辑框架。本批按各年级唯一同名课程定位，并重新核对该年的课号、方案、学期；未把2026学期数套入旧方案。2023/2024旧TOUR代码保留，跨年同名代码变化单列候选，不证明课程沿革、替代或互认。数学三选一等分支按原模块和学分规则保留，不合并成人人都需完成的链。

## 原始数据与再生成

每年official/raw保存完整全校目录、旅游学系筛选结果及方案详情JSON（gzip压缩，字段/语义保留，格式规范化）；official/word-originals保存官方Word下载字节。HTML阅读页和courses/modules表为派生材料。方案是官方当前公开的对应年级版本，不称入学当年的未修订原版；没有额外推断该年级历史实际开课或授课教师。

官方入口：[复旦本科及本研融通培养方案查询](https://fdjwgl.fudan.edu.cn/manager/bizType/2/page-center/major-program-search-view?skipAuth=1)。各方案详情/导出地址、适用对象、原件字节数与哈希见各年级official/programmes.json。原件权利归原权利人，未取得单独再利用许可声明。内容仅涉及官方方案与课程，不含登录凭据或个人教务记录。

本目录提供 `build_cohorts.py`、`semantic-recipes.py`、`semantic-seed.json`、`viewer-template.html` 和 `validate_cohorts.py`。用Python标准库离线重建：`python build_cohorts.py`；复核：`python validate_cohorts.py`（脚本语法检查另需Node.js）。`fetch_official.py`是独立网络采集脚本，不在离线构建/验证时执行。更新后应重算文件校验清单。

数据归属、逐条原始JSON定位、学期安排及每个方案内的有向无环关系均作核验。没有声称完成浏览器界面实测；交互页不依赖CDN或在线接口，下载后可直接打开。
