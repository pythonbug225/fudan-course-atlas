## 官方范围与适用对象

教务系统2026级 `major-program-search-view` 公开目录返回428条；院系2595（旅游学系）只有ID154832留学生方案。全校同一目录另有ID154078历史学—旅游管理双学士方案，归历史学系，学生类型为普通本科生。两者适用对象不同；结论限于这一公开目录，不推断其他未列目录中的项目不存在。

实际开课范围按 `openDepartmentAssocs=2595` 和学期504/505确定，包含本科、研究生及相关通识课，不是旅游专业学生全部跨院系必修课。培养方案建议学期与实际教学班分别保存。

## 阅读和检索边界

校内查询包含官方课程、教师全名、课号、连写/分词全拼、首字母，以及上下文中实际观察到的简称。完成分页只说明这些关键词的返回结果已取完，不表示搜索索引和所有别名完整。另一次误生成的单字母 `s` 查询达到100页上限，已从有效查询数和有效命中计数排除。

12,235个命中楼层未逐一人工核读；机器筛选后阅读候选及相关上下文，长洞部分只读相关窗口，正文图片未全面核读。提问、求资料和资料交易单独标注；多楼回复不视为多个独立修读者。旧《旅游与文化》与现行《旅游文化》没有直接合并；历史班、同名跨班和教师缩写不明确的记录保留待核。

Edge因无法可靠核实当前网址停止控制，本批**未完成小红书、知乎已登录站内的全部别名、拼音、评论、全文与图片检索**。公开索引零结果不等于平台内没有课评；公众号检索同样不代表全库穷尽。吴本教师专题属于2020年官方报道，未算作目标学期独立学生课评。

## 来源与发布说明

官方原件来自[复旦教务培养方案查询](https://fdjwgl.fudan.edu.cn/manager/bizType/2/page-center/major-program-search-view?skipAuth=1)，具体目录、详情和导出地址见官方资料清单。课程评价提供匿名释义摘要、时间与来源编号，保留个人感受、二手说法及归属不确定性；成绩自报不推算拿A概率。

本贡献包含官方公开返回值、原件和研究摘要/台账，不包含账号密码、登录状态、会话令牌、私人聊天原档、无关树洞原文或未经授权的外部全文。第三方原件及原始内容的权利与许可不因本次整理改变；来源编号用于复核，不授予新的转载许可。

本批资料总量约6MiB，最大单个原件不足0.5MiB，原件与数据直接随贡献目录保存。本次分支仅新增研究资料与入口，课程库合入和在线网站发布仍需另行复核。
