# 国务学院课程关系图谱

下载并用浏览器打开[index.html](index.html)，可按名称、代码、教师检索，点击课程查看内容联系及大纲来源。[graph.json](graph.json)供后续检索程序读取。

覆盖306个课程节点、109条关系候选。官方摘要未提供独立先修字段，故不凭推荐学期或课程编号推定先修。正文先修措辞及候选关系另存JSON中供复核。内容连线基于官方中文简介、教学目标、教学内容中的共同主题词自动提取，均属推断，未逐对专家核实；无连线表示证据不足，不表示无关联。

有向候选从被提及的基础课程指向后续课程；正文中的否定、建议措辞及同名多课号仍需核查，不能视为选课硬性要求。
