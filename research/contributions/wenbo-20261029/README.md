## 范围与证据边界

院系编号2569。2026级全校目录共428条，文博系7个方案ID与院系筛选结果逐一相同。培养方案建议学期与2025秋／2026春实际教学班为不同口径，不能将同代码出现理解为教学班只服务2026级学生。

查询包含课号、课程及教师全名、有来源的短称／历史写法、全拼、分词全拼和首字母。检索成功仅表示当前账号可见返回分页完成，不等于全网穷尽，也不等于17956个原始命中楼层全部人工读过。2000候选的阅读全文与前缀排除、补读上下文按去重ID登记；135条体验记录不是135名独立学生，也不都属于目标学期完整修读经历。

**小红书、知乎及微信公众号的已登录站内逐词检索未完成。** Edge恢复后，本轮电脑操作仍因无法可靠识别当前网址而停止。公开索引补查未取得可采用的相关学生课评；仅全文读取了一份动物考古学官方教改报告，其他索引摘要标作线索，不计学生体验。待查清单中的词为计划，未冒充已执行。
