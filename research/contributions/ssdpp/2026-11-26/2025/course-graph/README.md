# 2025级课程关系图谱

覆盖本年级9份系统方案、193个课程代码及9个培养环节，共202个节点、140条关系。方案列课不等于实际开课，也不保证每门课对所有学生开放。

- [交互图谱](index.html)：下载目录后离线打开，可按课程名、代码与具体培养方案筛选、点击课程逐层浏览。GitHub不直接执行HTML。
- [完整图谱JSON](graph.json)、[节点CSV](nodes.csv)、[关系CSV](edges.csv)、[待补关系](待补关系.csv)。
- [来源核查](source-audit.json)、[培养方案及原件目录](../README.md)、[自动验证](../../validation.json)。

对9份JSON及Word导出文字检索先修关键词；未发现可编码的逐课强制先修条款或明确建议先修条款。检得72个先修字段实例（含重复课程对象），全部为空。字段缺失、为空或未出现关键词，都不能证明没有先修。



每条边保留来源定位、适用方案、判断依据、方向及`mandatory:false`。课程号不同就分别保留，不能据同名或H标记自动互认。点击“依据”可核对两端课程列课来源；**推断关系的来源仅证明课程身份，不能作为官方认可此连线的证据**。

2025心理学普通方案（97235）的原图核得11条明确课程箭头。社会学原图的“古典社会学理论／社会统计学”、社会工作原图的“社会研究方法A／社会统计学”与本次列课题名存在差异，未将这些旧题名自动替换成新课程代码。详见来源核查记录。

全部节点保留；56个节点尚无足够材料连接课程，列在待补关系中。培养环节与正式课程分开统计。2026级的先修备注没有继承到本年级。
