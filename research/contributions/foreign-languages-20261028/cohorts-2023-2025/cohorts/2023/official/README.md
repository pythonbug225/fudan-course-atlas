- `raw/`：未改写的方案 JSON（`.json.gz`）及目录接口响应。
- `word-originals/`：官方导出文件；仅规范了本地文件名。
- `word-text/`：从 Word XML 按段落顺序提取的可搜索文本；表格、图片仍以原件为准。
- `source-figures/`：Word 原件内嵌图片，未重绘；不把图中版面位置当作强制先修。
- `metadata/`：逐份方案的来源与校验信息。
