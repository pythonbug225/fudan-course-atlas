## 先修证据

已核查 5 份 API 方案的原始 JSON 与 Word 文字；未发现 API 先修字段，另有 1816 个课程对象实例未提供这些字段。空缺字段不能证明课程没有先修要求。另有 16 个官方 PDF 补充方案记录；其先修文字与图像依据独立人工核查，见来源说明与每条证据。本版官方强制先修 0 条，官方建议先修 0 条。

完整字段与文本审计见 [prerequisite-audit.json](../data/prerequisite-audit.json)。5 个 Word 图片实例保留在原文中，不将图片位置或推荐学期自动解释为先修。若另有人工图像核查结论，以本批次总说明为准。

## 关系如何产生

- `official_prerequisite`：仅接受明确且可定位的官方强制先修证据。
- `official_recommendation`：官方明确建议先修，未声称存在教务强制选课限制。
- `suggested_sequence`：同年、同方案、相同系列名称的相邻编号或上／中／下课程；同系列同阶段有多个课号时不生成不确定的排列。每条保留两端原文定位。
- `program_module`：课程与官方模块的归属，用方案 ID + 模块 ID 区分同名模块。若 API 在一个方案中重复使用虚拟模块 ID，则加原始数组位置后缀区分，`module_source_id`保留原值。API课程列表由 `planCourses` 与 `realPlanCourses` 按计划课程 ID 去重取并集。PDF抄录使用明确标识的合成模块 ID。
- `topic`：名称中的语言、翻译、文学等关键词关联；不是教学大纲已确认的知识依赖。

数据以 `program_id`、原始 JSON 相对路径、JSON Pointer、官方详情链接定位。缺少课号时以课程对象 ID 建立临时稳定节点，不凭名称合并。所有主题与顺序边有适用方案列表。

## 覆盖边界

- 各年仅使用该级官方培养方案所列课程，含双学位等方案引用的其他院系课程；不混入 2025 秋—2026 春实际开课清单。
- 名称编号或上／中／下顺序是推断，不是教务选课限制；正式先修须向具体教学大纲与教务系统确认。
- 主题关系是名称关键词线索；模块关系只表示官方方案归类，二者均非先修关系。
- 同名不同课号保留为不同节点；同一课号的名称变体保留，建议边须有同方案同名证据。
- 课程图无连线或没有官方先修边表示证据不足，不能解释为没有先修。
- API资料是 2026-11-26 查询到的相应入学年级方案快照；PDF出版原版独立保存。两类来源可能有版本差异，不凭同名覆盖或视作完全相同的历史版本。

使用 Python 标准库执行 `python scripts/build_graphs.py` 可从本批原始快照重建三个年级的数据（在本批次根目录运行）。
