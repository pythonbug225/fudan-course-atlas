# 外国语言文学学院课程关系图谱

下载本目录后打开 [index.html](index.html)，搜索课程名或课号，点击课程查看相邻关系和依据。文件可离线使用；仓库中的HTML源文件需下载后打开。`graph.json`、`nodes.csv`、`edges.csv`供后续检索和可视化使用。

## 覆盖与关系

图谱包含628个课程代码节点、121个培养方案模块节点和13个名称关键词主题节点。范围是2026级25份培养方案所列课程与2025秋、2026春外院开课课程的并集，双学位方案中其他院系开设的课程保留。不同课号未因同名合并；课程名称变体保留。由于索引未保留模块编号，同一方案中重复出现的同名模块不建立关联，以免混淆。

| 关系 | 数量 | 依据和含义 |
| --- | ---: | --- |
| 名称显示的建议顺序 | 83 | 相同系列名称中的编号或上、下，属于推断，不是官方先修要求。 |
| 培养方案模块归属 | 984 | 课程与同一培养方案模块之间的归属，不代表课程有先修关系。 |
| 名称关键词主题关联 | 683 | 据课程名称建立语言、文学、翻译等主题线索，不代表已核验课程大纲。 |
| 官方明确先修 | 0 | 25份方案接口中的先修字段为空，文本未发现明确先修课程；未采集完整课程大纲，不能推断官方不存在先修要求。 |

来源：[培养方案课程索引](../data/program-course-index.csv)、[两学期官方教学班](../data/official-classes.json)、[培养方案接口原件](../raw/official-programs/)。方案课程索引的“开设季节”原字段未解释为建议学期；图谱不根据它推断顺序。具体选课限制以教务系统、对应年份培养方案及课程大纲为准。

每条关系保留类型、理由与来源；`graph.json`中的课程节点带开课院系、课名变体、适用方案及目标学期开课信息。图谱不能证明任何课程已经开设或适用于所有班级。搜索不到关系也不表示不存在联系。

生成脚本 [build_graph.py](build_graph.py) 使用仓库中的官方课程索引和课表；`validate.py`另核对25份压缩接口原件及图谱节点、关系和引用。数据以分支版本 `ed6ceda` 为基础。
