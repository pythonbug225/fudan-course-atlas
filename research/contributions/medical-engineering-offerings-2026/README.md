# 医科与工科开课记录候选（2026）

本目录是供人工复核的官方开课表结构化候选，不是网站的已核验课程目录，也没有自动写入 `public/data/catalog.json`。整理来源为用户提供的复旦官方本科生课程表 PDF：2025–2026 学年春季学期（SHA-256 `FD0B81423A4BBB4CA33C627F7545E7700B71241DB9F790FE5F7BEACCB37B5359`）和 2026–2027 学年秋季学期（SHA-256 `7661B6B3A620DBE1B685C3EEA61A574286A354053485315284ED5ED18E4C9536`）。

## 文件

- `candidate-offerings-2026.csv`：与仓库现有教学班去重后，新增的 **1,757** 个候选开课班次。按“规范学期＋选课序号”合并同一班次；工科和医科来源同时列到同一班次时只保留一行，并合并院系范围。
- `catalog-conflicts.csv`：与现有同名班次有课程名、教师或考试方式差异的 **34** 个班次。此表只列冲突字段名称，不重发教师姓名或冲突内容。

## 去重与覆盖

- 输入：工科 830 行、医科 1,134 行，共 **1,964** 行。
- 工科与医科之间发现 **25** 个相同学期和选课序号的重复班次；已抽取字段一致，合并为一行。
- 与现有网站课程班次匹配：**182** 个唯一班次；其中 **34** 个需人工核对，另外 **148** 个现有记录已去重，不重复提交。
- 去重后新增 **1,757** 行；所有“规范学期＋选课序号”键唯一。
- 冲突字段统计：教师 25 个班次、考试方式 8 个班次、课程名 2 个班次（一个班次可同时含多个冲突字段）。只有双方都有值时才认定不一致；教师名单顺序不作为冲突。

## 字段与限制

CSV 不含源表的“备注”字段。教师列按源表顺序保留，但原始整理说明指出教师字段可能是相邻行推断或文本提取，故每行均标为未核实。上课时间、人数上限、考试日期和考试方式也需要与原 PDF 或教务系统核对。`2025-2026春` 和 `2026-2027秋` 分别映射为网站使用的 `2026春` 与 `2026秋`；原始学期仍保留在 `source_term`。

本目录没有复制培养方案 PDF、全文课评、知乎回答、树洞/旦克原始记录、聊天/微信材料或其它第三方原文。培养方案只在 `public/data/faculty-resources.json` 增加教务处官方来源链接。完整文件请从学校原站查看：[2020版培养方案目录](https://jwc.fudan.edu.cn/0a/ae/c25336a461486/page.htm)、[2022版培养方案页面](https://jwc.fudan.edu.cn/0a/4f/c25327a461391/page.htm)。
