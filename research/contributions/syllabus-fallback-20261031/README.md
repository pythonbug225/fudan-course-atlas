# 无学生评价课程的大纲兜底与官方复查

2026-10-31在第38版基础上复查。为6,142门暂无已核实学生评价的课程整理8,790份大纲，按教师、学期与班号展示课程主线、学习方式、作业和主要任务、考核构成及先修要求。课程卡片标注“依据官方大纲”，与学生体验分开；没有大纲的课程不虚构内容。相同教师、同学期且内容相同的平行班合并展示班号，教师或考核不同的版本分别保留。

- 两学期全校课表14,812班次及2026级428专业方案＋1公共方案再次核对。已有秋季索引亦重查。没有新增或变化班次，55,153条方案课程及培养环节清单没有新增或删除。
- 对3,683个缺项或可疑占位记录逐班查教务接口：3,682个明确返回“暂无审核通过的大纲”，1个允许访问但为空模板。17次网络失败已重试解决，没有遗留请求失败。本轮新增正文0份。
- 两份旧占位/空模板记录1003099、1034280从可用大纲索引移出，保留在 `retired-placeholders.json`。全站可用大纲或结构摘要索引改为13,930条。
- 253门仅列入方案的课程使用已标明学期和教师的参考大纲，不构造2025秋或2026春开课。

`individual-access-checks.json` 保存每次最终状态、课程身份及官方提示；`public-plan-recheck.json` 保存429份方案的响应哈希与课程清单比较；`official-delta.json` 保存六组全量/已审核索引的比较；`source-hashes.json` 保存整理所用HTML哈希。均为课程级规范化数据，没有账户、Cookie或学生名单。

网站数据：`public/data/syllabus-fallback.json` 是索引，`syllabus-fallback-*.json` 保存完整逐班整理文本。源码仍保留可编辑JSON，部署无损gzip传输。原始大纲仍在对应卡片中展开；此批没有新增网页课评或私群内容。

验证：`npm test`，包括所有兜底记录与原大纲哈希、教师/学期隔离、空模板排除、学生原有综评保留、普通与gzip加载等检查。
