# 原始采集响应与查询台账

这里保存本轮采集器实际落盘的24份JSON源文件，以Gzip无损压缩公开。包含校内检索／课程详情／线程聚合响应、查询计划和分页执行记录，以及教务原始接口快照。它们独立于课程摘要，可用于重新核对来源和归属。

## 数据范围

| 数据 | 本轮保存量 |
| --- | ---: |
| 树洞搜索候选 | 19,632条，保留全部编号、时间、查询关联及来源定位 |
| 树洞线程 | 63个线程、502层记录 |
| 蛋壳搜索候选 | 616个课程组 |
| 蛋壳已展开详情 | 369个课程组、776条开课记录、11条课评 |
| 当前查询计划 | 树洞与蛋壳各1361条；执行台账另保留旧拼音等历史查询 |
| 官方资料 | 本轮教务原始JSON；两份Word原件另见[方案原件](../官方资料/方案原件/) |

文件入口：[完整清单与SHA-256](manifest.json)、[校内响应](live/)、[查询计划](query-plans/)、[教务响应](official/)。`forum_search_results.json` 和详情文件是采集器去重聚合后的JSON，不是逐字节HTTP网络包；分页请求地址、offset和完成／失败状态在相应ledger中。

## 解压与验证

在上一级目录运行：

```shell
python restore_raw.py
python restore_raw.py --output raw-restored
```

第一条检查压缩文件、解压后SHA-256及JSON结构；第二条额外恢复全部公开JSON。只使用Python标准库，无需账号或网络。`manifest.json`分别记录采集文件与公开脱敏版的哈希，二者可能不同；Gzip解压不会丢失公开版信息。

## 公开版处理

采集时账号、Token及用户档案已不落盘；公开导出进一步删除身份与凭据字段、联系方式、学号、分享口令和签名参数。响应结构、候选编号与课程／查询关联保留。

树洞搜索池中44条候选正文、线程池中166层正文来自已核读的课程相关讨论串，经脱敏保留；其余19,588条搜索候选、336层线程记录保留元数据与来源，正文标记为尚未完成课程相关性或隐私核对。候选命中不等于与本院有关，也不等于全文已读。原帖删除、折叠或作者限制转载时仍以逐条标记为准。
