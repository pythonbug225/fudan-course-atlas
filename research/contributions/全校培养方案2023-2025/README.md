# 复旦大学 2023—2025 级本科及本研融通培养方案

[打开课程图谱与逐方案修读导读](课程图谱与修读导读.md) · [下载交互导图](https://github.com/pythonbug225/fudan-course-atlas/raw/refs/heads/research/schoolwide-cohorts-2023-2025/research/contributions/%E5%85%A8%E6%A0%A1%E5%9F%B9%E5%85%BB%E6%96%B9%E6%A1%882023-2025/%E8%AF%BE%E7%A8%8B%E4%BF%AE%E8%AF%BB%E5%AF%BC%E5%9B%BE.html)

按教务查询页 2026 级实际有结果的 **40 个归属** 导航。前三届有 38 个同名归属，另有经济管理试验班、自然科学试验班、预科三个历史归属。本页同时收录这三项。生物技术学院、相辉学堂各有专题入口，可以按原院系回查相关方案。

2023、2024、2025 级分别有 147、244、407 份公开方案。本次补录 572 份，已有 226 份可在原分支查阅。2023 和 2024 年度出版的原版汇编另收录 119、142 个分专业章节。两种来源的计数有重叠。

院系名称按教务归属，年度汇编保留出版时的名称及课号。文、理、工、医用于浏览，文类含社科、经管和体育，相辉学堂设跨类入口。数字是当年在该归属下查到的公开方案数。

## 年度汇编与历史院系

[2023 年分专业目录与原件](年度汇编/2023) · [2024 年补录目录与原件](年度汇编/2024)。院系更名和跨院系专业保留文献原称。例如 2023 年法医学列入基础医学院，软件工程列入软件学院。原书中还有通识、大类基础和各专业修读建议，可按目录页码回查。

教务系统 2025 级的 407 条均已纳入。两个试验班归属只在 2024 级的系统目录出现。临床医学按教务的“临床医学院”归属检索，中山、华山临床医学院在学校机构名录分别列名。卓越工程师学院、国际传播与全球领导力学院、生物技术学院、艺术教育中心和终身教育集团在所查三届系统目录均未单列本科专业培养方案。

## 图谱读法

每个方案各有一张可在 GitHub 阅读的图与课程表。方案列明的预修可按原文定位；知识准备建议和内容联系附依据，排课先后使用同一方案明确给出的学期字段。课程在不同方案中的归属、普通与荣誉班型、公共候选课程保留各自适用范围。空白记录表示现有材料未能确认该关系。

统一图谱核对了 798 份系统方案中的 133,472 条课程行。按方案分别计，找到 12 条原文明示的修读顺序、5,161 条建议学习顺序、2,923 条学期先后和 10,509 条内容联系。跨方案重复出现的课程对在各自适用方案中分别计数。[统计与逐组结果](统一数据统计.json) · [Word 和原始数据核验](官方目录/source-validation.json)

来源快照日期为 2026-11-26。系统当前版本与入学年度汇编可并存。原件、课程行以及来源哈希见对应院系和年份。
