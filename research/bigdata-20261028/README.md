# 大数据学院课程研究包

本包单独整理复旦大学大数据学院 2025 秋、2026 春的开课与课程评价，核验日期为 2026-10-29。采用独立分支 `research/bigdata-2026-20261028`，供后续与全校课评库合并。

## 阅读入口

打开 `大数据学院课程研究预览.html` 即可离线检索。每门课程包括教学班、学分、教师、人数与容量，以及大纲、资料、学生评价、综合比较四部分。检索只匹配课程代码、课程名称、教师姓名和这些名称的拼音/首字母；评论正文不会参与匹配。

页面支持培养方案、课程类型和代码前缀筛选。选择专业方案时一并显示公共方案中对应的课程。荣誉版本单独保留，标明优秀率比例不限。没有收录学生评价的课程有明确标记；仅有历史其他教师评价时也单独提示。

已核对的完整蛋壳原评可在课程内展开；正文与摘要分开，保留教师、原始期次、课评ID和匿名来源。历史同名课程组的不同代码不表示可以替代培养方案学分。原评与平台期次存在冲突时会保留冲突，而不自行改成当前班次。

## 大纲、容量与数据含义

本轮通过已授权的教务会话逐个读取146个班次：83份返回大纲正文，覆盖78个课程代码；63个班次返回HTTP 500。失败记录只说明本次未取得正文，不等同于课程没有大纲。六个尚无正文的代码为 `000.000.6`、`CS40022`、`GESP20003`、`GESP20004`、`STAT40004`、`STAT70008`。具体状态见 `教学大纲覆盖.csv`。

人数与容量按教学班ID、班号、课程代码、教师姓名集合四项精确匹配，146班全部匹配。使用的是2026-10-25查询时的聚合快照，并非选课阶段逐日变化数据。`stdCount` 为人数，`limitCount` 为容量；`selectionLimit` 是年级、专业等限选条件。人数差异还受必修安排和限选条件影响，不能直接视为教师受欢迎程度排名。

大纲内容为查询时页面返回的版本，考核结构与学生对往届实际执行的回忆分开写。具体已发现的变化包括黄增峰数据结构的考试权重与孙鑫伟统计荣誉课的考核形式。`STAT50033` 的简介与后文目标/进度存在不一致，综合描述已依目标、周次表和参考教材说明，没有照抄错误简介。

## 各来源与检索方式

- **蛋壳课评、树洞/茶楼讨论**：复用本地保存的课程组详情、检索结果和楼层。课程全名、历史代码、别名、拼音以及教师全名/拼音/首字母都用于寻找候选；归属时核对课程、教师、学期和上下文。关注完整长评，也阅读考试焦虑、给分、作业与复习讨论。纯资料广告、未回答的问课和缩写误命中不作修读评价；交易帖有实质课程体验时仅保留该部分并去掉联系方式。新读取不使用未经平台许可的非官方脚本接口，缓存覆盖不等同于实时穷尽站内结果。
- **六个用户提供的群聊**：按课程/教师别名提取上下文，再筛选可归属的内容。公开包只含匿名来源标签、文件哈希、覆盖计数和可用摘要，不包含原始群聊、群号、成员信息或完整上下文包。见 `group_chat_coverage.json`。
- **知乎、小红书、微信公众号**：仅以课程全名加“复旦”提交公开检索，不做拼音或模糊扩展。84个名称均已提交；本轮未核读到可对应当前教师班次的评价，保留一条知乎的历史知识图谱课程资料线索。站内页面访问受限，且部分批次原始响应未留存，不能把搜索引擎索引结果当作三站穷尽。实际状态逐项保存在 `public_search_coverage.json`。
- **课程材料**：采用固定版本的 [FDU-Sharing](https://github.com/victkk/FDU-Sharing/tree/9a7474955b5a349ebb6d6cdf62d1b89d8ac15959/public/resources) 资料目录及已核读的公开资料页。`material_index.json` 保留课程、文件名、来源与链接，混合年份/教师的题目会注明范围；不以同名资料推断本班考试或给分。

## 原评许可与引用

[旦挞社区服务使用协议](https://danxi.fduhole.com/doc/community-user-agreement)第1条同时包括茶楼和蛋壳，第4条规定用户拥有版权的文本无特别说明时默认采用CC BY 4.0，作者另行声明优先。所收录原评已检查完整正文中的限制声明；匿名来源没有提供作者化名时不猜测身份。每条正文保留原评ID、教师、期次、许可依据与变更说明。摘要为本项目的整理表达，原评所述个案与个人判断不改写成校方规定。

公开课程页仅对课程资料和已核读的知乎/小红书原文设置跳转链接；其他学生来源显示来源名称和记录ID。完整树洞讨论若仅选择部分楼层，会明确标为所选楼层，而不标整帖全文。私有原始响应和认证会话不会随包发布。

## 文件与协作

- `dataset.json`：84门课程的公开结构化数据；`review_sources.json`：核读后的原评、摘要和来源。
- `plans/`：公共及7份专业方案、体系图、精确课号与模块对应。
- `开课班次_2025秋.csv`、`开课班次_2026春.csv`：逐班次资料；`课程汇总.csv` 与 `教学大纲覆盖.csv`：覆盖核对。
- `source_manifest.json`、`verification.json`：来源及检查结果；最终文件哈希见 `files_manifest.json`。
- `alias_registry.json`：课程和教师的拼音/首字母/历史名称线索；`cache_coverage.json`：13,493个本地缓存文件的扫描覆盖，与逐条核读分开统计。
- `render.py` 直接由已发布的 `dataset.json` 生成预览；`synthesize.py` 整理大纲事实并应用AI逐条核读的教师比较；`build_dataset.py` 是维护者从已授权本地缓存导入的入口，不会在运行时登录或抓取网站。

协作者新增记录时，先按原评ID或洞号/楼层去重，保留具体教师与期次，说明亲修、旁听、转述或问课状态。对新教师不要直接继承历史异师结论；无评价时保留标记。只提交去掉身份和联系方式的课程信息；原始群聊、认证数据留在本地。

可运行 `python render.py` 重建预览，使用 `python verify.py` 与 `node filter.test.cjs` 检查课程数量、来源标记、完整原评状态及筛选行为。通过独立分支提交和审阅后再整合到主站。
