# 中文系原始数据

本目录直接存放在 `chinese-2026-plans-2025fall-2026spring-reviews` 分支。原始文件按已有发布版内容保留，与本分支研究目录中的对应文件使用相同 Git 内容对象；逐个来源路径和 SHA-256 见[原始数据校验清单](原始数据校验清单.json)。本次整理未创建新分支。

| 原始材料 | 文件 | 数量与说明 |
| --- | --- | --- |
| 旦挞课评 | [raw/danke.jsonl](raw/danke.jsonl) | 246条来源记录，其中244条公开脱敏正文，2条含私密个人细节的正文保留未公开标记。 |
| 树洞课程讨论 | [raw/forum.jsonl](raw/forum.jsonl) | 355条已核对课程归属的原始记录及相关上下文。 |
| 外部来源 | [raw/external-sources.json](raw/external-sources.json) | 13条小红书、知乎来源索引；未经授权全文及图片不转载。 |
| 2026级培养方案 | [官方培养方案](官方培养方案/) | 8份官方Word原件。 |
| 官方开课接口数据 | [官方课表](官方课表/) | 2025秋、2026春的原始JSON及官方来源记录；两学期共451个教学班。 |
| 官方教学大纲 | [教学大纲原页](教学大纲原页/) | 213份按教学班保存的官方HTML原页。 |

`raw` 中的 `content`、`title` 等文字来自实际平台接口响应，经过必要脱敏后保留原文，没有用AI摘要替代原始正文。来源编号、原帖链接、时间与阅读/归属字段分开保存。[raw-manifest.json](raw-manifest.json)记录正文公开状态、处理次数与校验值；课程归属和阅读状态属于整理元数据。

该目录覆盖本轮已确认课程归属、可公开的来源材料；宽泛检索返回的未确认候选和无关聊天不作为中文系课程原文公开。树洞课评按社区协议及作者声明处理，未公开正文、个人身份与凭据、私密群聊、未授权外部全文和图片不在本目录；六群原档尚未取得。原始数据采集时间为2026-10-27，本目录整理日期为2026-10-30。

检索机制可读取[中文系课程名单](../research/contributions/chinese-language-20261027/中文系课程名单.txt)，并用原始记录的来源ID关联[逐课结构化资料](../research/contributions/chinese-language-20261027/courses/)；历史教师和修读学期仍须按具体记录核对。
