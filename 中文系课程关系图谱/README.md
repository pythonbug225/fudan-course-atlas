# 中文系课程关系图谱

[下载离线包](中文系课程关系图谱_离线包.zip)（解压后打开index.html）

[打开使用说明与路线导读](课程关系导读.md) · [交互图谱](index.html) · [关系数据JSON](课程关系数据.json) · [关系表CSV](课程关系表.csv) · [课程节点CSV](课程节点表.csv)

图谱覆盖2025秋、2026春官方451个教学班对应的291个课程代码（286个不同课程名称），保留同名不同课号。来源为8份2026级培养方案和213份已取得官方大纲；大纲缺失者保留待核状态。

本轮未确认官方硬性先修关系。虚线箭头为整理者建议学习顺序，连线为内容或方法联系；待核边至少一端只有官方课名依据。所有边均保留依据、原文摘录与来源定位，可按类型、学科及课程检索。

在GitHub中查看HTML会显示源码；下载本目录后打开index.html即可离线使用，无需安装依赖或启动服务。JSON、CSV用于后续检索机制和图数据库导入。

数据快照为2026-10-27，图谱整理日期为2026-11-19；未将旧开课学期或培养方案建议开课季节解释成强制先修。
