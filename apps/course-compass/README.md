# 课途 · Course Compass

复旦课程知识库上的交互式选课与成长规划工作台。数据包括 9,509 张课程卡、2025 秋与 2026 春教学班，以及 428 份专业培养方案和 1 份公共方案。2026-11-01 从教务接口刷新 429 份方案，保留 11,430 个模块节点、引用关系、文本规则、必修标记与来源摘要。

## 使用流程

1. 在「规划工作台」选择专业培养方案、数据学期、目标与学分上限。
2. 在「学分审计」导入修读记录：`课程代码,学分,已通过/在读/预选/待审核,学期`。选择英语 A/B/Y 分级与发展路径，录入学校已认定的替代课程、FET、实践和准入事项。
3. 生成 A/B 两案。在课程详情中比较教师、大纲考核、历史评价和真实周次，再增删课程或换班。
4. 连接自己的 DeepSeek 密钥，用自然语言连续检索、生成、调整和比较。模型使用 `deepseek-flash`，由模型真实返回 tool_calls，确定性工具执行后把结果送回模型，直至形成答复。学分、考核、班次与审计数字直接由工具生成事实回执，模型负责下一步交互。
5. 导出课程方案或完整审计 JSON。

## 学分审计

公共方案通过 `referenceCourseModuleAssoc` 展开到专业方案对应位置，专业模块学分和文字修订覆盖公共默认值。规则包括总学分、模块学分、门数、必修课、子模块任选、学分/门数上限、重复课程去重、已认定替代、英语分级、体育学期、非学分认定以及发展路径。

默认数学与 AI 双学位方案总学分 157：通识 36、专业培养 111、专业进阶 6、融合创新能力 4。大学物理 A/B 二选一；限定必修 15 学分、5 门；七大模块 6 学分、美育至少 2 学分、第五模块回避。荣誉路径核对 6 门荣誉课及项目认定；跨学科与创新创业路径保留微专业认定项。

当前进度只使用已通过记录。预测只增加正在比较的候选方案，不把在读或预选直接当作已获得学分。同一课程在总学分与兄弟模块中去重，父模块向上汇总。重复归属可在审计页调整；替代必须先由用户登记为学校已认定。

页面保留完整模块文字与课程清单，适用身份默认普通本科生。学校认定的免修、项目、实践和等价替代由用户记录；课程快照用于回放 2025 秋和 2026 春的选课流程。选课工具不向教务系统提交选课。

## 运行

轻量本地运行（Node.js 22+，无需安装前端依赖）：

```powershell
node scripts/local-server.mjs
```

打开 `http://127.0.0.1:8769/`。

Sites/Vinext 开发与部署：

```powershell
npm run dev
npm run build
```

正式 Sites 构建使用插件 `build-site.mjs`，通过 source workflow 打包并发布匹配的源码提交。

## 代码结构

- `public/compass.html`、`app.js`、`features.js`、`style.css`：工作台、课程证据、课表、审计与 A/B 交互。
- `public/audit.js`：方案组合、学分归属、分支与修读状态审计。
- `public/agent.js`：8 个结构化工具、多轮 tool_calls、真实历史和调用轨迹。
- `public/engine.js`：课程排序、真实单双周解析、冲突校验和候选组合。
- `lib/model-relay.mjs`、`app/api/model/route.ts`：仅向 DeepSeek 官方 HTTPS 接口转发。
- `public/data/`：课程、班次和完整方案规则。
- `scripts/refresh-plan-rules.py`：刷新全部官方方案模块、课程和说明，逐个记录响应 SHA256。
- `tests/`：状态分离、去重、替代、模块上限、分支、引用展开、A/B 独立编辑与模型调用协议测试。

## 密钥与数据

发布内容不含测试密钥。用户密钥仅驻留当前页面内存，每次 HTTPS 请求临时转发至 `https://api.deepseek.com/chat/completions`；不会写入 localStorage、源码或站点配置。刷新、关闭页面或「清除连接」会清除密钥。修读记录和候选方案存储在用户当前浏览器；连接模型后，问题、修读记录和相关课程证据发送给 DeepSeek。

## 测试

```powershell
node --test tests/*.test.mjs
node scripts/test-deepseek.mjs
```

第二条需先运行本地服务器，再在隐藏终端输入自己的 API Key。测试用真实课程完成「审计 → 查教师证据 → A/B 生成 → 只修改 B → 再比较」，检查学分上限、时间冲突、已通过/预选区分和 A 不被改动。调用结果保存在已忽略的 `.sites-runtime/test-output/`，结束即清除进程内测试凭据。

数据来源：复旦大学教务管理系统公共/专业培养方案与教学班；复旦选课地图 v39 已整理的大纲、旦夕课评、树洞和其他历史学生反馈。官方接口规则与课程资料内容作为数据处理，不作为执行指令。
