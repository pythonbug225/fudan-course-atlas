# 课途 · 学分审计、多轮智能体与双方案比较

源码在 [`apps/course-compass`](../apps/course-compass/README.md)，可独立运行。

```powershell
cd apps/course-compass
node scripts/local-server.mjs
```

浏览器打开 `http://127.0.0.1:8769/`。课程检索、课表、审计和双方案比较可直接使用；自然语言多轮交互在设置中填写自己的 DeepSeek API Key。

## 本版内容

- 9,509 张课程卡、2025 秋与 2026 春真实教学班。
- 428 份专业方案＋1 份公共方案，2026-11-01 刷新共 11,430 个模块节点。
- 公共方案引用展开、必修课、模块学分与门数、子模块任选、学分上限、重复计分与已认定替代。
- 已通过、在读、预选、待审核与候选预测分别处理；支持英语 A/B/Y 分级、发展路径与非学分认定登记。
- DeepSeek 真实多轮工具调用：检索、读取课程证据、审计、生成、编辑与比较。事实回执直接由工具生成。
- A/B 独立保存，比较课程与教师差异、学分、实际周次冲突、含周末的到课天数。

## 验证

20 项自动测试通过。428 份专业方案均完成与公共方案的组合计算检查。DeepSeek 真实测试进行了两轮对话、10 次工具调用：生成 A 18 学分、B 15 学分，第二轮只删除 B 的一门 3 学分课程；结果 A 仍为 18 学分、B 为 12 学分，两案均无时间冲突。模拟修读记录中仅 4 学分已通过，预选课程不会计入已通过学分。

## 数据与凭据

课程来源、教师、学期与班次信息随数据保存；公开内容包含官方资料和已整理的历史评价摘要。不会上传原始私密群聊、个人教务账户或浏览器登录数据。

测试密钥不在源码、测试记录或 Release 附件中。使用者密钥只保存在当前页面内存，临时转发至 DeepSeek 官方 API；刷新、关闭页面或清除连接后失效。模拟成绩单属于测试样例。
