# 复旦选课地图轻量视觉升级与工医资料索引

## 意图

让课程检索首页更清楚、更有层次，并让工科与医科的培养方案和课程体验来源采用一致、可追溯的展示方式。主要使用者仍是希望按课程、教师、班型和学期做选择的复旦学生。

## 目标

- 保留现有单页应用、课程筛选、详情、比较、GPA、规则、体测和投稿流程。
- 改善首页标题与搜索区、筛选控件、课程卡片、空状态、导航和窄屏布局的视觉层级与可读性。
- 增加“院系资料”入口，使用同一套资料卡片展示工科和医科的培养方案链接、课程目录来源和公开体验材料。
- 每条资料显示院系、标题、学年/学期、来源链接、资料类型、核验状态、再利用状态和适用范围说明；状态不能只靠颜色区分。
- 外部课程体验只展示可追溯的原站链接与短而中性的说明；新闻报道、课程改革研究、学校精选评价和独立学生课评分别标记，不混成同一类评价。

## 不在本次范围

- 不迁移到新的前端框架，不改数据库、登录、投稿接口或评分逻辑。
- 不把本地两份 PDF、工科培养方案压缩包里的原始文件或社交平台全文放入网站静态资源；公开站点优先给官方原站链接，转载许可未核实时明确标记。
- 不把 `ai_draft_not_reviewed` 草稿导入公开课程详情、评分结论或课评台账，也不把关键词命中当成已读证据。
- 不合并到 `main`，不改用户指定范围外的分支。

## 已知约束与证据

- 当前目标分支是 `codex/engineering-course-contributions`（PR #5），前端采用 `public/index.html`、`public/assets/app.js` 与 `public/assets/app.css`；`app/page.tsx` 只负责跳转到静态首页。改动沿用现有 HTML/CSS/JavaScript，不重写栈。
- 用户授权的改动范围仅限先前提交的两个 PR 分支（PR #4 来源登记、PR #5 工科贡献）。前端与公开资料索引改在 PR #5；如需修订全局来源登记，只改 PR #4 对应来源分支。
- PR #5 已包含 112 份待审核 AI 课评草稿和 2026 工科培养方案档案包；现有草稿仍在研究区，不进入线上课程数据。培养方案原件的再发布权未确认，因此网站索引指向可验证的官方入口，不复制原件。
- 用户提供的 377 页 PDF 是 2026–2027 学年第一学期选课须知/课程表，目录覆盖临床医学、基础医学、公共卫生、法医学、药学、护理和口腔医学等院系；452 页 PDF 是 2025–2026 学年第二学期选课目录。两份 PDF 作为检索目录，不公开上传；其中含教务联系人信息。
- 医科公开来源候选包括教务处 2026 培养方案目录、基础医学强基 2026 培养方案公告、院系官方课程设置，以及少量学校/媒体的课程体验报道。报道与教学研究不是独立课评；公开搜索目前未核实到可按课程、教师、学期匹配的社交平台全文。
- 仓库 `CONTRIBUTING.md` 要求公开第三方课评优先链接原文、完整转载需另有许可，并明确禁止把 AI 摘要冒充实际阅读台账。

## 备选方案与取舍

1. 只微调配色与间距：风险最低，但不能清楚承接工科、医科资料，用户不容易找到新增内容。
2. 保留现有信息架构，统一首页视觉，并加一个轻量“院系资料”入口：能改善页面并展示资料来源，改动小且保留已有交互。**选择此方案**。
3. 重做成多页门户，重新安排课程、学院、数据与工具：导航改动更大，回归风险更高，也超出“轻量升级”。

## 界面设计

- 桌面继续使用左侧导航和主内容区；统一留白、字号、边框和阴影，保留深松绿品牌色，以温和纸白背景和深色文字提高阅读层次。
- 首页突出“按课程/教师搜索”，把主筛选收进一组清楚的筛选面板；课程卡片优先显示课程名、代码、教师/班型、来源覆盖状态和短摘要。
- 移动端导航横向滚动，搜索框与筛选控件按单列/双列折叠，课程卡片单列，不出现横向页面溢出。
- “院系资料”视图按工科/医科筛选，卡片显示标题、年份、院系、类型、来源链接和状态注释。官方培养方案与公开体验资料使用相同外观，但不同类型徽标和说明。
- 继续使用语义标题、键盘焦点提示、可读对比度和减少动态效果设置；保留现有 DOM 事件绑定所需的 ID。

## 资料格式与发布边界

新增的资料索引拟使用单一 JSON 文件，参考现有 `public/data/handbooks.json` 的 `title`、`url`、`source_label`、`summary`、`note` 结构，并补充 `faculty`、`academic_year`、`source_type`、`verification_status`、`reuse_status`、`course_codes` 和 `scope_note`。所有描述仅写来源能直接支持的事实。

- 工科培养方案：PR #5 已有离线档案包；网页只列可验证的官方查询/下载入口与档案状态。未核实再利用许可前不在公开页面托管附件。
- 医科培养方案：以教务处现行目录和院系官方页面为入口，明确版本与适用年级。两份用户 PDF 只用于识别院系/课程代码，不上传、不抄录其中联系人信息。
- 医科课程体验：只有找到可公开访问并能确认课程归属的来源，才记录链接和中性说明。课程宣传报道标作“官方报道/精选体验，非代表性评价”；学术教学改革研究标作“教学研究”，不作为个体课评分数。
- 公开课评原文、学生姓名、未经许可的全文和未审核 AI 摘要不复制到新索引。

## 验收

- 原有搜索、筛选、课程详情、比较、GPA、规则、体测和投稿入口保持可用。
- 桌面与手机各有一张完成后的页面截图，包含首页和工医资料卡片。
- 医科/工科资料卡片字段一致，链接能直接访问，年份、来源类型和许可/核验状态有文字说明。
- 只更新 PR #4 和/或 PR #5 的既有分支；生产站点是否可由该分支部署仍需依照仓库发布流程确认。
