# 学号账户与访问控制

所有课程页面、课程数据分片、站内 PDF、附件、试卷和投稿接口均要求已通过审核的账号。公开入口只有登录页、登录页样式脚本和账户认证接口。

学生使用11位学号注册，设置12—128个字符的本站独立密码。新账号状态为 `pending`；管理员核对身份后通过，才可查阅网站。学号格式校验本身不等于校内身份验证。管理员在“我的账户 → 学号注册审核”处理申请，可通过、退回、停用。停用立即撤销会话。

密码使用随机盐、服务端 pepper、PBKDF2-SHA256（100000轮）派生；明文密码不入库。`STUDENT_PASSWORD_PEPPER` 是必须配置的 Sites 运行时 secret，不能写入仓库。登录 cookie 为 HttpOnly、Secure、SameSite=Lax，7天过期，数据库只保存随机令牌的 SHA256。登录、注册与恢复按 IP 和学号限速，写请求核验同源 Origin。

注册时发放一次性展示的恢复码。凭学号和恢复码重设密码后，恢复码轮换，旧会话全部作废。已登录用户修改密码时必须验证原密码，同样撤销其他设备会话。

原 Sites 管理员账号仍通过平台登录，用于审核账号及投稿。只有运行时 `REVIEW_ADMIN_EMAILS` 中的管理员可进入；其他 ChatGPT 账号不能代替学号注册。既有平台账户的积分、投稿按原身份保留，新学号账户使用独立稳定 ID。

公开静态目录仅保留登录页及其两份样式脚本。课程页面、脚本、JSON、PDF等构建产物由 `privatize-assets.mjs` 转为带 SHA256 的分卷，管理员通过 `/admin-assets` 分卷导入私有 R2，全部分卷校验完成后再切换资料版本，登录后由 Worker 按目录进行 Range 读取。不能把受保护文件放在静态资产目录；当前托管分发会优先返回这些文件。

Cloudflare assets 配置必须保留 `binding: ASSETS` 和 `run_worker_first: true`，；受保护文件必须从静态目录移入私有 R2，不能只依赖该配置。所有受保护响应 `Cache-Control: private, no-store`。上线验收要以无登录 cookie 的请求确认课程 JSON、PDF 与主页均不返回内容。

此前已经公开在 GitHub、第三方平台或浏览器缓存里的材料不由本网站的登录控制。当前项目不自动修改 GitHub 仓库权限，也不删除第三方原文。

迁移：`drizzle/0004_student_accounts.sql`；新增 `student_accounts`、`student_sessions`、`auth_rate_limits`。恢复码、密码哈希、会话令牌和学号不得提交到公共仓库或写入日志。

课途 `/compass` 和其云端接口沿用相同身份。`0005_course_compass.sql` 新增个人档案和选课快照；保存请求同时核验快照版本、活动方案及档案版本，另一设备切换方案后旧保存会返回冲突。

资料版本由 `lib/private-assets-config.json` 管理。自动发布使用运行时 secret `PRIVATE_ASSET_PUBLISH_KEY`，仅允许导入、状态查询和完成发布三个接口。`0006_private_asset_import_grants.sql` 保存密钥哈希、版本、1小时有效期与撤销时间；完成发布即撤销该版本的发布凭证。上线后移除运行时密钥，旧密钥请求必须返回401。私有分卷、实际密钥和账户资料不进入 Git。
