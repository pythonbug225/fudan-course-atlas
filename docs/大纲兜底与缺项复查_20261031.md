# 大纲兜底与缺项复查

没有学生评价时，课程仍可根据官方大纲作选课参考。现为6,142门课程整理8,790份大纲，卡片标明“依据官方大纲”；详情按教师、学期、班号分别说明：

- 课程主要讲什么、采用何种课堂或实践方式；
- 作业、实验、项目、汇报、阅读或论文等明确任务；
- 考核比例与大纲中的具体标准；
- 已列明的先修要求及教学进度要点。

课程主线与考核信息来自对应版本的大纲，不把教学目标写成已经发生的学习收获，也不生成学生给分体验。学生原评和已有学生综评保持独立。筛选教师或学期时，其他版本不会冒充该班内容；仅供参考的大纲标明来源班次。

本轮重新查询全校课表、429份2026级方案及3,683个缺项/可疑占位记录。课表和方案课程清单没有新增缺项。缺项中3,682个明确没有审核通过的大纲，1个为空模板；17次网络失败均已重试，新增正文0份。旧索引中两个只有占位信息或空模板的记录已剔出可用大纲，原文件仍保留以便追溯。

现有9,509张课程卡片、17,398个班次，索引13,930份大纲或结构摘要。另有2,064门无学生评价课程尚未取得可用大纲，其中包含大量仅列在方案、目标学期没有开课的课程，仍显示实际资料状态。
