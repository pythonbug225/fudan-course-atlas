# 尚未完成院系清单与全校覆盖核对

核对日期：2026-10-30。本轮核对GitHub分支、Release资产更新时间和固定提交，再与当前网站课程库对照。培养方案基线为2026-10-28保存的教务2026级目录：428份方案、39个院系、203组院系与专业/培养方向。

## 优先安排的专项工作

1. **医学六院系，以及基础医学课程范围**：临床医学院、公共卫生学院、药学院、护理学院、口腔医学院、法医学与法庭科学学院。已核对1109个教学班、接入37份方案，但尚需系统课评核读、逐教师总结和大纲。基础医学院未单列在该版2026目录，仍应按实际开课纳入，不能据此排除。

2. **五个工科创新学院**：智能机器人与先进制造创新学院、智能材料与未来能源创新学院、未来信息创新学院、集成电路与微纳电子创新学院、生物医学工程与技术创新学院。已有官方方案和局部资料；112条AI草稿、开课表候选不算完成的学生课评。医学已核验班次不重复记作工科完成。

3. **国际金融学院、相辉学堂**：尚未找到院系专项检索成果，现有共享课程卡不能替代院系整理。相辉学堂的培养要求还需与学生所属院系方案关联。

以上共13个目录院系需要开展或继续主体工作，另有基础医学课程范围；并非其所有课程均无资料。

## 已有首轮整理，不能误判为未开展

历史学系、新闻学院、国际文化交流学院、社会发展与公共政策学院、马克思主义学院本轮新增或补齐专项成果；此前数学、计算与智能、物理、化学、生科、环科、中文、外文、国务、大气海洋、核科学、高分子、大数据、经济、管理、哲学、法学、文博、旅游、体育均已有首轮资料。已有首轮不代表所有教师和所有外部平台均已查完。

生物技术学院已按两份方案整理54组跨院系课程。计划内24个本院系代码尚未见25秋/26春班次，应等实际开课后跟踪，不当作24门已开但漏搜课程。

## 后续补缺标准

- 先核对当期实际开课范围、课程代码、教师和班次，再找大纲、资料、学生原评与综合总结。
- 树洞可查课程/教师别名和拼音，并记录模糊搜索分页及停止原因；知乎、小红书和微信公众号按课程全名搜索。
- 找不到已核实课评可以如实标注；不要求每门课程一定有评价。问课和考试焦虑属于讨论，不能直接充当修读评价或成绩分布。
- 表中“有体验”包括历史教师或历史班次；“有大纲”包括正文和结构摘要；两者均不等于当前教师证据齐全。
- 培养方案列课并不保证当期开设。同代码卡可能来自跨院系开课；需要逐班次确认。公共方案与一个专业方案共同构成完整方案。
