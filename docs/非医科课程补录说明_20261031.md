# 非医科课程补录与检索覆盖（2026-10-31）

本轮对照2026级官方培养方案目录（2026-10-28留存）与2025秋、2026春教学班快照（2026-10-27留存），补全站点缺失的非医科课程信息。生物医学工程按工科保留，其他医学范围未扩录。

- 391份非医科专业方案已逐项核对。本轮补44项方案元数据与342份缺失附件，其中341份为完整正文，方案151832为官方测试课程索引。
- 两学期12661个非医科教学班全部与课程卡对应；新增1323组课程、3474个教学班，修正139组教师清单。
- 新取得6148份可用大纲；本轮接口空白、错误分别记录，未充当大纲正文。各班教学大纲按课程代码、教师、学期及教学班绑定。
- 新增410条评价摘要与9条讨论记录，276条完整原评或所选讨论楼层可展开。这些是资料记录数，不是独立学生人数。
- 全站现有7009组课程、15816个教学班、11872份大纲或结构摘要；5765组暂无已核实学生评价。

## 如何理解覆盖

课程表对应完成不表示每门课都有学生评价。树洞检索使用全名、课程/教师别名与拼音；本轮优先查询和历史上下文读取的实际页数、停止原因保存在参考包台账。小红书、知乎、公众号仅采用课程全名加复旦精确查询；未打开的搜索片段不作为已读课评。Edge本轮仍有连接故障，公开网页检索与已有GitHub资料继续使用，未声称完成这些平台站内全量扫描。

本轮新增59个课程全名模糊查询及10个补充考期窗口请求，共69份成功结果，38份翻到空页，31份达到40页上限。命中项只有经过核读才出现在课程体验中。考期窗口只是接口请求参数，返回结果包含跨期条目，修读学期仍按正文或平台明确标记识别。

历史教师评价按原教师与修读学期保留。普通课、荣誉课、英才班不自动混并；体育旧优秀率和报分只表示历史个人经历，当前体育采用绝对值给分。课程类型未明确本科或研究生时，保留官方原始课型，不按代码猜测。

公共方案加本人对应的一份专业方案构成完整培养要求。方案152715为相辉/英才独立方案，与151991不合并。资料可点开；评价来源除小红书、知乎外以文字注明。私群只公开匿名摘要，未收录原始聊天、成员身份或登录信息。
