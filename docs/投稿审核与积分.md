# 投稿审核与积分

投稿入口支持当前目录的全部课程。新投稿进入待审核状态，审核通过后在课程详情公开，课评奖励 20 分，课程资料奖励 10 分。投稿人在“我的投稿”查看状态、反馈并撤回。

审核员在投稿页下方使用“投稿审核”。服务器根据平台登录身份和生产环境的 `REVIEW_ADMIN_EMAILS` 逗号分隔名单授权；未配置名单时不开放审核权限。名单保存在 Sites 运行环境中，源码不包含管理员个人信息。

待审核与退回正文、附件仅投稿人和审核员可读。此前公开的投稿标为 `legacy`，继续公开，不追溯发奖。提交时对正文与附件生成内容校验值，同一作者的相同内容只收录一次。

审核决定与奖励在同一个 D1 事务中写入，积分事件具有唯一键。重复审核、网络重试不重复发奖。撤回会停止公开、移除附件并收回对应奖励；已使用奖励时，余额可能暂为负值，后续签到可继续累积。内容去重与奖励记录继续保留，防止撤回后重复领取。

每日签到按上海日期奖励 5 分；首次通过本站解锁一份试卷扣 1 分，同一账户重复打开免费。原始试卷仓库公开，本站积分不改变原仓库的访问方式。

## 部署与验证

- 追加迁移 `0002_slimy_jazinda.sql` 创建积分账本，`0003_pink_enchantress.sql` 增加审核状态、内容去重和审核记录；旧迁移保持原样。
- Sites 发布流程在 Worker 更新前应用待执行迁移。
- 服务端身份来自平台注入头，不接受请求正文中的用户、日期、费用或奖励金额。
- 回归测试：`npm test`。新增审核测试使用全部真实迁移建立 SQLite 数据库，覆盖公开范围、附件权限、审核权限、奖励、退回、撤回及重复请求。
- 线上验收：登录 → 签到 → 单份试卷解锁 → 再次免费打开 → 查看流水；投稿 → 审核通过 → 公开 → 奖励 → 撤回并收回奖励。
