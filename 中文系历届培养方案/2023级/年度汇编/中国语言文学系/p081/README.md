想了解汉语研究的课程安排，可以在原表中找到《现代汉语（上）》（`CHIN130002`）、《语言学概论》（`CHIN130011`）、《语法学》（`CHIN130239`）。 [原书 PDF 第 93 页](original-pages.pdf#page=1) · [原书 PDF 第 94 页](original-pages.pdf#page=2)
