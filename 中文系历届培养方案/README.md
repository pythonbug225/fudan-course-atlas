## 怎样读这些关系

- **方案中的先修要求**需有官方条款点明前后课程。26 份培养方案正文、课程字段和 Word 原件中，未核实到这种课程对。每个年级的说明另列官方手册核查范围。
- **建议学习顺序**从基础课程指向后续课程。每条关系记录两门课共同出现的具体方案。若方案中有足以判定先后的数字开课学期，关系数据还列出对应学期；学期相邻本身不能证明选课设有限制。
- **内容联系**连接有共同文本、研究对象或方法的课程，双向阅读。每条关系标注依据来自大纲、课程名称或分级编号。来自某一教学班的具体建议保留学期和来源。

## 年级之间有什么变化

- **2023 级**以两个专业的“2+X”方案和古文字学强基班为主，七份方案的总学分均不低于 156。
- **2024 级**增列汉语言—人工智能双学士培养项目，项目要求 176 学分。两个常规专业方案为 141 学分，古文字学强基班正文列 141 或 142 学分。
- **2025 级**两个常规专业方案为 140 学分。汉语言和汉语言文学各有一份博雅班本博融通方案，双学士项目也有独立的本博融通版本。

每个年级下的 `课程关系.json` 提供课程节点、关系、适用方案 ID，以及回到原始 JSON 的记录指针，可按“年级＋方案 ID＋课号”检索。下载该年级资料包并解压，用浏览器打开 `课程图谱.html`，课程和方案原件均可离线查阅。
