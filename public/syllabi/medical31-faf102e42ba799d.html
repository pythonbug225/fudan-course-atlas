1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 医学统计学基本概念和原理，常用概率分布和抽样分布，研究设计，假设检验，不同类型数据的常用检验方法，相关回归分析等。

课程简介（英文） Course Description ( in English ) | Basic concepts and principles of medical statistics, probability distributions and sampling distributions, research design, hypothesis testing, and commonly‑used test methods for different types of data, correlation and regression analysis, etc.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

理解医学统计的基本概念，了解统计学基本原理，掌握常用的统计分析方法以及研究设计的基本原则，能够进行简单的研究设计，能够根据不同类型的研究设计，科学地搜集、整理、分析数据，作出合理推断，并能够理论联系实际，解决医学研究问题。

3 . 教学方式 /Teaching Methods （应体现实现教学目标所采用的具体策略、方法和组织形式）

充分运用PBL的教学理念，以授课结合课堂实习和案例讨论，注重培养学生分析和解决问题的能力。
