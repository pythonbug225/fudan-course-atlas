课程简介（中文）

传感器和信号处理是一门交叉学科，涉及光学、电子学、光与物质的相互作用等领域。《传感器和信号处理》课程主要讲述传感器的理论基础知识以及传感器的结构组成、设计思路和应用特点，通过本课程的学习能够独立的完成简单测量系统的设计。通过介绍传感器和信号处理方面的基础知识，学生可以对信号探测技术有初步的了解，并可以能够独立的完成简单信号探测系统的设计。

课程简介（英文）

Sensors have been used for industrial process control, measurement, and automation. The main task of this course is to enable students to master how to design measurement systems using available sensors and integrated circuits. For each sensor we describe the working principle, the basic structure, advantages, limitations, types, the main performance measurement circuit, and relevant application. The signal processing, interference suppression techniques and a number of new sensor detection system are also introduced in this course. The development, implementation, operation and applications of intelligent and smart sensors are also introduced.

教学目标

掌握智能传感器的基础理论、性能参数，熟悉各类传感器（包括电阻式、电抗式、有源式、磁电式、数字式传感器等）的基本工作原理、信号处理电路以及适用场景，能够初步掌握简单传感器的设计思路与方法。在此基础上，使学生深入了解智能传感器系统中硬件集成的方式及基础智能化功能软件模块的实现技术，掌握多种经典与新兴信息处理技术的原理与方法，以及深度学习与强化学习等人工智能技术在智能传感系统中的应用。
