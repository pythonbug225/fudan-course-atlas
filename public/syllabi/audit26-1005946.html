课程简介（中文）

通过课程讲解与演示，使学生了解质性或定性研究资料与定量研究资料的区别，了解质性和定性研究资料分析的常用软件；了解Maxqda和Nvivo的安装要求和界面特性；学会并能够使用Maxqda和Nvivo进行各种类型资料的导入；对资料进行编码和分析；创建备忘录、批注和链接；发掘隐藏的关系和规律、进行框架矩阵分析；利用Maxqda和Nvivo软件进行查询；将研究结果以可视化的方式显现等。学生在授课后将能了解质/定性研究分析软件的基本特征，能够正确地通过常见定性研究分析软件进行定性研究的资料分析，完成项目和工作任务。

课程简介（英文）

Through course lectures and demonstrations, students will learn the differences between qualitative and quantitative research data, as well as common software function for qualitative data analysis.Students will become familiar with the installation requirements and interface features of MAXQDA and NVivo; learn to import various types of data into these programs; perform coding and analysis; create memos, annotations, and links; uncover hidden relationships and patterns; conduct framework matrix analysis; utilize query functions in MAXQDA and NVivo; and visualize research findings. After the course, students will understand the fundamental characteristics of qualitative research analysis software, be able to correctly use common qualitative analysis tools for data processing, and complete projects or work tasks.

教学目标

通过教学使学生了解定性研究的基本方法，定性研究与定量研究的区别，定性研究资料的收集与分析的基本方法；了解并熟悉定性分析软件Maxqda和Nvivo的功能；能够正确地使用定性分析软件Maxqda和Nvivo定性资料分析软件进行定性资料的分析。

教学方式

课堂讲解与实习操作。
