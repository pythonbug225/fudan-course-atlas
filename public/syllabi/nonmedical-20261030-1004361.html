课程简介（中文）

《英语论说文写作》课程适用于《中国英语能力等级量表》中提高阶段（四至六级）的学习者。课程旨在培养学生初步的论说能力：使其学会对相关话题的语言材料把握要点，理清逻辑关系；能对语言材料进行初步的分析，判断和评价，并用论据支持观点。 通过本课程的修读，学生应能达到《中国英语能力等级量表》中书面表达、组构及语用相关能力的六级水平

课程简介（英文）

English Essay Writing is intended for non-English major undergraduates with higher English proficiency. This course aims to help students develop their writing skills so that they can write argumentative essays. In this course, students will: Learn to write a persuasive argument Learn to write clearly, concisely and coherently Recognize formal and informal language Improve word usage

教学目标

基本要求: 修课前要求： 学生应已完成大英III课程的学习，具有《中国英语能力等级量表》四级（含）以上的英语语言能力。 修课中要求： 学生应完成教师布置的文章阅读、写作任务；应积极参与课堂讨论，准备好课堂演讲，积极和发言同学互动；还应对自己保持学习策略调整。 预期教学效果 （参考《中国英语能力等级量表》六级水平）： 1. 总体能力：能就感兴趣的话题写短文，有论点和论据， 衔接手段多样，语意连贯。能理解多种话题（包括一般性专业话题）的语言材料，把握要点以及逻辑关系，分析、判断、评价材料中的观点、态度和隐含的意义。能就社会热点问题或现象，运用多种论证方法阐明观点，论据充分，有逻辑性。 2. 书面描述：能比较准确、清晰的描述事件；能准确地描述数据的特点及规律，条例较为清晰。 3. 书面说明：能就常见话题简单说明自己的观点；能比较完整、准确的描述图标信息；能根据图标信息说明事物的发展趋势；能撰写比较详细的实施方案；能合理解释某些社会和自然现象，并讨论其发展趋势和变化规律。 4. 书面论述：能解释支持或反对某一观点的理由，清楚说明不同观点的利弊；能分析数据和事例来证明论点或假设，语言准确，逻辑清晰；能对文章、书籍、电影等进行比较全面的总结和客观评价；能分析教育、娱乐、民生等领域的热点问题，并提出具体建议。 5. 书面表达策略：能运用结构规划、段落首站、起承转合等基本写作技巧；能通过增加实例、细节等手段丰富写作内容；能收集不同来源的信息，并判断其可靠性。能通过自问自答的方式帮助自己理清思路，以便有针对性地收藏信息；能深入审读所写话题，以规划写作内容；能利用电子资源数据库等，广泛收集学术论文的相关文献。能综合运用说明、议论等方法论证主要观点；能借助图表说明观点或提供信息；能通过变换词语、句法结构来避免重复。 6. 组构能力：能理解语篇中复杂结构的表意功能；能运用常见的语法结构组织信息，层次清楚；能使用有效的衔接手段，提高表达的连贯性。 7. 语用能力：能理解正式或非正式场合中对方表达的不同意图；能在交流中选择不同的语言形式，恰当地表达自己的观点、情感、态度；能就不同话题与他人交流，有效表达自己的观点，情感、态度，话语符合身份以及社会文化规约，沟通顺畅。能委婉表达反对和质疑；能在辩论中有效反驳他人的观点。
