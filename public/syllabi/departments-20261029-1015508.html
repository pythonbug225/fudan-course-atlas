课程简介（中文）

本课程采用当前流行的 Python 语言作为教学工具。对于非计算机相关专业的学生而言，Python 非常适合作为第一门编程语言。 学习内容涵盖以下几个方面：包括列表、元组、字典和集合在内的 Python 序列；选择、循环等控制结构；常用的字符串操作方法、字符串函数及正则表达式；函数的定义与应用，以及模块的定义与应用；图形用户界面（GUI）、绘图、文件操作与异常处理；还有涉及 NumPy 和 Pandas 学习与应用的基础数据处理。

课程简介（英文）

This course adopts the currently popular Python language as its medium. Python is highly suitable as the first programming language for students majoring in non-computer-related fields. The learning content covers the following aspects: Python sequences including lists, tuples, dictionaries and sets; control structures such as selection and loops; common string operation methods, string functions and regular expressions; function definition and application, as well as module definition and application; graphical user interfaces (GUI), plotting, file operations and exception handling; and basic data processing involving the learning and application of Numpy and Pandas.

教学目标

The Python Programming course aims to help learners master the core Python programming skills and develop the basic literacy to solve practical problems, covering three specific aspects. In terms of knowledge and skills, learners need to grasp Python's basic syntax, the use of standard libraries and third-party libraries, understand the concepts of object-oriented programming (OOP), and be able to design simple classes and objects. For processes and methods, they should establish a programming mindset of "problem analysis → logical decomposition → code implementation → debugging and optimization", proficiently use development tools (such as VScode), and develop standardized coding habits. Regarding attitude and application, learners are required to cultivate interest in programming, eliminate the fear of coding, and apply Python to practical scenarios like data processing and automated script development to put their skills into practice.

教学方式

Basic Requirements Master proficiently: common Python data types, control structures, string processing, functions, classes, and file operations. Understand: regular expressions, modules, and exception handling. Teaching Methods： Offline teaching: Basic knowledge is acquired through PPT presentations and operation demonstrations, followed by hands-on computer practice to develop programming skills, along with tutoring and Q&A sessions.

教学内容与进度安排

Teaching Content Arrangement（Detailed to Each Class）： Content Module Week Content & Expected Achievement Introduction to Python & Basics 1 - Understand what Python is and its application scenarios.- Install Python and set up the development environment (e.g., Anaconda, PyCharm). - Learn basic syntax: comments, variables, data types (int, float, str), and simple input/output (input(), print()). - Expected: Successfully run a simple "Hello, World!" program and perform basic variable operations. 2 - Dive deeper into data types: list, tuple, dictionary, set. - Learn basic operations for each data type (creation, access, modification for mutable types). - Expected: Be able to create and manipulate different data structures, e.g., create a list of numbers and access elements. Control Flow 3 - Master conditional statements: if, elif, else.- Practice writing conditional logic to solve simple decision - making problems (e.g., determine if a number is positive or negative). - Expected: Correctly use conditionals to branch program execution. 4 - Learn loop structures: for loop (including iteration over sequences) and while loop. - Use loops to perform repetitive tasks (e.g., print numbers from 1 to 10, calculate the sum of the first 10 integers). - Expected: Write loops to automate repetitive operations and understand loop termination conditions. Functions 5 - Understand the concept of functions and why they are used. - Learn to define functions with def, add parameters (positional, default), and use return to send back results. - Expected: Create and call simple functions, e.g., a function to calculate the area of a rectangle. 6 - Study advanced function topics: variable - length arguments (*args, **kwargs), lambda functions. - Learn about scope (local vs. global variables). - Expected: Use advanced function features to write more flexible code and understand variable scope. File Operations 7 - Learn to open, read, write, and close files using open() function (modes: 'r', 'w', 'a', 'r+'). - Practice reading data from a text file and writing results back to a file. - Expected: Successfully perform basic file operations, like reading a list of numbers from a file and writing their sum. Error Handling 8 - Understand common errors (syntax errors, runtime errors, logical errors). - Learn to use try, except, else, finally blocks for exception handling. - Expected: Implement error handling to make programs more robust, e.g., handle file not found errors. Object - Oriented Programming (OOP) Basics 9 - Learn the concepts of classes and objects. - Define classes, create objects, and understand attributes and methods. - Expected: Create a simple class (e.g., a Student class with name and grade attributes) and create objects from it. 10 - Dive into OOP features: inheritance, polymorphism, encapsulation. - Create a derived class and demonstrate method overriding. - Expected: Understand and apply basic OOP principles to organize code. Modules and Packages 11 - Learn to create and use modules (.py files). - Understand how to import modules (using import, from...import). - Expected: Create a custom module with utility functions and use it in another script. Data Visualization Basics (Matplotlib) 12 - Introduction to the Matplotlib library for data visualization. - Learn to create basic plots: line plots, scatter plots, bar charts.- Customize plots (titles, labels, colors).- Expected: Create a line plot to visualize a sequence of data points and customize the plot's appearance. NumPy 13 - Introduction to the NumPy library for numerical computing. - Learn to create NumPy arrays (1D, 2D) and understand array properties (shape, dtype).- Perform basic array operations: element - wise arithmetic, slicing, indexing. - Expected: Create arrays and perform operations like adding two arrays element - wise, slicing a 2D array to get a sub-array. Pandas 14 - Introduction to the Pandas library for data manipulation. - Learn to create Series and DataFrame objects.- Perform data loading (from CSV), selection, filtering, and basic data cleaning. - Expected: Load a CSV dataset into a DataFrame, filter rows based on a condition (e.g., select rows where a column value is greater than a threshold), and perform simple data cleaning like handling missing values. Review 15 - Comprehensive review of all topics covered.- Practice with sample exam questions and past assignments.- Expected: Solidify understanding of all concepts and be prepared for the final exam. Final Exam (Closed - book) 16 - The exam will cover all topics from weeks 1 to 15, including syntax, data structures, control flow, functions, OOP, file operations, modules/packages, data visualization with Matplotlib, NumPy, and Pandas.
