1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 卫生统计方法（一）主要介绍医学研究中统计学的基本概念、研究设计、统计描述、常用概率分布、抽样分布、假设检验的基本思想，以及常用的统计学检验方法。

课程简介（英文） Course Description ( in English ) | Biostatistics (level 1) primarily introduces the basic concepts of statistics in medical research, research design, descriptive statistics, probability distributions, sampling distributions, hypothesis testing, as well as commonly used statistical methods.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

通过本课程的学习，旨在帮助学生理解和掌握医学研究中统计学的基本概念、原理和方法，培养学生的统计思维和分析能力，掌握如何合理地进行医学研究设计，学会科学地搜集和整理数据，能够根据不同的研究目的和数据特点选择合适的统计方法进行分析，具备对统计分析结果进行合理解释和推断的能力，能够结合实际情况，得出科学、客观的结论。希望学生能所学理论知识应用于实际医学研究和临床工作中，解决实际问题，提高实践能力，为医学研究和临床工作提供有力支持。
