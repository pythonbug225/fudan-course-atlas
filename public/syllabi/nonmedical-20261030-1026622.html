课程简介（中文）

本课程主要包括以下三个部分： FPGA 架构组成：包括 FPGA 逻辑单元（logic block）、可配置布线资源、可编程 I/O，以及嵌入式 IP（知识产权）核，例如 DSP（数字信号处理）模块、存储器模块、PLL（锁相环）、微处理器、AI 引擎和片上网络（NoC, Network on Chip）等。 基于 FPGA 的硬件原型设计编译流程：涵盖 HDL（硬件描述语言）解析、逻辑优化、映射（mapping）、打包（packing）、布局布线（placement and routing）、静态时序分析（STA, Static Timing Analysis）以及器件编程等环节。实验一基于复旦大学自主研发的 FDE 开发板及 FDE+Rabbit 工具链进行。 基于 Nios 的嵌入式系统设计与软硬件协同设计技术：利用 Altera QSYS 工具链，在系统级 FPGA 平台上开展嵌入式开发。实验二基于 DE2-115 或 DE1-SoC 开发板，并采用 Intel/Altera 提供的 Quartus 工具链完成。

课程简介（英文）

There are three main parts in this course: 1．Architectures of FPGA logic block, configurable routing resource, programmable IOs and embedded IP (Intellectual Property) cores such as DSP (Digital Signal Process) block, memory block, PLL (Phase Locked Loop), microprocessor, AI engine and NoC (Network on Chip) etc. 2． Hardware prototype design compilation flow based on FPGAs, which includes HDL (hardware description language) parser, logic optimization, mapping, packing, placement and routing, STA (Static Timing Analysis) and programming etc. Lab session 1 is based on FDE board and the FDE+Rabbit tool chain, developed by Fudan University. 3． Nios-based embedded system design and software/hardware co-design techniques with system-level FPGAs based on Altera QSYS tool chain. Lab session 2 is based on DE2-115 or DE1-SoC board and Quartus tool chain, developed by Intel/Altera

教学目标

Learn the principle of modern FPGA hardware architectures, including hardware programming technologies, programmable logic block, routing architecture and IO blocks. FPGA compilation EDA (Electronic Design Automation) tool flow and system-level applications are covered to utilize the hardware resources and design embedded systems. Students will learn and practice the techniques on software/hardware co-design, and the embedded system design flow based on FPGAs.

教学方式

Lectures and 2 lab sessions plus the lab presentations.
