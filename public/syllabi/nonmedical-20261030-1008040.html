课程简介（中文）

本课程是关于如何将机器学习技术应用于实际问题。将介绍一系列技术，从线性回归和决策树等经典方法，到提升和深度学习等更新的方法。还将讨论如何为给定的问题选择正确技术，以及如何调整参数以获得最佳结果。我们也会手把手教学生如何用 python 实现每一个算法。学生需有python基础。我们将会提供 A40 的工作站作为大家编程的机器。

课程简介（英文）

This course is about how to apply machine learning techniques to practical problems. We will cover a range of techniques, from classical methods like linear regression and decision trees, to more recent methods like boosting and deep learning. We will also discuss how to choose the right technique for a given problem, and how to tune the parameters to get the best results. We will also walk you through how to implement each algorithm in python.you can program in our A40 work station.

教学目标

本课程面向有 Python 基础的学生，以学生培养为核心，融合知识传授与能力培养。通过课程学习，学生能系统掌握机器学习算法原理与适用场景；具备将算法应用于实际问题的能力，能独立完成数据处理、模型构建与优化，同时树立严谨的工程思维与创新意识，为后续科研或技术实践奠定基础。
