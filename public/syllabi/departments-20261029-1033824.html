课程简介（中文）

本课程将在回顾Python语言基本编程规范和内置数据结构的基础上，对于数据结构和算法的基础知识进行系统介绍。主要内容知识点包括算法复杂度分析、递归、数组、链表、栈、队列、树、优先级队列、堆、哈希表、搜索树、排序算法、图与图算法、模式匹配、贪心算法、动态规划等。学生通过听课、练习、日常作业等形式进行学习。课程包括期末考试。

课程简介（英文）

Following a comprehensive review of Python programming paradigms and built-in data structures, this course provides a systematic introduction to the fundamental principles of data structures and algorithms. Core Curriculum and Key Topics: The curriculum covers a broad spectrum of essential topics, including: Algorithmic Analysis: Formal analysis of time and space complexity ($O, \Omega, \Theta$ notation). Fundamental Linear Structures: Arrays, Linked Lists, Stacks, and Queues. Advanced Data Structures: Trees, Priority Queues, Heaps, Hash Tables, and Search Trees. Core Algorithms: Recursion, comprehensive Sorting Algorithms, and Graph Theory with associated Graph Algorithms. Strategic Paradigms: Pattern Matching, Greedy Algorithms, and Dynamic Programming.

教学目标

本课程的目标是让学生在对Python程序设计有一定了解及掌握的基础上进一步学习数据结构和算法的基础知识。 一方面，在编程中遇到的实际问题需要学生运用各种数据结构对数据进行查询、插入、删除、排序等处理。 另一方面，实践中出现的需要对数据进行的操作与运算则需要学生掌握一定的算法知识。 本门课程将在前序课程的基础上，利用Python语言作为载体，帮助同学加深对编程的理解，掌握对实际问题选择合理数据结构并编写合适的算法来解决的能力。 学生学完本课程后，应当能识别编程中会遇到的常见数据结构并合理运用数据结构来处理数据。同时，学生应当掌握对常见数据结构中的数据进行操作所运用的一些基础算法，并有一定的设计、改进算法的能力。

教学方式

课堂讲授与实际练习相结合。学生应自带电脑，有必要时在课堂上跟随老师进行代码实操练习。
