课程简介（中文）

课程聚焦 AI/HPC 主导时代存储器的核心战略地位，覆盖 SRAM/DRAM/FLASH/HBM 等主流存储设计，深入讲解 ReRAM/MRAM 新型存储与存算一体技术，邀请长鑫、长存、光羽专家解析量产与产业化实践。通过闭卷考试与课程设计，培养学生适配前沿需求的存储电路设计能力，为 AI 芯片、HPC 存储系统研究与应用奠基。

课程简介（英文）

The course focuses on the core strategic position of memory in the AI/HPC-driven era. It covers the design of mainstream memory technologies such as SRAM, DRAM, FLASH, and HBM, and delves into emerging memory technologies (ReRAM, MRAM) as well as in-memory computing technology. Experts from CXMT (Changxin Memory Technologies), YMTC (Yangtze Memory Technologies), and Transcputing are invited to explain practices in mass production and industrialization. Through closed-book exams and AI/HPC scenario-based course projects, the course cultivates students' ability to design memory circuits that meet cutting-edge needs, laying a foundation for the research and application of AI chips and HPC storage systems.

教学目标

本课程立足复旦大学 扎根中国、服务国家的办学定位，面向集成电路方向大三学生（具备基础电路知识，需深化专业能力），契合专业工程实践与科研创新并重的 培养要求。价值引领上，引导学生树立服务国家芯片自主战略的行业责任感；知识传授上，系统覆盖 SRAM/DRAM/HBM 等主流存储、ReRAM/MRAM 新型存储及存算一体技术；能力培养上，通过闭卷考试与 AI/HPC 场景化设计，提升存储电路设计、产业化适配能力，为学生投身顶尖科研或工业界存储领域奠定基础。

教学方式

课堂讲授结合存储器、存算一体案例传核心知识；邀请长鑫、长存等业界专家解析量产实践，强化产业认知；设存储器/存算一体实操与场景化课程设计指导，锤炼实践能力。 通过 “讲授 + 专家课 + 实操 + 指导” 多元形式，层层递进实现价值引领、知识传授与能力培养的教学目标。
