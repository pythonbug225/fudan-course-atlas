1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 本课程作为预防医学专业本科生《流行病学》理论课的配套实践课程，紧密结合流行病学核心基础理论，以疾病防控典型案例为切入点，以课堂讨论为形式，增强学生对理论知识的理解与掌握，培养疾病防控实际工作能力。内容涵盖疾病频率测量、研究设计、混杂控制、因果推断和筛检试验评价等内容。每周3课时，共11次课。

课程简介（英文） Course Description ( in English ) | This practicum course, designed for preventive medicine undergraduates, complements the theoretical epidemiology curriculum. Using real disease-control cases as entry points and classroom discussion as the main format, it deepens understanding of core concepts and cultivates field capacity. Topics include disease-frequency measures, study design, confounding control, causal inference, and screening-test evaluation. The course meets 3 hours per week for 11 sessions.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

秉承复旦大学公共卫生学院“严谨，求实，团结，创新”的治学理念，以为国家培养高质量的公共卫生与预防医学高层次人才为目标，引领学生树立为人民健康服务的使命感与责任感，系统掌握流行病学核心知识，并训练流行病学研究设计、现场实践、数据分析等综合能力，为毕业后胜任疾病防控、科学研究等岗位任务奠定基础。

4.教学内容及进度安排 /Course Content & Schedule （ 按照教学周编排，应包含每节课教学内容及教学目标，如有作业及考核要求，请一并列明）

1、疾病频率测量 （第2周） 1.1 流行病学常用的测量疾病和死亡的指标 1.2 各种指标的意义、用途及局限性。 2、疾病分布 （第3周） 2.1 疾病频率测量指标 2.2 疾病流行强度 2.3 疾病的分布 3、现况研究方法 （第4周） 3.1 现况研究中的抽样调查方法 3.2 现况研究的原理、用途 3.3 设计的主要内容和优缺点。 4、暴发调查 （第5周） 4.1 暴发及相关定义 4.2 暴发基本类型 4.3暴发调查基本步骤与方法 4.4暴发调查报告撰写。 5、病例对照研究方法 （第7周） 5.1 病例对照研究设计的原则和方法 5.2 病例对照研究与现况研究及队列研究相互转化的条件 5.3 病例对照研究常用指标的计算及结果的解释。 6、队列研究 （第8周） 6.1 队列研究的基本原理 6.2 队列研究方法 7、流行病学实验 （第9周） 7.1流行病学实验的基本概念、现场实验方法及注意事项 7.2 预防接种效果评价的常用指标及其计算 7.3预防接种计划的制定和实施方案的设计 8、筛检试验 （第11周） 8.1 筛检试验的应用原则 8.2 筛检试验的指标及其计算方法 8.3 各指标间的相互关系和筛检的策略 8.4筛检试验的影响因素 9、混杂及其控制 （第12周） 9.1混杂的概念及其特征 9.2不同类型研究中可能存在的混杂 9.3混杂的控制方法 10、不明原因调查及因果推断 （第13周） 10.1 病因评判标准 10.2案例学习和讨论 11、流行病学数据处理的基本原则（第14周） 11.1流行病学变量的基本类型、整理原则和方法； 11.2不同类型流行病学数据分析方法的选择思路与结果阅读 12、课程考试及考察（第15周）
