课程简介（中文）

本课程围绕金融大数据与 Python 应用展开，系统涵盖多维度内容。首章介绍金融大数据知识概况，第二章夯实其理论基础。接着从 Python 概念与基础入手，逐步过渡到金融场景下的 Python 应用，深入讲解金融分析方法。还涉及深度学习在大数据分析中的运用，并通过经典案例分析与实践，帮助学员将理论与实操结合，全面掌握金融大数据分析技能，提升在金融领域的数据分析与应用能力。

课程简介（英文）

This course centers on financial big data and Python applications, covering multi-dimensional content systematically. The first chapter introduces the general knowledge of financial big data, and the second chapter lays a solid theoretical foundation for it. Then, starting from Python concepts and basics, it gradually transitions to Python applications in financial scenarios, and deeply explains financial analysis methods. It also involves the application of deep learning in big data analysis, and through classic case studies and practices, helps students combine theory with actual operations, so as to comprehensively master financial big data analysis skills and improve their data analysis and application capabilities in the financial field.

教学目标

本课程旨在帮助学生全面掌握金融大数据分析核心能力。通过系统学习，学生能理解金融大数据的基础概念与理论体系，熟练运用 Python 进行金融场景下的数据处理与分析，掌握深度学习在大数据分析中的应用方法，并能结合经典案例解决实际金融问题。最终提升学生对金融数据的解读能力、建模分析能力及实践应用能力，为从事金融数据分析相关工作奠定坚实基础。

教学方式

教学采用 “理论 + 实操” 结合模式：课堂讲授金融大数据与 Python 理论，辅以案例解析；通过编程实训、场景模拟强化应用能力；分组完成项目实践，结合经典案例开展研讨；利用在线平台提供习题与答疑，确保学员扎实掌握知识，提升解决实际问题的能力。

教学内容与进度安排

第 1 周​ 教学内容：第一章金融大数据知识简介，介绍金融大数据的概念、特点、应用领域及发展历程。​ 教学目标：让学员理解金融大数据的基本概念和重要性，了解其在金融领域的典型应用场景。​​ 第 2 周​ 教学内容：第二章金融大数据理论基础，包括数据采集、处理、存储等基础理论，以及金融数据的类型和特征。​ 教学目标：使学生掌握金融大数据的理论基础，能区分不同类型的金融数据并了解其特征。​ 作业： 收集某一金融领域的相关数据，分析其类型和特征，形成报告。​ 第 3 周​ 教学内容：第三章 Python 概念和基础知识，讲解 Python 的语法、数据类型、函数、模块等基础内容。​ 教学目标：学员能掌握 Python 的基本操作，熟练运用基本语法和函数进行简单编程。​ 作业：编写几个简单的 Python 程序，实现数据的基本运算和处理。​ 第 4 周​ 教学内容：第四章金融场景下的 Python，介绍 Python 在金融数据获取、清洗等方面的应用，如使用相关库获取金融数据。​ 教学目标：学员能运用 Python 获取金融数据并进行简单清洗，适应金融场景下的 Python 应用。​ 作业：使用 Python 获取某类金融产品的历史数据，并进行简单清洗，提交代码和结果。​ 考核要求：作业需在指定日期前提交，逾期将扣分。​ 第 5 周​ 教学内容：第五章 Python 金融分析，讲解运用 Python 进行金融数据的统计分析、可视化等，如绘制金融数据图表。​ 教学目标：学员能运用 Python 对金融数据进行统计分析和可视化呈现，直观展示数据特征。​ ​ 第 6 周​ 教学内容：第六章深度学习大数据分析，介绍深度学习的基本概念及其在金融大数据分析中的应用，如预测股票走势等。​ 教学目标：学员了解深度学习的基本原理，知道其在金融大数据分析中的应用方式。​ 作业：查阅相关文献，总结深度学习在金融领域的一个应用案例，撰写报告。​ 第 7 周​ 教学内容：第七章经典案例分析与实践，选取金融大数据分析的经典案例进行深入分析，组织学员进行实践操作。​ 教学目标：学员能借鉴经典案例的分析方法，将所学知识运用到实际案例分析中。​ 作业：选取一个经典案例，按照分析方法进行复现，提交实践报告。​ 考核要求：实践报告需逻辑清晰，体现对案例的理解和分析能力。​ 第 8 周​ 教学内容：综合复习，对前 7 周的知识进行梳理总结，解答学员疑问，讲解课程考核相关事宜。​ 教学目标：帮助学员巩固所学知识，明确考核要求，做好考核准备。​
