1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 本课程是医学统计的入门课程，介绍基本统计概念、常用概率分布和抽样分布、统计推断原理和方法、不同类型资料的统计描述以及两样本资料的统计推断方法。

课程简介（英文） Course Description ( in English ) | This course is an introductory course in medical statistics, covering basic statistical concepts, common probability distributions and sampling distributions, principles and methods of statistical inference, statistical description of different types of data, and statistical inference methods for two-sample data.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

通过本课程的学习： 使学生认识卫生统计学在医学和公共卫生中的重要性，理解统计分析对医疗和公共卫生决策的影响. 培养学生初步的统计思维能力，掌握统计推断的原理，能够进行恰当的资料描述，做出合理推断。 训练学生在面对医学数据时，能够提出有针对性的问题并设计合理的研究方案，进行分析和解决实际问题。

3 . 教学方式 /Teaching Methods （应体现实现教学目标所采用的具体策略、方法和组织形式）

课堂讲授为主，结合实际的案例分析，让学生理解统计方法在医学和公共卫生领域中的应用。
