信息管理实证研究

2025秋 · MSE60003.02 · 李根

来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

这门研讨课包含两个部分。第一部分，我将进行授课，重点讲解一些关键知识点，包括但不限于经验研究中用于因果推断的方法论、信息系统与经济学领域的前沿研究论文等。第二部分，要求学生认真阅读指定论文并积极参与课堂讨论。在某些周次，学生需要复现指定论文中的关键表格。我将提供作者的原始数据和代码，学生可使用自己熟悉的统计语言进行复现。

课程简介（英文）

This seminar course contains two parts. First, I would like to give a lecture emphasizing the pivotal knowledge points which contain but not limited to methodologies used for causal inference in empirical studies, frontier research papers in Information Systems and Economics field, etc. Second, this seminar requires students to read the assigned paper carefully and participate in class discussion. This course also tries to improve students’ coding capabilities. In some weeks, students need to replicate key tables in the assigned paper. I will provide data and code from the authors. Students can use their preferred statistical language for reproduction.

教学目标

本研讨课旨在实现三个目标。 首先，我将介绍在信息系统顶级期刊中广泛采用的计量经济学方法。通过深入讨论，学生将学习如何运用合适的方法来开展实证研究，重点在于学习重要的因果效应推断工具。 其次，课程内容涵盖前沿研究主题，使学生接触到广泛且有趣的研究方向。 最后但同样重要的是，本课程还将通过复现已有实证研究的结果，提升学生在统计编程方面的能力。

教学方式

通过本课程的学习，学生将有机会了解以因果推断为核心的实证研究写作的整体流程。除了对方法论、研究主题和编程技能的探讨之外，更重要的是，本课程将帮助学生理解如何成为一名研究者，如何展开理论，如何构建自己的研究叙事等。因此，这门研讨课应被视为对学生其他课程学习和与导师合作研究项目的有益补充，而非替代。与此同时，学生的展示能力也同样重要。我计划用几节课专门讲授这一部分内容。 课堂中，学生将积极完成提前准备好的文章的讨论工作。 本课程没有书面形式的期中或期末考试，评估将基于学生对指定论文的评论、学期论文以及学期末的展示。学期论文应为一个具体主题的研究论文。我希望这篇论文可以成为未来撰写期刊论文的初步基础。在整个学期中，学生将从零开始逐步完成这篇论文。
