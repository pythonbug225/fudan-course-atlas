现代集成电路分析方法

2025秋 · EST60015.01 · 曾璇

来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

一、集成电路分析发展的历史。 二、节点电压方程的建立方法。 三、电路方程的时域瞬态分析方法。 四、第二代电路分析方法——时间步进法：数值积分方法（Euler、RungeKutta）；线性方程的直接解法（Gauss, LU）；稀疏矩阵技术； 五、第三代电路分析方法——波形松弛法：迭代法（Jacobian, G-S）； 六、非线性电路的求解方法：非线性代数方程组的Newton Raphson迭代求解； 非线性稳态分析方法：Shooting, Harmonic Balance。 七、超大规模互连线性电路的模型降阶方法：AWE，Krylov 子空间降阶技术如PVL等。 八、寄生参数提取方法。 九、基于贝叶斯统计推断的混合信号电路工艺偏差估计和建模分析。 基本要求：1、编程实现节点电压方程自动建立；2、对线性节点电压方程，基于MATLAB编程，采用时间步进法、波形松弛法和AWE方法、Krylov Space降阶方法实现求解。

课程简介（英文）

History of integrated circuit analysis development. Methods for establishing node voltage equations. Time-domain transient analysis methods for circuit equations. Second-generation circuit analysis methods – Time-stepping method: Numerical integration methods (Euler, RungeKutta); Direct solution methods for linear equations (Gauss, LU); Sparse matrix techniques. Third-generation circuit analysis methods – Waveform relaxation method: Iterative methods (Jacobi, G-S). Solution methods for nonlinear circuits: Newton Raphson iterative solution for nonlinear algebraic systems; Nonlinear steady-state analysis methods: Shooting, Harmonic Balance. Model order reduction methods for VLSI interconnect linear circuits: AWE, Krylov subspace reduction techniques such as PVL. Parasitic parameter extraction methods. Bayesian statistical inference-based process variation estimation and modeling analysis for mixed-signal circuits. Basic Requirements: Programmatically implement automatic node voltage equation formulation; For linear node voltage equations, implement solvers in MATLAB using: Time-stepping method, waveform relaxation method, AWE method, and Krylov Space reduction method.

教学目标

帮助学生了解现代集成电路的基本分析方法，特别是关于大规模集成电路的模型降阶技术和非线性电路模型的分析方法。 To help the attendees to understand the basic methodology of VLSI circuit analysis, especially the model order reduction techniques for large-scale circuit and the analysis methods for non-linear circuits. 帮助学生建立提升集成电路设计的推理、分析和编程能力。 To help the attendees to develop the ability of reasoning, analyzing, and programming in the area of circuit analysis

教学方式

教学采用渐进式框架，理论讲解与编程实践相结合。前期侧重基础概念引导，中期逐步引入核心算法原理，后期聚焦综合应用能力培养。每单元理论课配套实践任务，通过模块化编程训练深化理解。作业设计遵循阶梯式难度，从基础方程构建过渡到系统级仿真实现，最终以开放性课题收尾。课堂注重启发算法思维，实验环节强调抽象方法的代码转化，整体保持弹性以适应不同学习节奏。
