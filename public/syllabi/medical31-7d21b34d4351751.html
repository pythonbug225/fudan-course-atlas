1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 本课程在全面介绍医院管理基本理论和基本方法的基础上，针对医药卫生体制改革中医院管理工作面临的新形势、新问题作一些专题介绍，使学生在对医院管理学的学科体系全面了解的同时，也能接触到这一学科发展的前沿。

课程简介（英文） Course Description ( in English ) | This course provides a comprehensive introduction to the fundamental theories and methodologies of hospital management. It further addresses the new challenges and emerging issues confronting hospital management within the context of healthcare system reform through specialised modules. Students will gain a thorough understanding of the disciplinary framework of hospital management while also engaging with the cutting edge of developments within this field.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

随着社会进步与医疗卫生事业的发展，掌握医院管理的相关理论和方法，是对医院管理者的基本要求，本课程致力于在教授医院管理相关知识的同时，提高学生的医学人文精神。课程将涉及医院管理的核心内容，包括质量管理、安全管理、护理管理、运营管理等，也包括医院后勤管理、文化管理等内容。

3 . 教学方式 /Teaching Methods （应体现实现教学目标所采用的具体策略、方法和组织形式）

讲授为主，同时辅以线上慕课、课堂讲座和医院现场参观等形式
