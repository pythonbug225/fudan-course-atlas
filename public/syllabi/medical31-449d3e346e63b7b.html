1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 本课程总论部分详细介绍了微创外科观念的形成，以及现代微创外科的发展，微创外科技术如腹腔镜、胃肠镜、输尿管镜、胸腔镜、关节镜、介入等技术的特点及其应用，同时结合各专业的解剖特点，详细介绍了临床各专业普通外科、神经外科、泌尿外科、骨科、胸外科、血管介入微创外科、机器人外科、麻醉科等专业微创知识，通过微创学的历史、现状与演变，培养学生救死扶伤的医学人文理念和发展创新的科研理念，在我国微创外科的发展成果中培养自强自信、求实创新的精神；最后结合腹腔镜模拟实训室，掌握常用腹腔镜基本技能，加强学生的动手实践的能力

课程简介（英文） Course Description ( in English ) | 本课程总论部分详细介绍了微创外科观念的形成，以及现代微创外科的发展，微创外科技术如腹腔镜、胃肠镜、输尿管镜、胸腔镜、关节镜、介入等技术的特点及其应用，同时结合各专业的解剖特点，详细介绍了临床各专业普通外科、神经外科、泌尿外科、骨科、胸外科、血管介入微创外科、机器人外科、麻醉科等专业微创知识，通过微创学的历史、现状与演变，培养学生救死扶伤的医学人文理念和发展创新的科研理念，在我国微创外科的发展成果中培养自强自信、求实创新的精神；最后结合腹腔镜模拟实训室，掌握常用腹腔镜基本技能，加强学生的动手实践的能力。

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

本门课程的授课对象是临床医学本科专业学生，通过学习，使其掌握外科微创学解剖、病理等基本知识，掌握腔镜及内镜基本技术、各种外科疾病的微创治疗适应症以及手术方法，熟悉腔镜系统的组成、功能，掌握腹腔镜下的基本技能。在知识传授和能力培养的过程中塑造价值观，通过“学习、观察、讨论、验证、总结”等一系列教学过程中增强自信，鼓励创新，勇毅前行，培养学生的国家意识、仁心仁术、医学人文和创新观念

4.教学内容及进度安排 /Course Content & Schedule （ 按照教学周编排，应包含每节课教学内容及教学目标，如有作业及考核要求，请一并列明）

第1，2学时：外科微创学总论 （2学时） 了解外科微创学的概念和发展史：外科微创观念的形成，以及现代外科微创的发展，外科微创技术如腹腔镜、胃镜、肠镜、介入技术等； 熟悉外科微创学的优缺点； 外科微创学在治疗及诊断上的应用：血管介入治疗技术、主动脉瘤的介入治疗、主动脉夹层动脉瘤的介入治疗、颈动脉狭窄的介入治疗、动脉硬化闭塞性疾病的介入治疗、原发性下肢静脉曲张的介入治疗。 第3，4学时：外科微创学及腔镜基础（2学时） 了解外科微创学的发展史，了解微创外科与传统手术外科的异同，了解微创外科的培训过程，了解外科微创学各专科常见的手术体位； 熟悉外科微创学的发展过程和应用范围，熟悉腔镜的基本技术及操作步骤，熟悉不同的通道建立方法； 掌握外科微创学的概念，掌握腹腔镜系统的组成和常见的操作器械，掌握腔镜的基本原理和特点。 第5，6学时：普外科微创学 （2学时） 了解3D腹腔镜、N.O.T.E.S手术、达芬奇机器人、远程机器人微创手术的发展，了解常见的普外科微创手术体位及手术要点； 熟悉外科微创学在普外科临床中的应用范围，熟悉常见的普外科微创术式，熟悉手助腔镜外科的应用； 掌握普外科微创学发展的趋势，掌握常见的普外科微创学的手术适应症（肝胆胰脾、胃肠外科）及优势，掌握微创减重外科、疝外科手术的分类。 第7，8学时：胸外科微创学 （2学时） 了解外科微创理念在胸心外科领域的具体应用和实践； 熟悉胸外科微创发展史，理解医学实践与科技进步的辩证关系； 掌握胸腔镜外科和机器人胸外科技术的基本原则。 第9，10学时：泌尿外科微创学（2学时） 了解泌尿外科腔镜技术发展史； 熟悉开展泌尿外科微创手术的常用设备、路径，重点熟悉经皮肾镜、输尿管镜碎石术和泌尿外科腹腔镜技术； 掌握泌尿外科微创手术原则。 第11、12学时：微创内镜学 （2学时） 了解胃镜技术；结肠镜技术；胆道镜技术；十二指肠镜技术；内镜技术的发展，胶囊内镜技术；小肠镜技术；超声内镜技术； 熟悉内镜的发展史，内镜的组成，内镜的发展趋势； 掌握诊断内镜和治疗内镜的区别。 第13、14学时：血管介入治疗技术 （2学时） 了解血管介入技术的发展史及基本方法和器械； 熟悉血管外科常见疾病的微创介入手术方法及和传统开放手术的对比； 掌握血管介入技术的发展及进展。 第15、16学时：血管微创介入器具结构与研发（2学时） 了解血管微创外科介入器具和模拟真实研发场景（如优化支架的柔顺性、降低血栓风险），扩展学生的多学科视野； 熟悉从临床需求分析→概念设计→原型开发→性能验证→临床试验的全周期研发流程； 掌握血管微创常用介入器具（如导管、支架、球囊、导丝、栓塞器材等）的结构设计、材料特性及工作原理。 第17、18学时：妇产科微创学（2学时） 了解微创理念及妇科微创分类；了解妇科内镜手术发展史； 熟悉阴式手术的适应症及弊端、内镜手术的适应症； 掌握内镜手术的并发症及处理。 第19、20学时：骨外科微创学（2学时） 了解骨科各种微创手术的方法，以及技术发展史； 熟悉骨科微创手术的种类； 掌握骨科微创治疗的理念；膝关节镜的手术原则。 第21、22学时：神经外科微创学（2学时） 了解神经外科微创技术进展； 熟悉微创神经外科微创技术：显微神经外科（锁孔技术）、神经内镜技术、神经导航技术、血管内介入技术、立体定向放射治疗技术； 掌握神经外科发展历程及微创理念：宏观层面（外观创伤）和微观层面（神经功能微创）。 第23、24学时：甲乳外科微创学（2学时） 了解乳腺、甲状腺微创外科技术的发展史、手术设备及器械。 熟悉乳腺、甲状腺微创外科的各种手术路径，重点熟悉微创外科在乳腺、甲状腺外科已经开展比较成熟的手术。 掌握乳腺、甲状腺微创外科理念、技术的优缺点及基本原则。 第25、26学时：微创外科手术的麻醉（2学时） 了解国内外麻醉学的起源和发展史； 熟悉麻醉的工作内容和范畴； 掌握麻醉的定义，掌握麻醉药物的选择使用和注意事项；掌握腹腔镜对人体生理功能的影响以及麻醉管理。 第27-30学时：腹腔镜基础培训（腹腔镜模拟实训室）（4学时） 了解开放与腔镜手术的差异；了解模拟腹腔镜系统组成和功能； 熟悉腹腔镜模拟器下腔镜的打结、剪切及缝合 掌握腔镜常用器械的应用；掌握腹腔镜模拟器下定位、传递与两手配合等技能 第31-32学时：考试
