课程简介（中文）

本课程着重于介绍涉及计算机软件技术的一些基础课题并强调其实用性, 表现为用相当大的比重来介绍应用广泛且被认为是计算机软件工程环境标准工作平台之一的UNIX操作系统、以及用与之密切相关的C语言来实现数据结构的编程。 内容包括计算机操作系统的一般原理; UNIX操作系统及其软件开发工具(vi/ex、sed、awk、make、SCCS、lex和yacc等); C语言的主要特征(数据与存储单元的关系、构造性数据类型、数据的通讯等)以及对程序标准化的讨论; 数据结构的基础课题(线性表、栈和队列、树和二叉树、图的定义等)。

课程简介（英文）

This course focuses on introducing fundamental topics in computer software technology with an emphasis on practical applications. This is reflected in the significant proportion devoted to the UNIX operating system—widely used and recognized as one of the standard working platforms in computer software engineering environments—as well as programming implementations of data structures using the C language, which is closely related to UNIX. The content includes general principles of computer operating systems; the UNIX operating system and its software development tools (vi/ex, sed, awk, make, SCCS, lex, yacc, etc.); major features of the C language (relationships between data and storage units, structured data types, data communication, etc.) and discussions on program standardization; fundamental topics in data structures (linear lists, stacks and queues, trees and binary trees, definitions of graphs, etc.).

教学目标

本课程旨在为学生提供计算机应用软件开发的基础知识和实用技术。课程着重介绍UNIX操作系统及其开发工具（vi/ex、sed、awk、make等），C语言的核心特性（数据存储、构造性数据类型、数据通信等），以及基础数据结构（线性表、栈、队列、树、图等）。通过学习，学生将掌握设计、开发CAD/CAE/CAM/CAI等应用软件所需的核心技能，为今后的软件工程实践奠定坚实基础。

教学方式

课堂讲授为主，课堂讨论和实验教学为辅。
