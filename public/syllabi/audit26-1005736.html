课程简介（中文）

Java 是一种面向对象程序设计语言，具有简洁规范、面向对象、跨平台等优点。Java 语言早期主要用于 Internet 应用程序开发，经过 20 多年的发展，其功能不断扩展，在云计算和移动互联网迅速发展的产业环境下，Java 更具备了显著优势和广阔前景。本课程讲授 Java 语言的核心内容，主要包括基础语法和面向对象程序设计方法两部分。课程将编程实践融入到知识点的讲授过程当中，使同学掌握 Java 程序设计的基本原理和方法。

课程简介（英文）

Java is an object-oriented programming language that has the advantages of simplicity, standardization, object-oriented design, and cross platform compatibility. Java language was mainly used for the development of Internet applications in the early days. After more than 20 years of development, its functions have continued to expand. Under the industrial environment of rapid development of cloud computing and mobile Internet, Java has a significant advantage and broad prospects. This course teaches the core content of Java language, mainly including basic syntax and object-oriented programming methods. The course integrates programming practice into the teaching process of knowledge points, enabling students to master the basic principles and methods of Java programming design.

教学目标

熟练掌握 Java 语言基本语法，包括变量的定义和使用、运算符、流程控制、循环、数组。掌握 Java语言面向对象程序设计方法，包括类的定义和使用、继承的原理、抽象类和接口；熟悉 Java 的图形用户界面程序设计方法，包括用户界面元素、事件处理等；熟悉 Java 图像处理程序设计方法。能使用 Java语言编写图形用户界面程序和简单图像处理程序。

教学方式

课程内容讲授和编程联系深度融合。
