数据科学编程基础

2025秋 · MSE30027.01 · 石岩松

来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

本课程主要讲解数据科学理论与方法及Python中数据科学编程工具的使用，核心内容涵盖： （1）基于NumPy和Pandas的数据分析进阶操作； （2）经典机器学习方法的原理与实现，包括分类、回归、聚类、降维、推荐算法、主题模型等； （3）经典深度学习方法（各类神经网络）的原理与实现； （4）数据分析方法在实践场景中的应用实例。

课程简介（英文）

This course primarily focuses on the theories and methodologies of data science and the utilization of data science packages in Python. The core content includes: (1) Data analysis with the advanced operations of NumPy and Pandas; (2) The principles and implementation of classical machine learning methods, including classification, regression, clustering, dimensionality reduction, recommendation algorithms, topic models, etc.; (3) The principles and implementation of classical deep learning methods (i.e., various types of classical neural networks); (4) The application of data analysis methods in practical scenarios.

教学目标

本课程的教学目标是使学生能够深入了解数据科学的算法原理并能够熟练运用Python完成进阶数据分析工作。通过学习本课程，学生能够理解经典的机器学习和深度学习算法原理，使用Python的数据科学编程工具（NumPy、Pandas、Sklearn、PyTorch、TensorFlow等）实现算法并开展复杂数据分析项目，建立运用数据科学技术解决实际问题的能力。

教学方式

课堂讲授为主，结合上机指导：教师面对面讲解数据科学原理与方法、演示代码，现场指导学生使用自带电脑完成上机操作（建议学生使用Jupyter Notebook作为开发环境）。
