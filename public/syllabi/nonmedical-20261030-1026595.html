课程简介（中文）

本课程主要内容包括：数据转换器的定义、应用场景、国内外发展现状、基本原理、基本架构、基本模块、性能指标、性能影响因素、测试和验证、前沿技术和发展趋势等内容。 主要包括以下两个模块： 高性能模数转换器（ADC）的基本原理、电路、架构、应用、发展趋势和技术前沿 高性能数模转换器（DAC）的基本原理、电路、架构、应用、发展趋势和技术前沿

课程简介（英文）

The main content of this course includes: the definition of data converters, application scenarios, the current development status domestic and abroad, basic principles, basic architecture, basic modules, performance indicators, factors affecting performance, testing and verification, modern technologies, and development trends. It mainly includes the following two modules: (1) Basic principles, circuits, architectures, applications, development trends, and technological frontiers of high-performance analog-to-digital converters (ADCs)； (2) Basic principles, circuits, architectures, applications, development trends, and technological frontiers of high-performance digital-to-analog converters (DACs).

教学目标

本课程主要介绍数据转换器的基本原理和前沿技术发展，聚焦数据转换器基础知识，培养学生的逻辑思维和科学研究能力。具体学校目标如下： 【知识目标】 数据转换器基本概念和指标参数定义 数据转换器基本理论 数据转换器基本架构 数据转换器基本功能模块和电路原理 数据转换器发展趋势和技术前沿 【能力与素质目标】 评价数据转换器性能指标的能力 发现高性能数据转换器性能瓶颈的能力 掌握数据转换器仿真和基本电路设计的能力 设计数据转换器基本架构的能力 开展数据转换器电路和架构创新思考和设计的能力 【情感和价值目标】 探索科学技术的创新精神 为我国集成电路发展而努力的奋斗精神 敢于打破国外技术垄断的报国精神

教学方式
