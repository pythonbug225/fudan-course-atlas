1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 系统解剖学是医学基础核心课程，重点研究人体各器官系统的形态、结构和位置关系。课程强调理论与实践结合，学生将掌握人体九大系统（如运动、消化、呼吸等）的结构与功能，为其它医学课程奠定坚实的形态学基础。

课程简介（英文） Course Description ( in English ) | Human anatomy is a core medical course focusing on the morphology, structure, and spatial relationships of human organ systems. Combining lectures, specimen observation, and lab practice, it covers nine major systems (e.g., musculoskeletal, digestive, respiratory) to build a morphological foundation for clinical medicine.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

本课程兼顾基础和临床知识内容，临床的思维方法与研究策略，重视在解剖学知识传授的过程中提高学生学习医学知识的能力: 1. 记忆解剖学关键专业术语的概念，描述解剖学九大系统中各器官和结构中关键的形态学特点。 2. 运用解剖学的理论与知识解决解剖学问题。 3. 揭示并剖析日常生活中隐藏的解剖学知识点。 4. 能初步分析临床病例中“隐藏的”解剖学机制。 5. 推广普及健康中国2030。 6. 能熟练在“大体老师”上识别九大系统中各器官的关键结构，为《局部解剖学》和《病理解剖学》的学习奠定扎实基础。 7. 通过“大体老师”，感恩生命，普及医学人文，坚定成为一个“有仁心、有仁术的医学领军人才”。
