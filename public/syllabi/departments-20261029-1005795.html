Python编程基础与数据分析入门

2025秋 · MSE10001.03 · 石岩松

来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

本课程基于Python语言，学习内容包括：基础语法，基础数据结构（列表、元组、字典、集合），控制流（选择、循环），函数定义与使用，字符串，文件操作，并结合管理学院的培养要求，计划学习数据分析、可视化、机器学习入门、自然语言处理和爬虫等相关的基础编程和应用。

课程简介（英文）

This course, based on the Python programming language, covers the following content: fundamental syntax; essential data structures (lists, tuples, dictionaries, sets); control flow (selection and loop structures); function definition and usage; string manipulation; file operations. Integrating with the School of Management's curricular requirements, the course also introduces foundational programming and applications in data analysis, visualization, introductory machine learning, natural language processing, and web scraping.

教学目标

本课程旨在培养学生运用Python编程解决商业场景中实际问题的系统性能力。通过理论讲解与实操训练相结合，学生将掌握： 方法论基础- 理解Python的基础语法、程序设计及代码实现全流程 数据分析技能 - 熟练运用Python进行数据获取、清洗、转换与分析，重点培养Pandas、NumPy等库的数据处理能力 可视化应用- 掌握Matplotlib/Seaborn等工具将分析结果转化为商业洞察，支持决策制定 进阶能力 - 初步应用机器学习算法处理商业数据分析的问题

教学方式

教室授课：本课程建议学生使用Jupyter Notebook作为编辑环境，教师面对面讲解，现场指导学生使用自带电脑完成简单操作和上机。

教学内容与进度安排

周次 主题 内容主题 1 Python基础 编程语言概述,安装和使用 2 自带基础数据结构（作业1） 3 上机1 4 简单程序 控制流和函数（作业2） 5 字符串和文件操作（作业3） 6 上机2 7 期中考试 8 数据分析基础 Numpy和Pandas入门 9 数据处理与分析（作业4） 10 数据可视化 11 上机3 12 人工智能入门 机器学习入门1-监督学习 13 机器学习入门2-非监督学习（作业5） 14 自然语言处理入门 15 上机4 （网络爬虫入门） 16 期末总结 课程整体回顾
