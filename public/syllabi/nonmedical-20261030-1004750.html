大数据分析与可视化

2025秋 · ATMO30013.01 · 陈国兴、张若楠

来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

本课程通过“基础知识快速入门+课堂实操+针对性指导”的教学方法，教授学生Linux常用命令使用、Python语言基础、大气与海洋科学常见数据分析和处理方法、数据可视化与解读技巧、书面和口头报告技巧等内容。

课程简介（英文）

This course teaches students the use of common Linux commands, the basics of the Python language, common data analysis and processing methods in atmospheric and oceanic sciences, techniques for data visualization and interpretation, as well as skills for written and oral presentations, through a teaching approach combining "quick foundational learning + in-class hands-on practice + targeted guidance."

教学目标

本课程旨在培养和锻炼学生的基本科研技能，帮助学生深入理解专业课程所学大气科学知识，为参与科研项目、完成毕业论文做准备。要求学生掌握以下内容： 掌握Python语言的各种变量、函数和基本语法，掌握基础绘图方法，掌握常用数据分析和处理方法，能够理解和使用NCL脚本工具。 熟悉大气与海洋科学常用数据来源、格式和读取方法。 能够利用所学专业知识对结果进行一定的理论解释。 掌握一定的书面和口头报告技巧。

教学方式

课堂讲授和随堂上机实验

教学内容与进度安排

第一章 导论（3学时） 本章简要介绍课程的教学计划安排以及课程相关的一些背景知识。 大气与海洋科学数据特点 Python语言背景知识，包括Python相对于其他语言的优势和劣势、Python的主要应用场景等 Linux服务器账户开设和简单使用 第二章 基础能力快速入门 （15学时） 本章主要教授学生Linux常用命令和技巧、Python语言基础快速入门等。要求学生了解相关工具的基础使用（不要求熟练掌握），后续章节将通过实操练习教授学生逐步熟练掌握相关工具。 Linux基础（3学时）：Linux系统简介、常用Linux命令和工具使用 Python语言基础一（3学时）：最基础的Python使用，包含变量类型、循环和流程控制、简单的文件读写等。 Python语言基础二（3学时）：常用Python程序包使用，包含numpy、scipy、netcdf4、glob、datetime等。 Python绘图基础一（3学时）：Matplotlib基础，包含折线图、柱状图、等值线图和填色图等。 Python绘图基础二（3学时）：使用Basemap和Cartopy程序包绘制具有地图投影的图形，Matplotlib文件保存，颜色使用技巧等。 第三章 数据分析与绘图实操（15学时，其中实验上机学时10学时） 本章通过5次中等难度的课堂实操训练，帮助学生逐步熟悉之前教授的绘图工具和分析方法。要求学生使用大气和海洋科学中的常用数据，有针对性地分析、绘图并撰写实验报告，帮助学生了解本学科常用数据来源和类型。任课老师每次课程会介绍一种数据类型的相关知识，并根据学生实操完成情况进行点评和针对性指导。 文本格式站点数据分析，以中国环境观测站污染物浓度数据为例（3学时） 等经纬度格点观测数据分析，以卫星数据为例（3学时） 等经纬度格点模拟数据分析，以ERA5-Interim再分析数据（3学时） 等面积格点数据分析，以WRF数据为例（3学时） 多源、多文件、有破损数据分析，以卫星数据和CMIP6数据为例（3学时） 第四章 NCL编程简要普及（6学时） 因大气和海洋科学研究中存在大量NCL语言“遗产”，本章旨在教授学生NCL语言的快速入门，帮助学生在之后的研究中能够看懂和使用前人已开发成熟的NCL代码和工具。 NCL语言基础（3学时）：NCL语言介绍；NCL基本语法和变量，包括netCDF规则、基础语法、if语句及do循环；NCL数据处理，包括文件读取方式、数据写入、NCL函数和程序 NCL绘图基础（3学时）：NCL图形分析基础，包括五步法绘图和基本绘图。 第五章 数据分析与绘图进阶（9学时，其中实验上机学时6学时） 本章要求学生在任课教师的课堂指导下，自主选题，使用第四章中的多个数据或自选数据，深入分析数据、撰写实验报告，并进行课堂口头报告。本章书面和口头报告成绩为期末成绩。 选题、数据分析、撰写书面报告、准备口头报告（6学时） 课堂报告（3学时）
