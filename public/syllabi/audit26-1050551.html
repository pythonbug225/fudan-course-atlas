课程简介（中文）

课程涵盖了评价和项目评价的基本概念，项目目标、项目理论框架设计，项目形成评价中的需求评估、健康问题界定和项目干预设计；项目执行评价中监测执行、执行评价及评价指标、参与式评价方法及其设计；在项目总结评价部分则重点强调效果评价设计、评价随机试验等；明确项目理论与项目执行理论的关系，掌握将其运用于卫生项目实施效果的归因分析。

课程简介（英文）

The course covers the basic concepts of evaluation and program evaluation, program  goals, program theoretical framework design, needs assessment, health problem definition and program intervention design in program formative evaluation; monitoring implementation, implementation evaluation and evaluation indicators, participatory evaluation methods and their design in program implementation evaluation; in the summative evaluation section, it emphasizes the design of effect evaluation, evaluation randomized trials, etc.; clarifies the relationship between program theory and program implementation theory, and masters its application in the attribution analysis of the implementation effect of health programs.

教学目标

教学通过理论讲解结合案例，以及必要的参与式教学，让学生掌握如何应用具体科学方法，如何对卫生项目怎么进行合理评价，了解怎样把有限的资源配置到最需要的地方去，配置到效果好、效率高、公平性好的社会项目中去，如何通过评价为决策者配置资源提供有利的信息支持。最终为学生走上医疗卫生实践或研究岗位，坚持通过科学运用卫生项目评价理论与方法，切实提高人们健康水平，以达到提高人类生活质量的目的。

教学方式

教师授课加课堂讨论互动，三次特定主题的PRE小组专题汇报与讨论
