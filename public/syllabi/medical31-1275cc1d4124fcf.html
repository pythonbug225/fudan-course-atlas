1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 神经精神疾病II课程将是基础医学的选修课程，将利用细胞/遗传学原理来解释精神疾病的临床表现和发病机制。尤其是神经退行性疾病和神经系统发育异常。

课程简介（英文） Course Description ( in English ) | Neuropsychiatric Disorders Ⅱ uses the cellular / genetic principles to explain the clinical appearance and pathogenesis of psychiatric disorders. especially neurodegenerative diseases and developmental anomaly of nervous system.
