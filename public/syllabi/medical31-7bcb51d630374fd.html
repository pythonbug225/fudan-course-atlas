1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 本课程是口腔医学专业的临床实践环节。学生在复旦大学附属口腔医院牙体牙髓科进行临床轮转。在带教医师指导下，课程通过门诊接诊，重点培养学生对龋病、牙髓病及根尖周病的诊断思维与治疗计划制定能力。学生将规范化练习橡皮障隔离、树脂充填、根管治疗等核心操作，并强化无菌观念、医患沟通及病历书写技能，为成为合格的口腔临床医生奠定坚实基础。

课程简介（英文） Course Description ( in English ) | This course is a clinical clerkship in Endodontics and Operative Dentistry at Shanghai Stomatological Mospital - Fudan University. Under the supervision of experienced instructors, students will rotate through the outpatient clinic. The curriculum focuses on developing diagnostic reasoning and treatment planning for dental caries, pulpal diseases, and periapical lesions. Students will perform standardized clinical procedures, including rubber dam isolation, resin restorations, and root canal therapy. Emphasis is placed on aseptic techniques, doctor-patient communication, and medical record keeping to prepare students for independent dental practice.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

知识目标 ：深入理解牙体牙髓疾病的病因、病理机制，掌握常见病及急症的鉴别诊断与治疗原则。 能力目标 ：具备独立的临床接诊能力。能规范书写门诊病历；熟练掌握窝洞制备、复合树脂充填术、橡皮障隔离术；掌握前牙、前磨牙、磨牙根管治疗的全流程操作（开髓、根备、充填）；能准确解读口内X线片及CBCT影像。 素养目标 ：树立严格的无菌观念和医疗安全意识；培养“以患者为中心”的服务理念，具备良好的人文关怀精神、医患沟通技巧及团队协作能力。

3 . 教学方式 /Teaching Methods （应体现实现教学目标所采用的具体策略、方法和组织形式）

本课程采取临床带教为主，辅以讲座和讨论的混合式教学模式： 每名带教老师负责五位学生，实行“示教-指导下的操作-独立操作”的三步走策略，手把手指导临床技能。 每周选取典型或疑难病例进行科室讨论，培养临床思维。 在接诊过程中，教师对学生的问诊、检查、操作进行实时观察与反馈。 利用空闲时间进行小讲课，更新牙体牙髓病学前沿理论。

4.教学内容及进度安排 /Course Content & Schedule （ 按照教学周编排，应包含每节课教学内容及教学目标，如有作业及考核要求，请一并列明）

周次 教学内容 (含小讲课/CBL/病例讨论) 教学目标 第1周 入科教育与基础技能 1. 入科教育：科室规章、院感流程及安全教育； 2. 小讲课：牙体牙髓科出科汇报要求与格式； 3. 小讲课：牙体牙髓科常用材料介绍； 4. 小讲课：牙体牙髓科实习期放射读片技巧。 1. 熟悉科室环境、接诊流程及无菌操作规范； 2. 明确出科考核的具体要求，开始收集病例素材； 3. 能够识别并正确选择临床常用充填及根管材料； 4. 掌握根尖片及CBCT的基本读片技能，能识别常见病变。 第2周 龋病治疗与充填技术 1. 小讲课：龋坏组织去除的专家共识导读； 2. CBL：充填治疗心得分享； 3. CBL：前磨牙二类洞充填； 4. 病例讨论：15，16牙二类洞充填（含切龈）。 1. 掌握去腐净的标准及深龋护髓原则； 2. 熟练掌握II类洞的制备要点及豆瓣成形片的使用； 3. 解决充填过程中邻面接触恢复不良、悬突等常见问题； 4. 学习切龈术在深部龋坏充填中的应用。 第3周 微创与美学修复 1. 小讲课：渗透树脂； 2. CBL：渗透树脂治疗氟斑牙前牙一例； 3. 小讲课：牙齿美白； 4. 小讲课：前牙美学修复； 5. 病例讨论：前牙美学修复病例。 1. 了解渗透树脂的适应症及操作流程； 2. 掌握牙齿美白的适应症、操作步骤及并发症处理； 3. 培养前牙美学分析能力； 4. 掌握美学树脂的分层堆塑与抛光技巧。 第4周 根管治疗基础规范 1. 小讲课：根管治疗之如何开髓； 2. 小讲课：根管预备的相关步骤及器械使用说明； 3. 小讲课：根管充填的步骤讲解及器械使用说明； 4. CBL：右下前磨牙根管治疗。 1. 熟练掌握不同牙位的髓腔解剖特点及开髓揭顶技巧； 2. 规范使用机用镍钛器械进行根管预备，建立直线通路； 3. 掌握热牙胶充填技术； 4. 能够通过X线片评价根管充填质量。 第5周 复杂根管与失败分析 1. 小讲课：C型根管的分类及治疗； 2. CBL：右下磨牙根管治疗（含MM根管）； 3. 小讲课：根管治疗失败的原因； 4. 小讲课：根管治疗失败原因探讨。 1. 识别C型根管系统并制定相应治疗策略； 2. 提高寻找细小钙化根管（如MB2、近中MM根管）的能力； 3. 能够分析根管治疗失败的常见原因（如微渗漏、遗漏根管、根尖周持续感染等）。 第6周 活髓保存与再生医学 1. 病例讨论：一例16牙慢性牙髓炎活髓保存治疗； 2. 病例讨论：活髓保存技术在牙体牙髓科中的应用； 3. 小讲课：牙髓再生治疗； 4. 病例讨论：牙髓再生治疗的病例； 5. 学术讲座：牙干细胞与口腔颅面组织再生。 1. 掌握直接/间接盖髓术及活髓切断术的适应症与操作； 2. 理解牙髓血运重建（再生）的生物学原理； 3. 掌握年轻恒牙牙髓坏死的再生治疗操作步骤； 4. 了解干细胞及组织工程在口腔领域的最新科研进展。 第7周 根尖周病变与再治疗 1. 小讲课：根尖屏障术； 2. 病例讨论：根尖屏障病例； 3. CBL：牙内吸收； 4. 病例讨论：一例25牙慢性根尖周炎合并根外吸收的显微镜下的根管治疗；5. 小讲课：根管再治疗。 1. 掌握根尖敞开牙齿的根尖屏障术； 2. 鉴别牙内吸收与牙外吸收，并制定相应的治疗计划； 3. 掌握显微镜下根管再治疗中去除旧充填物的技巧； 4. 理解难治性根尖周炎的处理原则。 第8周 鉴别诊断与综合回顾 1. CBL：伴根纵折的慢性根尖周炎； 2. CBL：瘘管是否等于慢性根尖周炎？ 3. 病例讨论：1例21、22牙根尖囊肿多学科联合病例讨论； 4. 小讲课：牙体牙髓科常见并发症及其预防措施。 5.出科病例汇报 1. 掌握牙根纵折的诊断及临床表现； 2. 具备牙髓牙周联合病变、非牙源性瘘管及根尖囊肿的鉴别诊断能力； 3. 培养多学科联合诊疗（MDT）思维； 4. 总结实习经验，完成出科汇报。
