1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 本课程为基于基础、临床、人文医学各学科整合式病例进行的研讨型课程，学生8-9人一个小组进行学习。每个病例通过三次讨论课（6学时）、一次线上文献学习（2学时）和一次总结课（2学时）来完成，每个学期学习3个病例。

课程简介（英文） Course Description ( in English ) | The course mainly involves diseases of different systems, which are composed of 3 cases. Each case is arranged for three tutorials and one case wrap-up. Each case is composed of discussion and self-learning for 9 academic hours and case wrap-up for 2 academic hours. Meanwhile, the students are provided adequate time to search materials, deduce and prepare for discussion. Small group discussion (8-9 students) is adopted.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

通过PBL教学，激发学生自主学习动机和效果，提高学习兴趣；培养学生思维能力、自学能力和创造能力；案例不仅考虑专业性，还兼顾社会性和时代性，在专业教育中融入人文关怀、医患沟通、医学伦理、医疗改革、职业道德等方面元素，使学生对医疗职业的道义与责任有清晰的认识，理解医学是人的科学，探究医学的本质，感悟精湛医术与人文关怀完美统一的重要性，提高人际交往及协作能力；真正树立起终身学习的习惯和方法。培养临床医学专业学生早期接触临床，激发医学学习兴趣，早期培养临床思维。
