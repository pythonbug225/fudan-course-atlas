课程简介（中文）

本课程主要讲解监督式学习(supervised learning)，并简略的讨论一些无监督学习(unsupervised learning)方法。 监督式学习内容包括：线性和多项式回归， logistic回归和线性判别分析；交叉验证和重采样方法，模型选择和规则化（ridge regression 和 lasso）；非线性方法，splines 和GAM; tree based methods － 决策树，随机森林，boosting； 支持向量机。 无监督学习内容包括：主成分分析 和聚类分析。

课程简介（英文）

This is an advanced statistical learning course, with a focus on regression and classi cation methods. Potential topics include: linear models for regression and classi cation, basis expansion and regularization, model assessment and selection, kernel methods, resampling methods, tree based methods and boosting, support vector machine, nearest neighbour, hidden markov models. Some unsupervised learning methods are briefly discussed. This is not a math-heavy course, so I'll try to describe the methods without heavy reliance on formulas and complex mathematics. We focus on what we consider to be the important elements of modern statistical learning.

教学目标

这是一门统计学习的高阶课程，课程的目的在于使学生熟悉并掌握统计学习的基本方法极其涉及的理论知识。该课程侧重于对理论知识的理解，同时结合实践项目，培养学生利用统计学原理解决实际大数据问题的能力。本课程的设计目的是让学生全面掌握当前统计学习领域使用的方法论以及每个方法的优缺点和适用范围，从而引导学生探索新的研究课题。

教学方式

课堂以主讲教师讲授为主（80%），学生可以自由提出问题，自由发表对解决问题的观点 。学期中学生将分组，每组将自选涉及近期学习方法论的期刊论文并上讲台讲解 。所选论文可以是本领域的著名标志性论作，也可以是应用型文章 （20%）。教学助理将有office hour讲解课程的相关问题；学期末学生会有一个final project；本课程不设置期末随堂考试。
