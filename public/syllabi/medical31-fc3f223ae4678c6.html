1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 课程名称：仪器分析导论 课程性质：专业选修 选课对象：预防医学专业本科生 课程学分：2 学时：2 授课校区：枫林 授课内容：介绍卫生化学光谱分析、色谱分析、质谱分析、电化学分析等方法中常用仪器的原理、构造、应用。

课程简介（英文） Course Description ( in English ) | Course Title: Introduction to Instrumental Analysis Course Type: Professional Elective Target Students: Undergraduate Students in Preventive Medicine Credits: 2 Credit Hours: 2 Campus: Fenglin Course Content: An introduction to the principles, structures, and applications of commonly used instruments in sanitary chemical analysis, including spectroscopic analysis, chromatographic analysis, mass spectrometry, and electrochemical analysis.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

分析化学是关于研究物质的组成、含量、结构和形态等化学信息的分析方法及理论的一门科学，是化学的一个重要分支，分析化学使用的仪器是完成研究工作的重要基石。随着分析仪器的不断迭代发展，各种新型仪器不断涌现，为公共卫生领域的定性、定量分析工作提供了重要支撑。了解各类仪器的工作原理及使用方法，对开展公共卫生实践具有重要意义。
