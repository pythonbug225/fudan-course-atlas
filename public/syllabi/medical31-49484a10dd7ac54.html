1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 《药学专业英语》是面向药学专业本科生开设的专业选修课程，主要介绍药学专业词汇、学术演讲技巧、专业英语书写与阅读等，拟在课程学习过程中，帮助学生掌握学习药学专业英语的技巧。

课程简介（英文） Course Description ( in English ) | This is a professional elective course designed for undergraduate students majoring in pharmacy. It mainly introduces pharmaceutical vocabulary, academic presentation skills, pharmaceutical reading and writing, etc. During the course learning process, it aims to help students master the skills of learning pharmaceutical professional English.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

经过本课程的训练，希望学生能够做到以下几点： 熟悉和掌握一定数量的药学相关专业词汇; 能够较为流畅阅读和正确理解药学方面的原版书籍及英文文献; 能够掌握英语演讲的技巧并勤加练习; 掌握药学类学术英语常用的写作方法和技巧;

3 . 教学方式 /Teaching Methods （应体现实现教学目标所采用的具体策略、方法和组织形式）

1.课内安排翻译训练、presentation训练等练习环节； 2.课外完成超星学习内容，了解药学行业发展等相关内容； 3.课后完成翻译、写作等作业，做好个人presentation的准备工作。
