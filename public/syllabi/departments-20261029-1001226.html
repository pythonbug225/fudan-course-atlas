课程简介（中文）

运筹学是一门研究如何有效地组织和管理人机系统的科学。它研究解决实际问题时的系统优化思想，从提出问题、分析建模、求解到方案实施的一整套严密科学方法，在培养提高管理人才素质上起到重要作用。内容包括线性规划、整数规划、动态规划、网络规划、决策论、排队论、非线性规划和其他数学规划理论和算法。

课程简介（英文）

In this course, we will discuss basic concepts and methodologies of Operations Research.  Special attention will be paid to the use of scientific approaches to management and industrial problems. An Excel based optimization software package will be introduced.  We will present algorithms and theory for linear programming, integer programming, dynamic programming, network programming, game theory, queuing theory, non-linear programming and other mathematical programming.

教学目标

掌握运筹学的基本原理和方法； 掌握基本软件（如Excel Solver、Lingo、Matlab、Python Gurobi和Crystal ball等）的使用； 掌握运筹学的基本工作方法，学会对一些基本的实际管理问题的建模和求解。

教学方式

课堂讲授：基本理论和算法 课堂讨论: 实际建模问题 家庭作业：掌握实际计算、建模能力 软件使用：用运筹学软件解决实际问题 案例分析：运筹学相关案例深入分析
