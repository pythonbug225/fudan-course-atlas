自动控制原理

2025秋 · AAST30014.01 · 艾剑良

来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

1. 自动控制系统的基本概念 2. 经典控制系统设计与分析的基本方法：时域分析法、根轨迹法、频率特性法 3. 控制系统校正的基本原理 4. 现代飞行控制系统的基本原理、 5. 自动控制理论在现代飞行控制系统设计与分析中的应用

课程简介（英文）

1. Basic concepts of automatic control systems 2. Basic methods of classical control system design and analysis: time-domain analysis, root locus method, frequency response method 3. Basic principles of control system compensation 4. Basic principles of modern flight control systems 5. Application of automatic control theory in the design and analysis of modern flight control systems

教学目标

自控原理的教学目标主要有以下几方面： 知识目标上，要让学生掌握自动控制的基本概念、原理，如反馈控制原理等，熟悉常用控制系统的数学模型构建与分析方法。 能力目标方面，培养学生能够运用所学知识对简单控制系统进行分析、设计与计算，如能准确绘制根轨迹、计算稳定性等，提升解决实际自动控制问题的能力。 素质目标则是培养学生严谨的科学思维、工程实践素养以及对自动控制技术的持续学习与探索精神。

教学方式

课堂讲授

教学内容与进度安排

第一周 绪论；制系统的基本概念及一般控制系统组成、工作原理。 第二周 控制系统的一般要求；控制系统性能指标； 控制系统建模的基本原理；传递函数的基本概念。 第三周 控制系统结构图及等效变换；信号流图及梅逊公式。 第四周 反馈系统的传递函数、干扰作用下系统的传递函数；系统稳态误差的基本概念。 第五周 求稳态误差的基本原理。 第六周 系统稳定的基本概念；统稳定性判据——Routh判据。 第七周 时域分析方法的基本原理；脉冲响应函数。 第八周 控制系统的典型环节；惯性环节的时间响应（脉冲、单位阶跃、斜波响应）。 第九周 二阶系统的分类；阻尼二阶系统的时间响应；阻尼二阶系统性能指标的估算。 第十周 过阻尼二阶系统的时间响应及性能指标的估算；善系统的基本方法。 第十一周 根轨迹的基本原理；开环零极点与闭环零极点的关系；根轨迹方程。 第十二周 根轨迹绘制的基本规则（Ⅰ）。 第十三周 根轨迹绘制的基本规则（Ⅱ）；根迹分析。 频率特性的基本概念；典型环节的频率特性（Ⅰ）。 第十四周 典型环节的频率特性（II）；开环频率特性；耐奎斯特稳定性判据。 闭环频率特性及其与开环频率特性的关系；频率特性与系统性能指标的关系。 第十五周 阻尼飞行控制系统、增稳控制系统、控制增稳系统的组成及基本原理。 第十六周 典型飞行控制系统的设计原理及分析方法。 第十七、十八周 复习、答疑、期末考试
