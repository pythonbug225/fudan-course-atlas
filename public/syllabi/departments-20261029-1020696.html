数据结构与算法导论

课程简介（中文）

本课程将在回顾Python语言基本编程规范和内置数据结构的基础上，对于数据结构和算法的基础知识进行系统介绍。主要内容知识点包括算法复杂度分析、递归、数组、链表、栈、队列、树、优先级队列、堆、哈希表、搜索树、排序算法、图与图算法、模式匹配、贪心算法、动态规划等。学生通过听课、练习、日常作业等形式进行学习。课程包括期末考试。

课程简介（英文）

This course builds on a review of Python programming fundamentals and built-in data structures to provide a systematic introduction to the core concepts of data structures and algorithms. Major topics include algorithmic complexity analysis, recursion, arrays, linked lists, stacks, queues, trees, priority queues, heaps, hash tables, search trees, sorting algorithms, graphs and graph algorithms, pattern matching, greedy algorithms, and dynamic programming. Students will learn through lectures, exercises, and regular assignments. The course includes a final examination.

教学目标

本课程开设的目的为让学生在对Python程序设计有一定了解及掌握的基础上进一步学习数据结构和算法的基础知识。具体目标为： 1. 了解如何对常见数据结构进行查询、插入、删除、排序等处理； 2. 了解常见数据结构上的常用算法； 3. 具备一定的根据实际问题选择合理数据结构并编写合适的算法来解决的能力。

教学方式

课堂讲授。学生应自带电脑，有必要时在课堂上跟随老师进行代码实操练习。
