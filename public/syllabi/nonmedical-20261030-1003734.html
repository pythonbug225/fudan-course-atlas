金融数据科学和编程

来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

本课程介绍数据科学技术，以利用金融数据做出稳健的财务决策或解答金融领域的问题。它融合了多个领域（金融、经济学和统计学）的工具。完成课程后，学生将具备对金融数据科学工具的实操熟悉度、金融数据处理与统计编程的熟练能力，并希望学生能深刻理解如何运用计量经济学工具和金融数据来制定决策或提出恰当的问题，以及如何以最佳方式实现这一目标。

课程简介（英文）

This course introduces data science techniques to harness financial data for making sound financial decisions or answering questions of financial interests. It combines tools used in a variety of fields (finance, economics and statistics). Students will finish the course equipped with a workman’s familiarity with the tools of financial data science, facility with financial data handling and statistical programming, and—hopefully—a good understanding of what decisions you want to make, or what questions you want to ask and how best to do it with econometric tools and financial data.

教学目标

This course aims for students to understand and critically discuss: 1) Data science methods for finance 2)Computational/algorithmic implementations of methods in programming languages 3) Key applications in finance Students will understand not only how methods work in theory but will also replicate and extend empirical applications by working with data by themselves.

教学方式

Off-line multimedia teaching and case study

教学内容与进度安排

1st Week: Introduction and Python fundamentals 1 2nd Week: Some basic tools for quantifying risk and Python fundamentals 2 3rd Week: Predicting the market: historical mean model 4th Week: Predicting the market: autoregressive models and Python fundamentals 3 5th Week: Models with stationary variables 6th Week: Models with stationary variables more and Python fundamentals 4 7th Week: Predicting the market: Predictive regression 8th Week: Predictive regression more and Python fundamentals 5 9th Week: Time varying volatility and risk management 10th Week: Volatility models and Numpy 11th Week: MLE and Value-at-Risk (VaR) 12th Week: Beta-Risk Model and Pandas 13th Week: Fama-French Factor Models 14th Week: Panel regression 15th Week: Event study analysis and Matplotlib 16th Week: Event study analysis more and review
