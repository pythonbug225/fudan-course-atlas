课程简介（中文）

本课程主要包括复杂指令集的设计、CPU的架构、时序电路、流水线的组织方式与特点、存储架构机制、Cache机制、机器相关与机器无关的程序的优化方法、虚拟存储机制、系统I/O和网络编程。

课程简介（英文）

This course introduces necessary hardware to run program, how to manage memory and optimize program with underlying hardware, and the mechanisms to interactive with other programs, including CPU instruction set architecture of complex instruction set computer, combinatoric and sequential circuits, single cycle processor the principle of pipelined processor, memory hierarchy, principles of cache, virtual memory management, file and system I/O, and network programming.

教学目标

计算机系统基础使学生了解支撑应用软件运行的计算机系统的概况。了解处理器和存储等硬件的基本工作原理，掌握虚拟内存管理和计算机网络的工作机制，并运用这些概念解决实际问题。该课程帮助学生建立计算机系统的整体概念，对相关概念的了解为后续计算机系统类课程开设打下基础。

教学方式

线下授课+上机实验+课后Lab。
