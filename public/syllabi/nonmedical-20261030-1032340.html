课程简介（中文）

计算机在社会经济统计中的应用是一门实践性很强的课程，本课程着重介绍STATA的基本操作、常见的统计模型和数据分析。

课程简介（英文）

Applied Computerized Statistics is a practice-oriented course. This course focuses on teaching basic operations, common statistical models, and data analysis using STATA.

教学目标

通过本课程的学习，学生能够熟练掌握数据管理、数据分析的基本概念、数据模型、分析流程，学会并熟练运用常见的统计软件，能够在未来的学术研究或职业发展中将丰富的数据资源转化为可理解的信息，为科学研究和职业发展打下坚实的基础。

教学方式

课堂讲授与上机实习操作相结合
