数据挖掘与机器学习

2025秋 · MAS60006.01 · 刘彬

来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

本课程将涵盖现代数据挖掘和机器学习的基本原理和技术，包括有监督学习技术(如分类和预测)和无监督学习技术(如寻找数据模式、降维、聚类)。本课程将展示一些具体的商业实际案例，同时学生也将有机会学习R 或者python并将其应用到案例中。更具体地说，本课程包含以下主题: 机器学习的基本概念; 监督学习技术(回归和分类方法); 无监督学习技术(发现数据模式、降维、聚类和关联规则); R或者Python中的机器学习软件包

课程简介（英文）

This course will cover the fundamental principles and techniques of modern data mining and machine learning, including supervised learning techniques (such as classification and prediction) and unsupervised learning techniques (such as pattern discovery, dimensionality reduction, and clustering). The course will present practical business cases, and students will have the opportunity to learn and apply either R or Python to these cases. Specifically, the course will include the following topics: Basic concepts of machine learning; Supervised learning techniques (regression and classification methods); Unsupervised learning techniques (pattern discovery, dimensionality reduction, clustering, and association rules); Machine learning packages in R or Python.

教学目标

本课程旨在帮助学生深入理解常用的机器学习技术及其背后的基本思想和算法原理，掌握至少一种主流机器学习软件包（如R或Python中的相应工具），并能够将所学技术灵活应用于现实商业问题的建模与分析中。通过理论讲解与实际案例相结合的方式，课程将系统培养学生的问题建模、算法选择、模型评估与结果解释能力，增强其在数据驱动决策中的实战应用水平。

教学方式

本课程将采用理论讲授与实践操作相结合的教学方式。课堂上将通过案例驱动的方式讲解机器学习的核心概念与算法原理，帮助学生建立系统的知识体系。课程将安排编程实操环节，指导学生使用R或Python实现典型算法，并应用于真实或模拟的商业数据集。此外，还将组织小组项目，鼓励学生围绕实际业务问题，选择合适的模型进行数据分析与建模，提升综合应用能力。通过课上讨论、作业练习与项目实践，培养学生的逻辑思维与数据分析能力。

教学内容与进度安排

第1周  教学内容：机器学习基本原理介绍 预期效果： （1）了解机器学习基本思想和原理 （2）理解有监督学习以及无监督学习和其他机器学习方法的本质区别     能够正确区分在不同场合下应该使用什么机器学习方法 第2周  教学内容：线性回归模型 预期效果：掌握线性回归模型的基本原理和最小二乘估计；同时掌握子集选择和几种压缩估计方法     给定实际数据，能够使用线性回归模型进行预测和解释 第3周  教学内容：模型评估与选择 预期效果：掌握经验误差与过拟合、常见评估方法、性能度量、偏差与方差等常见概念     给定线性回归模型，从偏差与方差分解等角度进行解释 第4周  教学内容：贝叶斯方法 教学目标：掌握贝叶斯决策理论、朴素贝叶斯分类器以及半朴素贝叶斯分类器     给定实际数据，能够使用贝叶斯方法进行分类 第5周  教学内容：决策树与随机森林 教学目标：掌握决策树基本原理、学会构建回归树、分类树；学会使用随机森林并实现随机森林算法     给定实际数据，使用决策树与随机森林算法进行预测和分析 第6周  教学内容：支撑向量机 教学目标：掌握支撑向量机的基本原理以及支持向量机和核技术方法     给定实际数据，使用支撑向量机进行预测和分析 第7周  教学内容：提升方法 教学目标：掌握提升方法基本想法、理解AdaBoost 算法和提升树模型     给定实际数据，使用AdaBoost算法进行预测和分析 第8周  教学内容：梯度提升算法 教学目标：理解和掌握GBDT、XGBoost以及LightGBM的基本原理   给定实际数据，使用常见的梯度提升方法进行预测和分析 第9周  教学内容：无监督学习I (聚类分析) 教学目标：(9.1) 聚类分析简介 (9.2) K-means算法与高斯混合模型 (9.3) 层次聚类分析 理解聚类的基本概念以及各种聚类算法之间的差异。掌握在实际数据集上应用K-means和高斯混合模型的技能，并根据数据特性判断适用的模型 第10周 教学内容：数据降维 教学目标：(10.1) 主成分分析（PCA） (10.2) 流形学习：曲线和曲面 (10.3) 探索性因子分析（EFA）理解如何使用PCA进行数据降维以及如何解释结果。通过流形学习了解非线性降维技术，并知道何时应用它们。学习进行探索性因子分析以揭示数据中的潜在因素，并区分可观测变量和潜在结构 第11周 教学内容：异常检测 教学目标：(11.1) 异常检测简介 (11.2) 统计异常检测技术 (11.3) 基于机器学习的异常检测 理解异常检测的基本原则和异常类型。学习实施传统的统计方法和机器学习方法来检测数据中的异常 第12周 教学内容：推荐系统 教学目标：(12.1) 协同过滤 (12.2) 基于内容的推荐 (12.3) 其他推荐方法概述 理解协同过滤的核心机制，并能够实施基本的基于用户和基于项目的方法。掌握设计和部署基于内容的推荐系统，并了解如何处理特征表示。 第13周 教学内容：小组报告1 教学目标：小组报告的目标是将课程第一部分学到的概念应用于具体实际问题。这包括选择一个合适的数据集，提出一个相关的分析问题，选择合适的分析技术，并给出一份综合报告。    每个小组选择一个与他们的兴趣或学科专业相关的数据集。 具体明确一个实际问题。清理数据、分析数据以及解释结果。 第14周 教学内容：小组报告II以及课程总结 教学目标：(14.1)小组报告展示。（14.2）课程总结   同13.
