来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

C语言的基本语法和基本结构，程序设计的基本原理和基本算法，C编程平台的使用和调试方法。

课程简介（英文）

The basic syntax and basic structure of C language, the basic principles and basic algorithms of programming, and the use and debugging methods of C programming platform.

教学目标

该课程面向大一新生，以C语言为载体，通过程序设计实践，培养学生的计算思维与问题解决能力。通过学习C语言的基础语法、数据结构、算法设计等内容，学生将掌握分析问题并使用编程技术进行解决的方法。课程注重计算思维的培养，帮助学生学会抽象化问题、分解复杂问题、识别模式，并设计高效的算法来实现解决方案。同时，通过实践编写小型程序，学生将提升实际编程能力，并逐步掌握如何面对更大、更复杂的编程任务。

教学方式

面授和上机辅导

教学内容与进度安排

第1周：课程简介，计算机基本原理，简单例子和编程环介绍 第2周：C语言基本数据类型和输入输出基础 第3周：C语言基本运算和表达式 第4周：基本语句和选择结构 第5周：循环结构 第6周：一维数组 第7周：多维数组和字符串 第8周：函数和库函数基础 第9周： 期中考试 第10周：指针基础 第11周：数组高级和指针行参 第12周：结构和链表 第13周：存储类别和作用域 第14周：文件处理技术 第15周：指针高级和联合位域枚举 第16周：例题选讲和期末复习 17-18考试周：答疑，期末考试
