半导体存储器

课程简介（中文）

系统讲授主流半导体存储器关键技术和经典应用场景，介绍各项技术的最新进展及发展趋 势； 分析电路、测试、系统、器件、制造、封装、应用场景和通用标准之间的相互影响，阐明多因素之间如何相互妥协、平衡与共优化，从而形成存储器技术及其应用生态 ( ecosystem），分析当前的主流技术之所以能够在与其他各类技术的激烈竞争中胜出的来 龙去脉和决定因素。涉及先进的主流存储器SRAM、DRAM、FLASH以及主流嵌入式非易失存 储器，应用场景涉及嵌入式应用、计算机体系机构中的存储架构应用、低功耗应用、高性 能应用。

课程简介（英文）

Systematically teach the key technologies of mainstream semiconductor memories and classic application scenarios, introduce the latest progress and development trends of various technologies; analyze the mutual influences among circuits, testing, systems, devices, manufacturing, packaging, application scenarios and general standards, clarify how multiple factors compromise, balance and co-optimize with each other, so as to form the memory technology and its application ecosystem. Analyze the determining factors of why the current mainstream technologies can win in the fierce competition with other various technologies. It involves advanced mainstream memories such as SRAM, DRAM, FLASH, and mainstream embedded non-volatile memories. The application scenarios include embedded applications, storage architecture applications in computer architecture, low-power applications, and high-performance applications.

教学目标

通过“课程简介 ”中所述内容的讲授，针对半导体存储器领域，从原理性能、应用市场两个方面，从时间（演进）、空 间（不同技术的竞争）两个维度，从用户和技术产品提供者两个角度，从宏观到重要的局部，知其然和所以然，了解分析思路和方法，理解各个要素的平衡妥协以及不得不遵守的判断标准和所以如此的来龙去脉，从而理解整个存储器工业和关键技术的有机生态(ecosystem)，知晓当前现状的由来，了解发展瓶颈和趋势，并学习课程中展示的分析方法，并在形成课程研究报告时加以实践。

教学方式

课堂教学，答疑，批改报告
