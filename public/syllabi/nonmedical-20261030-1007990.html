Big Data Financial Analytics

来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

This course is designed for master students who are interested in big data analytical tools and their applications in financial analytics. The course covers key concepts and techniques related to working with financial big data.

课程简介（英文）

This course is designed for master students who are interested in big data analytical tools and their applications in financial analytics. The course covers key concepts and techniques related to working with financial big data.

教学目标

This course aims to equip master students with the knowledge and skills necessary to effectively analyze financial data using big data analytical tools. Students will develop an understanding of key concepts and principles in big data analytics, gain proficiency in using tools such as R or Python to analyze financial data, select appropriate tools for different types of financial data, interpret results, handle and transform data using Python, develop and deploy big data models for forecasting, risk management, and explore emerging trends in big data financial analytics. By the end of the course, students should have a solid foundation in big data analysis techniques and be able to use these tools to solve complex financial problems.

教学方式

The course begins by introducing students to the principles of big data analytics, including different types of data, data structures, and data management systems. Students will then learn how to use various big data tools to conduct exploratory data analysis, build predictive models, and extract insights from financial data. Throughout the course, students will work on hands-on projects that involve analyzing real-world financial data using big data tools and techniques. These projects will help students develop their analytical and problem-solving skills, as well as their ability to use big data tools to make sense of complex financial information. In addition to learning how to use big data tools, students will also learn how to interpret the results of their analyses in a rigorous and meaningful way. They will learn how to assess the reliability and validity of their findings, and how to communicate their results effectively to stakeholders.
