课程简介（中文）

经典和现代非参数统计方法的特点与方法简介； 基于顺序统计量的各类假设检验，拟合优度检验，单样本，双样本问题，非参数密度估计, 非参数回归，wavelets 导论, minimax理论。此课程对数学要求较高，建议同学有扎实的微积分，线性代数和数理统计基础。部分作业涉及模拟实验，建议同学掌握R，matlab，python或其他主流编程语言的一种。

课程简介（英文）

Introduction to classical and modern nonparametric statistical methods and their key features; hypothesis tests based on order statistics, goodness-of-fit tests, one-sample and two-sample problems, nonparametric density estimation, nonparametric regression, an introduction to wavelets, and minimax theory. This course is mathematically demanding; students are expected to have a solid foundation in calculus, linear algebra, and mathematical statistics. Some assignments will involve simulation experiments, so proficiency in at least one mainstream programming language—such as R, MATLAB, or Python—is strongly recommended.

教学目标

By the end of this course, students should be able to: Understand the theoretical foundations and practical applications of classical and modern nonparametric statistical methods. Formulate and conduct nonparametric hypothesis tests for one-sample, two-sample, and multi-sample problems, including tests based on ranks, order statistics, and empirical processes. Apply nonparametric techniques for density estimation and regression, including kernel methods, local polynomial smoothing, and wavelet-based approaches. Interpret and evaluate estimation procedures through the lens of asymptotic theory, minimax optimality. Implement nonparametric methods using statistical software (e.g., R, Python, or MATLAB) to analyze real-world data and conduct simulation studies. Appreciate the connections between nonparametric inference, function estimation, and modern statistical learning theory.

教学方式

Lecture

教学内容与进度安排

1. Empirical Distribution and Order Statistics    Introduction to empirical distribution functions; order statistics and their properties; asymptotic distributions and moments of order statistics. 2. Tests for Randomness and Goodness-of-Fit    Chi-squared goodness-of-fit test; Kolmogorov–Smirnov one-sample test; Lilliefors test for normality. 3. Inference for Quantiles    Confidence intervals and hypothesis tests for quantiles; sign test and median test; rank-order statistics; Wilcoxon signed-rank test. 4. Two-Sample Nonparametric Tests (I)    Wald–Wolfowitz runs test; Kolmogorov–Smirnov two-sample test; median test; Mann–Whitney U test (Wilcoxon rank-sum test). 5. Two-Sample Nonparametric Tests (II) and k-Sample Problems    Linear rank statistics; linear rank tests for location and scale alternatives; extension to multiple independent samples (e.g., Kruskal–Wallis test). 6. Nonparametric Tests for Association    Two-sample tests for dependence (e.g., Spearman’s rank correlation, Kendall’s tau); extension to multiple samples. 7. Midterm Exam 8. Nonparametric Delta Method and e-values    Delta method in nonparametric settings; introduction to e-values. 9. Nonparametric Density Estimation    Kernel density estimation; bandwidth selection; bias–variance tradeoff; smoothing techniques. 10. Nonparametric Regression I     Brief review of linear and logistic regression; kernel regression estimator; local polynomial regression. 11. Nonparametric Regression II     Variance estimation; construction of confidence intervals; extension to multiple nonparametric regression. 12. The Normal Means Problem and Shrinkage Estimation     Introduction to the normal means model; Pinsker’s theorem; James–Stein estimator and Stein’s paradox. 13. Applications of the Normal Means Problem in Nonparametric Regression     Connection between sequence-space models and regression; role of shrinkage in function estimation. 14. Wavelets and Fourier Analysis     Introduction to Fourier transforms; basics of wavelet systems; comparison of time–frequency representations. 15. Wavelets in Nonparametric Regression     Wavelet thresholding; adaptive estimation; spatial adaptivity and function denoising. 16. Minimax Theory in Nonparametric Estimation     Minimax risk; lower and upper bounds; role of smoothness classes (e.g., Sobolev, Hölder); optimality. 17–18. Final Exam Week
