Perl语言入门和提高

2026春 · ICSE20002.01 · 周晓方

来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

教授Perl编程的基础内容，包括标量、数组、列表、散列、内置函数、自定义函数、文件访问、程序结构等，教授Perl编程的进阶内容，包括常用模块的使用，高阶编程技巧、模块和面向对象的编程、编写Perl模块等。

课程简介（英文）

In this one semester course, you will learn the basics of Perl programming languages, including scalar, array, list, hash, build-in functions, user-defined functions, file accesssing, program syntax etc. You will also learn the advanced techneques, including cpan moduels, high-order programming, object-oriented programming and learn to write your own modules.

教学目标

“Perl语言入门和提高(含Perl高级编程专题)”，前9周学习Perl基本知识和技巧，后6周学习常用的Perl模块。学生通过一学期的课程和练习，掌握Perl语言并学会综合运用Perl模块编写较完整和复杂的程序。

教学方式

修学本课程的学生要熟悉C语言、Unix/Linux入门等计算机方面的基础知识。 上课以教师讲课为主，有10次以上的课后作业题。历年试题将发给选课同学参考。 期末总评包括平时成绩和期末成绩两部分，其中平时成绩占30%，含课堂签到和作业等情况。 期末成绩占70%，以编程题为主。 期末考核方式：开卷。 不指定教材。

教学内容与进度安排

第一周 Perl标量、数组、undef、上下文以及相关函数 第二周 运算符、hash表、Perl的正则表达式扩展 第三周 正则表达式(续)、相关的函数及实例 第四周 语句、软件控制结构、子程序、程序框架； ---前四周教学成效：学会用Perl编写简单的软件 第五周 匿名函数、函数引用、高阶编程 第六周 文本文件和二进制文件操作、内部函数、特殊变量 第七周 Perl引用、Perl模块，CPAN 第八周 Perl程序调试方法，Profile（性能瓶颈）、Coverage（覆盖率）相关模块 ---四周教学成效：学会Perl特有的高阶表达方式，使用模块，调试软件的方法 第九周 Perl网络编程和模块、Perl win32相关的模块、PDF模块 第十周 Perl Tk，消息驱动的GUI图形界面程序设计方法 第十一周 Perl CGI，运行在http服务器后端的perl程序如何与远端浏览器互动 第十二周 面向对象的Perl：类和对象，构造和析构，set/get 第十三周 面向对象的Perl(续)：继承和多重继承，虚函数，多种实例 第十四周 Perl模块选讲，h2xs、Makefile和CPAN模块 ---后六周教学成效：学会用各种CPAN模块充实软件功能、提高编程起点 第十五周 复习和答疑 第十六周 考试、第十七周 阅卷、第十八周 完成登分 （本学期每星期四上午上课，若遇国定假日冲突，按通知调整，恕不另行上传大纲）
