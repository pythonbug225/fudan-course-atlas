来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

《计算机原理》是复旦大学大数据学院本科的基础课程。随着信息技术的高速发展并迅速渗透到社会生活的各个方面,计算机日益成为人们学习,工作,生活不可缺少的基本工具。而在大数据方向的后续课程和实践中，对海量数据的处理往往需要对计算机原理的了解才能实现高效、稳定、安全的数据处理。因此，学习并掌握计算机原理和运行机制可以为学习本专业后续课程打好基础。

课程简介（英文）

Computer Principles is a foundational undergraduate course in Fudan University's School of Data Science. As information technology rapidly develops and permeates all aspects of society, computers have become essential tools for learning, work, and daily life. Understanding computer principles is crucial for efficient, stable, and secure big data processing in subsequent courses and practices. This course covers fundamental principles of computer hardware, internal information representation, program execution flow, debuggers, data storage, networking, and concurrent programming. It also introduces effective practices for performance optimization, overflow protection, and parallel execution in big data programming.

教学目标

结合复旦大学建设和大数据学院人才培养定位，本课程旨在培养学生正确的学习态度和解决问题的思维方法，学习并掌握计算机硬件、内部信息表示、程序执行流、调试器、数据存储、网络、并发编程等相关计算机基础知识，具备分析解决复杂计算问题的能力，能基于这些知识进行高质量的大数据处理编程和调试，为后续专业课程学习和实践应用奠定坚实基础。

教学方式

采用理论与实践相结合的教学策略，通过课堂讲授、编程实验、调试演示和项目实践等组织形式，系统性地引导学生从基础概念到大数据处理实际应用的能力提升。

教学内容与进度安排

教学内容安排 （具体到每节课内容）： 1.    计算机基本组成简介 o    计算机硬件的五大组成部分：输入设备、输出设备、中央处理器（CPU）、存储器和控制器。 o    计算机硬件的基本工作原理和功能。 o    主板、处理器、内存、存储设备、外围设备的介绍。 2.    计算机内部信息表示1 o    二进制数的概念和重要性。 o    整数的二进制表示方法，包括无符号和有符号整数。 o    位（bit）和字节（byte）的基本概念。 3.    计算机内部信息表示2 o    浮点数的二进制表示方法。 o    字符和字符串的编码方式，如ASCII和Unicode。 o    存储单位的扩展，包括千字节（KB）、兆字节（MB）等。 4.    计算机程序执行原理1 o    程序的编译过程和编译器的作用。 o    指令集架构的基础知识。 o    程序的加载和执行流程。 5.    计算机程序执行原理2 o    CPU的工作原理和组成部分。 o    指令周期和指令的执行过程。 o    CPU流水线技术的概念和优势。 6.    程序调试 o    调试器的基本使用方法，包括断点、单步执行和变量观察。 o    常见的程序错误类型和调试技巧。 o    使用调试工具进行性能分析和内存泄漏检测。 7.    程序调试上机 o    实际操作熟悉汇编代码和反编译过程。 o    实际操作调试过程。 8.    大数据处理的性能优化 o    性能优化的基本原则和常用技术。 o    大数据处理中的并行计算和分布式计算。 o    数据库和存储系统的性能优化策略。 9.    存储基本原理1 o    计算机存储层次结构的概述。 o    寄存器和缓存的作用和类型。 o    主存储器（RAM）的工作原理。 10.    存储基本原理2 o    辅助存储的概念，包括硬盘和固态硬盘。 o    存储技术的发展历程和趋势。 o    缓存的工作原理和缓存优化策略。 11.    程序底层优化上机 o    实际操作底层性能优化。 12.    操作系统I/O原理 o    I/O系统的组成和功能。 o    I/O设备的管理和驱动程序。 o    缓冲技术、中断和直接内存访问（DMA）。 13.    计算机网络原理1 o    计算机网络的定义和重要性。 o    网络的分类和网络拓扑结构。 o    网络通信协议的基础，包括TCP/IP模型。 14.    计算机网络原理2 o    OSI模型的七层结构和功能。 o    网络设备和网络安全的基本概念。 o    网络编程的基础，包括套接字的使用。 15.    网络通信上机 o    实际操作底层并发网络通信程序。 16.    并发编程与大数据处理 o    并发编程的基本概念和多线程编程。 o    同步机制，包括互斥锁、信号量和条件变量。 o    并行计算框架和大数据处理技术，如MapReduce。
