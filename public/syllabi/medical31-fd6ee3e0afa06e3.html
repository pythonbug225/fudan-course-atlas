1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 本课程讲授食物‑宿主免疫互作、食物过敏、营养免疫调节、食源性危害等内容，培养学生从免疫视角分析食品相关健康问题的能力，为食品安全防控、营养干预和食源性疾病预防打下理论基础。

课程简介（英文） Course Description ( in English ) | This course covers food‑host immune interactions, food allergies, nutritional immunomodulation, and food‑borne hazards. It aims to equip students with the ability to analyze food‑related health issues from an immunological perspective, laying a theoretical foundation for food safety prevention and control, nutritional intervention, and the prevention of food‑borne diseases.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

通过食品免疫学的学习，使学生掌握食品中各种成分对机体免疫系统的影响，能够利用食品中天然存在或人工加入的有益成分来增强机体免疫力，了解食品中的有害成分对机体免疫系统的损伤作用，培养学生对食品免疫学的科研兴趣和科研思维。
