1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 本课程是针对药学专业二年级学生开设的专业必修课，内容涵盖以解剖学、组织学、生理学、病理生理学为基础的整合基础医学课程。具体主要涉及对运动系统、消化系统、呼吸系统、泌尿生殖系统、循环系统、神经和内分泌系统等的形态与功能的教学。

课程简介（英文） Course Description ( in English ) | This course is a required professional course for second-year students majoring in pharmacy. It covers an integrated basic medical curriculum based on anatomy, histology, physiology, and pathophysiology. Specifically, it mainly involves the teaching of the morphology and function of the musculoskeletal system, digestive system, respiratory system, urinary and reproductive systems, circulatory system, nervous system, and endocrine system.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

本课程是针对四年制药学专业的二年级学生开设的专业必修课，选课学生数预计在110-120人左右。基于药学院对药学专业人才的培养要求，学生需要从形态结构到基本生理功能再到病理生理学机制，按照知识的循序渐进和整合思维，对医学基础知识有较系统和全面的理解与掌握。在此基础上，注重对学生分析和解决实际问题的能力的培养，有助于学生理解临床常见病的发病机制和用药原理,为临床用药指导打牢坚实的理论根基。

3 . 教学方式 /Teaching Methods （应体现实现教学目标所采用的具体策略、方法和组织形式）

以课堂讲授为主，并向学生提供超星平台的线上资料辅助其进行预习和复习。 解剖的理论教学在解剖实验室上课，学生可以通过标本更直观地掌握解剖知识。 将考勤、小练习等作为过程考核的一部分。
