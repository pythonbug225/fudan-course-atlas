FPGA结构原理和应用(H)

来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

本课程分为三个主要部分： FPGA硬件架构：用于硬件可编程的各种存储单元结构、FPGA逻辑块、可编程互连资源、可编程IO和嵌入式IP核结构，如DSP（数字信号处理），PLL/DLL等时钟管理单元结构、微处理器和块存储器等。 2. 基于FPGA的硬件原型设计编译流程：硬件描述语言的词法语法分析、逻辑优化、工艺映射、装箱、布局、布线、时序分析、位流生成、编程下载等模块。侧重于理解时序分析的基本原理和时序优化技术。 3. 嵌入式系统设计和使用系统级FPGA的软件/硬件协同设计技术。 扩展研究：基于复旦大学自主设计的FDE教学板和配套开源软件的软硬件协同设计或者基于商用FPGA的DNN架构比较和DNN的加速和相关的FPGA EDA算法。

课程简介（英文）

There are three main parts in this course: 1．Architectures of FPGA logic block, configurable routing resource, programmable IOs and embedded IP (Intellectual Property) cores such as DSP (Digital Signal Process) block, memory block, PLL (Phase Locked Loop), microprocessor, AI engine and NoC (Network on Chip) etc. 2． Hardware prototype design compilation flow based on FPGAs, which includes HDL (hardware description language) parser, logic optimization, mapping, packing, placement and routing, STA (Static Timing Analysis) and programming etc. Lab session 1 is based on FDE board and the FDE+Rabbit tool chain, developed by Fudan University. 3． Nios-based embedded system design and software/hardware co-design techniques with system-level FPGAs based on Altera QSYS tool chain. Lab session 2 is based on DE2-115 or DE1-SoC board and Quartus tool chain, developed by Intel/Altera 4. For the extended honor part, there are hardware/software co-design methedology based on Fudan University's self-developed FDE educational board and its accompanying open-source software, or comparative study of DNN architectures on commercial FPGAs, along with DNN acceleration and related FPGA EDA algorithms.

教学目标

理解现代FPGA硬件架构的原理，包括硬件可编程技术、可编程逻辑单元、互连单元和输入输出单元结构，以及各种IP核结构，包括DSP模块、存储器模块、嵌入式处理器、PLL/DLL等时钟管理单元结构。FPGA编译EDA（电子设计自动化）工具流程和系统级应用。学生需要理解FPGA编译流程的各个步骤，包括逻辑优化、工艺映射、装箱、布局、布线、时序分析、位流下载和编程下载等。学生将学习和实践软件/硬件协同设计技术，以及基于FPGA的嵌入式系统设计和调试流程，包括嵌入式系统硬件结构、硬件抽象层和层次化软件结构等。 对于扩展学习内容，学生需要了解深度学习神经网络（DNN）的复杂性，理解空间计算和时间计算模式的优缺点，并编写有关CPU，GPU，FPGA和其他加速器之间架构比较的论文阅读和调研报告，也可包括相关的FPGA EDA算法及其代码阅读等报告。

教学方式

本课程以讲课为主，包括2次的实验和全英语实验报告与演示。 扩展学习内容主要包括研究论文的阅读与分组讨论，报告撰写，和DNN实验演示与报告。对于软件能力较强的同学，可以选择基于MAC/Linux/Windows跨操作系统平台和复旦大学自主设计的FDE教学板和配套开源软件的软硬件协同设计和FPGA EDA代码阅读等内容。
