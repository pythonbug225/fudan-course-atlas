1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 本课程基本内容包括常用药物中文名称、人体解剖结构的中文名称、八大系统相关器官的中文名称，常见病的中文名称、一些常见病主要症状及其体征的汉语表达、日常会话交流、中文语法、日常词汇用法等。

课程简介（英文） Course Description ( in English ) | This course covers the following core contents: Chinese names of commonly used drugs, Chinese terms for human anatomical structures, organs related to the eight major physiological systems, Chinese names of common diseases, Chinese expressions for the main symptoms and signs of common diseases, daily conversational communication, Chinese grammar, and the usage of daily vocabulary.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

《医学汉语II》是为MBBS学生将来进入临床见习、实习所开设的必修课。本课程为医学专业汉语、汉语日常用语技能课，主要目的是为MBBS学生进入中国医院见习、实习打下汉语基础，帮助他们用汉语跟医护人员、病人及家属进行基本交流。
