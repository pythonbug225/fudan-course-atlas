1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 本课程是面向放射医学、特种医学、放射肿瘤学、医学影像技术等相关专业研究生开设的核心专业课程，兼具理论深度与医用场景实操属性，是衔接辐射基础理论与临床放射安全管理的核心桥梁课程。

课程简介（英文） Course Description ( in English ) | This course is a core professional module designed for graduate students in fields such as radiation medicine, specialized medicine, radiation oncology, and medical radiation imaging technology. Combining theoretical depth with practical application in clinical settings, it serves as a pivotal bridging course that connects fundamental radiation science with clinical radiation safety management.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

围绕理论能力、实操能力、职业素养三个维度设定，同时对接医用辐射防护行业的实际岗位需求。培养学生独立分析、解决临床放射安全实际问题的能力，能结合前沿研究成果优化现有医用辐射防护流程。建立完整的放射防护安全文化素养，在后续科研与职业工作中严格遵循辐射安全相关规范要求。对接国家放射工作人员岗位培训的能力要求，完成研究生阶段的专业能力储备。

3 . 教学方式 /Teaching Methods （应体现实现教学目标所采用的具体策略、方法和组织形式）

采用“理论精讲+实操落地+案例驱动+前沿拓展”的混合式教学方式，同时贴合医用辐射防护行业的实际岗位能力需求。融入课程思政元素，结合我国辐射防护领域的发展历程、国际热点事件，强化学生的专业认同感与安全责任意识。

4.教学内容及进度安排 /Course Content & Schedule （ 按照教学周编排，应包含每节课教学内容及教学目标，如有作业及考核要求，请一并列明）

第1周：课程导论 电离辐射的发现与应用 电离辐射事故及潜在危害 电离辐射的量-效关系 第2周：核辐射物理学基础 天然与人工核辐射产生机理 核辐射与物质相互作用 放射性衰变与辐射屏蔽 第3周：放射生物学基础 核辐射生物效应机理 辐射人体效应分类与风险 电离辐射风险评估方法 第4周：核辐射防护基础 核辐射防护体系 内外照射防护基本方法与措施 核辐射防护法规与基本标准 第5周：辐射剂量学基础 电离辐射场与辐射量 放射诊断与治疗剂量学 第一次课堂讨论 第6周：核辐射测量方法 常见核辐射原理与探测器 核辐射测量方法 实验室参观与见习 第7周：内外照射剂量估算方法 外照射剂量估算方法 内照射剂量估算方法 内外照射剂量估算事例 第8周：电离辐射医学应用中的辐射防护 职业人员防护 患者与受检者防护 公众防护与环境保护 第9周：蒙特卡罗方法在剂量估算中的应用 人体数字化模型构建 粒子输运蒙特卡罗模拟 模拟计算事例 第10周：AI在辐射剂量学研究中的应用 基于AI的图像配准与自动勾画 基于AI的辐射剂量学预测 第二次课堂讨论 第11周：医学辐射防护与剂量学研究进展 放射诊断领域的研究进展 放射治疗领域的研究进展 核医学领域的研究进展 第12周：期末考试
