机器学习与金融建模

2025秋 · MF60010.01 · 王晓虎

来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

本课程是为金融专硕开设的一门选修课程。主旨是介绍一些基本的机器学习的方法以及其在数据挖掘，变量选择，模型建立，预测等方面的应用。重点关注金融资产的数据与模型，以及机器学习方法在其中的应用。本课程将以金融市场文本数据的挖掘与使用，金融资产超额收益率的预测因子的构造和选择为例，介绍如下的内容 数据挖掘与机器学习方法 变量选择与机器学习方法 模型建立与机器学习方法

课程简介（英文）

This course is an elective course for finance masters. The main purpose is to introduce some basic machine learning methods and their applications in data mining, variable selection, model building, and forecasting.

教学目标

本课程将以金融市场文本数据的挖掘与使用，金融资产超额收益率的预测因子的构造和选择为例，介绍如下的内容 数据挖掘与机器学习方法 变量选择与机器学习方法 模型建立与机器学习方法 教学目标为：通过本门课程的学习，学生将掌握基本的机器学习的方法的思想、涉及与应用步骤。应可以灵活的将基本的机器学习方法用于现实的数据和问题，以完成数据挖掘，变量选择，模型建立，预测等方面的工作。
