数值代数及其应用

2025秋 · MATH50042.01 · 苏仰锋

来源：复旦教务系统教学大纲；正文整理。

课程简介（中文）

数值代数，亦称矩阵计算，是所有科学计算的核心。本课程将讲授数值代数的基本内容，舍入误差的基本概念及初等分析方法，数值代数中四大基本问题，即线性方程组、最小二乘问题、线性特征值问题、奇异值分解的直接法，最后简单介绍求解这些问题的大规模情形下的迭代法。本课程注重实际使用算法时可能遇到的问题以及如何选择最合适的算法，也就是数值代数的应用。

课程简介（英文）

Numerical Linear Algebra，or Matrix Computation, is the core task of all scientific computation. This course covers round error and basic analysis methods, direct methods for four foundmental problems, i.e. linear systems of equations, least square problems, linear eigenvalue problems, singular value decompositions, and finally, simple introduction to iterative methods for the large scale versions of these four problems. The course will emphasize the application of numerical methods, which means how to the best algorithm for a given problem.

教学目标

1、 期望学生能掌握矩阵计算的基本内容与方法； 2、 对于一个给定的矩阵计算问题，学生能根据问题的性质、结构选择合适的算法； 2、 由于这是研究生第一学期的计算课程， 期望学生能够在科学写作、科学计算编程、科学研究的基本方法等方面有所提高。

教学方式

每周教师在教室讲授课程内容； 本课程共分5章，每章结束后由学生自己组织习题课对每道习题进行讲解。

教学内容与进度安排

本课程共分5章 第一章 舍入误差 第二章 线性方程组 第三章 最小二乘问题 第四章 线性特征值问题 第五章 对称特征值问题与奇异值分解 计划每周用2-3周的时间。

教学参考资料

1、 J. Demmel. Applied Numerical Linear Algebra, SIAM, 1997.
