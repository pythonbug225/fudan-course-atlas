课程简介（中文）

《数字信号处理的VLSI设计》课程主要是介绍数字信号处理器设计过程中涉及到的基本理论，如精度分析，噪声分析等；基础结构设计，包括流水线架构、并行串行架构，脉动处理结构等；以及高性能、低功耗处理器设计方法学等知识，并对学生进行完整的芯片设计流程训练。

课程简介（英文）

A. High-Level Architecture Transformations: Characteristics and representations of signal processing programs: signal flow graphs, data-flow graphs and dependence graphs, iteration bound, pipelining and parallel processing for high-speed and low-power, high-level transformations such as retiming, unfolding, folding, systolic array design, Algorithmic strength reduction in parallel filters and transforms. B. Implementation Styles: Arithmetic processors for signal processing using bit-level and multi-bit level pipelining, Bit-parallel, bit-serial, and digit-serial structures for addition and multiplication. Use of canonic signed digit, carry-save, distributed arithmetic (Chapter 13), redundant number based arithmetic architectures. Applications of various number systems in implementation of Viterbi decoders, Finite field arithmetic and implementations of Error Control Coders such as Reed-Solomon codes (Papers handed out), Numerical strength reduction. C. Synthesis, Low Power Design and Programmable DSPs: Overview of scheduling and allocation, overview of low-power design, power reduction techniques, overview of programmable DSPs.

教学目标

This course brings together the distinct fields of computer architecture and digital signal processing. Familiarity with a programming language such as MATLAB or C is assumed. Digital signal processing is an enabling technology for many applications such as video, speech, communications and multimedia. The focus of this class will be on the design methodologies and tools for design of dedicated VLSI systems for signal and image processing applications. The design methodologies will be used for exploring area-power-speed tradeoffs for different DSP applications. Minimization of area is another constraint in implementations using VLSI chips. Power consumption reduction is crucial in design of modern systems for portable as well as non-portable applications. The purpose of this class is to learn design methodologies to design a family of architectures for a given algorithm and select appropriate architectures based on area-speed-power constraints of the specified application. The goal of this class is to understand architecture design tradeoffs so that better RTL code can be generated leading to better digital signal processing chips. While RTL coding and chip design are beyond the scope of this class, the logic and arithmetic transformations enable an ASIC designer to write better RTL code and to generate more efficient digital chips.
