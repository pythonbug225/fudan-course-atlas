1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 《诊断学C》总课程为4个月，共32个学时，基本内容包括：呼吸、循环、消化、神经系统疾病症状，全身体格检查，基本实验室检查（血液一般检查、贫血检查、肾功能、尿常规和尿液其他检查、肝脏病常用实验室检查）、心电图。作为学生基础课程与临床学习阶段的桥梁有着举足轻重的作用，知识点的传输，临床实践的运用显得尤为重要突出。难点也就在如何更好的让学生接受患者，感受临床；可以通过多媒体教学、模拟患者、情景教学让学生加深印象。

课程简介（英文） Course Description ( in English ) | Diagnostics C This course lasts 4 months with a total of 32 class hours. It mainly covers: symptoms of respiratory, circulatory, digestive and neurological diseases; complete physical examination; basic laboratory tests (including routine blood tests, anemia-related tests, renal function tests, routine urinalysis and other urine tests, common laboratory tests for liver diseases); and electrocardiography. As a crucial bridge between basic medical courses and clinical learning, this course plays a pivotal role. The transmission of knowledge and the application of clinical practice are particularly important. The key challenge is how to better help students accept patients and experience clinical scenarios. Impressions can be deepened through multimedia teaching, simulated patients and situational teaching.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

通过《诊断学C》的学习，让公共卫生管理的学生对疾病的症状和体征、临床的体格检查、基本实验室检查和心电图、肺功能有一个基本的熟悉，通过课堂及课外教学，使学生能熟悉体格检查手法，了解常用的辅助检查的临床意义。 掌握呼吸、循环、消化、神经系统疾病症状， 熟悉全身体格检查步骤。 了解基本实验室检查（血液一般检查、贫血检查、肾功能、尿常规和尿液其他检查、肝脏病常用实验室检查）、 熟悉心电图、肺功能。
