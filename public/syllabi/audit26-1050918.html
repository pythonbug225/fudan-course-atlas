课程简介（中文）

本课程将教授使用统计软件（SAS）进行数据分析方法的基础知识。学员不需要具备任何SAS编程经验。本课程面向真正的初学者。数据分析方法和SAS软件编程将同时进行教学。课程将讲授横断面队列数据中的简单方法，涵盖参数检验（t检验、方差分析、协方差分析）到非参数检验（Wilcoxon检验、Kruskal-Wallis检验）以及回归分析（线性回归和逻辑回归）。每种方法背后的统计理论将进行基本解释。课程将安排作业和考试，以确保学生深入学习教材内容，并能将其应用于示例数据集。

课程简介（英文）

This course will provide the basics in data analysis methods using statistical software (SAS).Students are not expected to have any SAS programming experience. This course is for true beginners.

Methods in data analysis and SAS software programming will be taught simultaneously. Simple methods in cross-sectional cohort data will be taught, ranging from Parametric tests (t-test, ANOVA, ANCOVA) to Non-Parametric tests (Wilcoxon, Kruskal-Wallis) and regression analyses (linear and logistic). Basic explanations of the statistical theory behind each method used will be done. Homework and an examination will be held to ensure students’ in-depth learning of the material and its application to sample datasets.

教学目标

  1. To learn basic SAS programming
  2. Able to perform different Parametric tests (t-test, ANOVA, ANCOVA)
  3. Able to perform Non-Parametric Tests (Wilcoxon, Kruskal-Wallis)
  4. Learn how and when to perform Regression analyses (linear and logistic)
  5. Learn about the assumptions made when performing each test (eg. Normality of data, etc)
  6. Be able to independently think of a research question and analyze data sets

教学方式

This course adopts a hands-on, computer-based approach to simultaneously build SAS programming skills and foundational statistical knowledge. Each weekly session combines brief theoretical lectures with extensive in-class practical exercises, during which students follow step-by-step coding demonstrations on their own laptops. To facilitate this, students are required to pre-install SAS on their personal devices and bring them to every class. The instructor emphasizes not only the execution of statistical procedures but also the underlying assumptions and interpretive logic—such as normality, variance homogeneity, and model fit—ensuring students understand why and when to apply each test. Through guided lab sessions, real-world sample datasets, and progressively challenging homework assignments, students actively apply parametric and non-parametric tests as well as regression techniques. The course culminates in a final examination that assesses both conceptual understanding and practical coding competency, reinforcing the integration of statistical reasoning and reproducible data analysis.
