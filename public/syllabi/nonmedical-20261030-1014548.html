课程简介（中文）

掌握数据分析与算法设计是熟练运用计算机系统开展研究工作的前提。随着Python日益广泛的应用，Python具有与传统的面向对象编程语言相似的数据结构与算法。本课程讲授在Python环境下如何进行数据分析，如何通过一系列存储机制高效地实现各类算法。课程内容包括Python语言基础、内建数据结构、函数及文件、Numpy基础、数据载入、存储及文件格式、数据清洗与准备、数据规整、绘图与可视化、数据聚合与分组操作、时间序列、Pandas数据结构、Python建模库、Hadoop 或mapReduce分布式大数据处理系统和系列经典算法设计等内容。

课程简介（英文）

Data analysis and algorithm design is a fundamental for proficiently using computer systems to conduct research work. With the increasingly widespread application of Python, it has data structures and algorithms similar to traditional object-oriented programming languages. This course teaches how to perform data analysis in the Python environment and how to efficiently implement various algorithms through a series of storage mechanisms. The course content includes Python language basics, built-in data structures, functions and files, Numpy basics, data loading, storage and file formats, data cleaning and preparation, data organization, plotting and visualization, data aggregation and grouping operations, time series, Pandas data structures, Python modeling libraries, Hadoop or mapReduce distributed big data processing systems, and a series of classic algorithm designs.

教学目标

该课程主要面向未来信息创新学院一年级电子信息专业硕士生。通过本课程学习，使学生深刻理解和熟练掌握数据分析与算法设计方法，在Python环境下用经典的算法、编码技术和原理来求解计算机科学的一些经典问题，为进一步的专业学习和研究奠定基础。
