1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 本课程是专为临床医学八年制专业学生的系统整合式教学体系设置的先修课程，内容包含有基础医学阶段主要学科的基本概念、总论/一般性规律知识，为后期的系统整合式教学做铺垫。

课程简介（英文） Course Description ( in English ) | This course is a prerequisite specifically designed for the systematic integrated teaching system of eight-year clinical medicine students. It covers the basic concepts and general knowledge of the main disciplines in the basic medical stage, laying a foundation for the systematic integrated teaching in the later stage.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

本课程是专为临床医学八年制专业学生的系统整合式教学体系设置的先修课程，内容包含有基础医学阶段主要学科的基本概念、总论/一般性规律知识，为后期的系统整合式教学做铺垫。本课程主要包括了生理学、病理学、病理生理学、药理学的基本的一般规律性知识，是后面系统整合式课程的先导课程。总共33节理论课和14节实验课。
