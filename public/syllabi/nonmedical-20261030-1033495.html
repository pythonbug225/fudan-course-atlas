课程简介（中文）

本课程从文本检索与挖掘的角度，比较全面和系统地介绍了利用文本数据支持助理型智能系统的各种算法和技术。文本检索算法与技术可用于构造各种搜索和推荐系统，这类系统可帮助用户快速定位到与当前任务最相关的文本数据。而文本分析与挖掘算法与技术则可进一步对相关文本数据进行分析，帮助用户消化相关文本信息，将文本转化为可直接支持任务和决策的知识。

课程简介（英文）

This course approaches the topic from the perspective of text retrieval and mining, and provides a comprehensive and systematic introduction to various algorithms and techniques that use textual data to support assistive intelligent systems. Text retrieval algorithms and techniques can be used to build a wide range of search and recommendation systems, which help users quickly locate textual data that are most relevant to the current task. Text analysis and mining algorithms and techniques further analyze relevant textual data, helping users digest information and transform text into knowledge that can directly support tasks and decision-making.

教学目标

本课程通过系统讲述文本检索与挖掘的各个方面，如搜索引擎架构、检索模型、文本聚类、文本分类、信息抽取和知识挖掘的常用算法与理论，并结合其在 Web 文本挖掘、生物医学文本挖掘等领域的应用，引导学生理解和掌握这些基本方法。同时，通过阅读、讨论和课程项目等形式，尝试运用文本检索与挖掘的算法与技术解决实际问题。

教学方式

实施理论讲解与实践相结合的教学策略，以课堂教学为先导，通过项目实践深化学生对教学内容的理解。
