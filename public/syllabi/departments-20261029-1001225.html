课程简介（中文）

运筹学注重将数据转化为决策依据以优化决策效果的科学过程。该学科与管理科学紧密相连、具备解决实际问题的系统化框架，是涵盖从问题构建、分析、建模、求解到实施全过程的严谨科学方法，对培养和提升管理人才素质具有重要作用。课程内容涵盖线性规划、整数规划、动态规划、网络规划、决策理论、排队论、非线性规划等数学规划理论与算法。

课程简介（英文）

Operations research is defined as the scientific process of transforming data into insights to making better decisions. It is a science that studies how to effectively organize and manage human-machine systems. It plays an important role in cultivating and improving the quality of management personnel because of its close connection with management science, systematic framework for solving practical problems, and a set of rigorous scientific methods from problem formulation, analysis, modeling, solution, to implemetation. The course content includes linear programming, integer programming, dynamic programming, network programming, decision theory, queuing theory, nonlinear programming, and other mathematical programming theories and algorithms.

教学目标

Understand basic principles and methods of Operations Research; Master the basic modeling approaches of Operations Research, learn to model and solve some basic practical management problems; Master the use of basic optimization solves (such as Python+Gurobi).

教学方式

The main teaching method is lecturing. There will also be several hand-on session that requires programming using Python.
