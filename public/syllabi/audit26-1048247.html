课程简介（中文）

SAS系统是用于数据分析与决策支持的大型集成式模块化软件包，是进行数据分析的有力工具，为国际标准统计软件之一。本课程将介绍SAS软件及其的编程方法，SAS中的基本数据整理，常用统计分析方法的SAS实现，包括各种单因素分析方法，相关回归分析，生存分析，多元线性回归，多元logistics回归和COX回归等。

课程简介（英文）

The SAS system is a large-scale, integrated, and modular software package designed for data analysis and decision support. It serves as a powerful tool for data processing and is recognized as one of the international standard statistical software. This course will introduce the SAS software and its programming technique, covering fundamental data management in SAS, as well as the programming of commonly used statistical analysis methods. These include various univariate analysis techniques, correlation and regression analysis, survival analysis, multiple linear regression, multiple logistic regression, and COX regression, among others.

教学目标

通过本课程的学习，学生能熟练运行使用SAS软件编程,掌握数据整理的主要命令和语句，以及常用的各种统计方法的SAS基本语句。能够根据分析需要进行数据整理，选择合适的统计模型和统计分析方法进行单因素和多因素分析；并能够正确理解、解释SAS输出结果，回答医学研究问题。
