课程简介（中文）

《计算机》是一门专为医学院学生开设的计算机基础课程，旨在帮助医学生系统掌握计算机核心知识和应用技能。课程内容涵盖计算机基础及其广泛应用、硬件原理、常用软件、操作系统、网络通信、计算机编程基础以及图像处理等，为医学生未来的学习和职业发展奠定坚实的数字化基础。

课程简介（英文）

Computers:Tools for an Information Age is a foundational course tailored for students in medical schools. Its primary objective is to enable medical students to systematically master essential computer knowledge and practical application skills. Course content encompasses fundamental computer concepts and their diverse applications, hardware principles, common software applications, operating systems, network communications, introductory computer programming, and image processing. This comprehensive course establishes a robust digital groundwork crucial for medical students' forthcoming academic pursuits and professional growth.

教学目标

Course Objectives:

1) understanding of computer hardware, software, OS and networking;
2) understanding of basic programming concepts using python language;
3) understanding of digital image processing.

教学方式

Lecturing and programming practice.

教学内容与进度安排

1) Introduction to computer application in medicine and digital basics.

Computer Application in Medicine; Computer Technology Trend; Computer Architecture; represent of data in computer including numerical data， ascii, char, fonts and image data represent.

COIP: Using Application in countrywide deployment to guide students’ deep understanding of china and eliminate bias.

2) hardware concept: CPU, memory, disk

    Von Neumann RM, CPU and main memory; Storage program; RISC and CISC; example of Instruction set; Instruction execution; bit,byte and array; meomory type; latency graph.

3,4) Software basics, operating system and file management.

Software basic; operating system: definition, functionality and types; process: concept, scheduling and life cycle; File System.

5,6) LAN, WLAN and Internet.

Network device; Computer networking; Internet: ip address, layered model; tcp/ip procotcol suite; dns; www.

COIP: using rapid development in internet to guide students’ understanding of china and eliminate bias.

5) python programming environment

Algorithm basics; python environment; simple use of python;

7) basics for python

Python basics; types: bool, int, float, string; expressions; and examples. Simple statement; variables.

8) condition, loop and function (1)

vscode use; conditions; branches; for loop; while loop.

9) condition, loop and function (2)

For loop and while loo; function definitions; function calling; function design; var scope: local and global variables.

10, 11) function and strings

Function demos; string types; string operations; string usage.

12) list, tuple

List manipulation; list usage; tuple represent; tuple usage.

13) set and dictionary

Set representation; set usage; dictionary represent; dictionary usage.

14) file management & debug program

15) digital media and image processing in medicine.

16) exam of course.
