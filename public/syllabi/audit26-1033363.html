课程简介（中文）

本课程旨在利用统计分析软件（SAS）讲授数据分析方法的基础知识，这是开展流行病学研究的基本要求。课程面向没有任何SAS编程经验的“真正”的初学者，将同步教授数据分析方法与SAS软件编程。

课程内容将涵盖横断面队列数据的简单分析方法，范围从参数检验（t检验、方差分析、协方差分析）到非参数检验（Wilcoxon检验、Kruskal-Wallis检验），以及回归分析（线性回归与logistic回归）。课程会对所用统计方法背后的理论进行基础性讲解。为确保学生对课程内容及其在样本数据集上的应用有深入理解，课程将布置作业并进行考试。

课程简介（英文）

This course will provide the basics in data analysis methods using statistical software (SAS), which is a fundamental requirement for research in Epidemiology. 

Students are not expected to have any SAS programming experience. This course is for true beginners.

Methods in data analysis and SAS software programming will be taught simultaneously. Simple methods in cross-sectional cohort data will be taught, ranging from Parametric tests (t-test, ANOVA, ANCOVA) to Non-Parametric tests (Wilcoxon, Kruskal-Wallis) and regression analyses (linear and logistic). Basic explanations of the statistical theory behind each method used will be done. Homework and an examination will be held to ensure students’ in-depth learning of the material and its application to sample datasets.

教学目标

1. 掌握基础 SAS 编程：学习 SAS 编程的基础知识。

2. 熟练运用参数检验：能够执行不同的参数检验，如 t 检验、方差分析（ANOVA）及协方差分析（ANCOVA）。

3. 熟练运用非参数检验：能够执行非参数检验，如 Wilcoxon 检验及 Kruskal-Wallis 检验。

4. 掌握回归分析方法：学习如何以及何时进行回归分析，包括线性回归与逻辑回归。

5. 理解统计假设：了解在执行每种检验时所需满足的前提假设（例如数据正态性等）。

6. 培养独立分析能力：能够独立提出研究问题并对数据集进行分析。

教学方式

本课程采取线下实践式教学，在讲授理论知识的同时由任课老师带领学生同步实践，及时提出问题并进行反馈，每节课后布置作业进行巩固。采取过程化评价体系结合期末考试进行综合评价
