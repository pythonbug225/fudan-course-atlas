课程简介（中文）

本课程聚焦于培养学生利用数据结构与算法解决复杂计算问题的实战能力。通过 Python 语言的深度实践，学生将掌握如何将抽象逻辑转化为高效的系统实现，学习利用大O分析、递归、线性及非线性结构进行科学决策，构建从问题建模到性能优化的完整思维链路，真正实现利用编程作为工具来解决问题。

课程简介（英文）

This course focuses on empowering students to solve complex computational problems using Data Structures and Algorithms. Through hands-on Python practice, students will learn to transform abstract logic into efficient systems. By mastering Big O analysis, recursion, and advanced data structures, learners will build a robust mindset for problem modeling and performance optimization, understanding how to solve questions with data structures and algorithms.

教学目标

本课程致力于培养学生利用数据结构与算法解决实际计算问题的基本功。教学过程以 Python 语言为工具，重点传授大O表示法、线性表、树、图等核心知识，通过大量的代码实现，将抽象的逻辑具象化。课程的目标是让学生能够根据问题的规模和特征，选择最合适的存储结构并设计出高效的执行步骤，从而提升程序的运行效率。同时，结合应用型人才的培养要求，课程强调严谨的逻辑思维和规范的工程编码习惯，引导学生在实践中积累解决复杂问题的经验，为后续从事专业技术开发打下扎实的理论与实践基础。

教学方式

本课程采取理论教学与解题实践并重的教学模式。在课堂教学中，通过实际编程案例引出抽象概念，重点讲解数据逻辑结构与 Python 代码实现的对应关系。在课后练习环节，作业主要依托力扣在线评测平台开展。学生通过在平台上解决实际算法题，实时检验代码的正确性与执行效率。这种“边学边练”的方式，旨在让学生在不断纠错与优化的过程中，磨炼复杂度的分析能力，养成规范且高效的编码习惯。

教学内容与进度安排

第一周 绪论 课程介绍、数据结构的概念、数据结构的抽象形式、Python中的ADT类、算法的定义、算法性能分析与度量 第二周 基本数据结构 线性数据结构、栈、队列、双端队列、链表 第三周 递归思维与函数调用栈 递归的概念、递归三原则、分型可视化、递归相关案例分析 第四周 复杂递归与动态规划 汉诺塔问题、找零问题、记忆化搜索、贪心算法、动态规划 第五周 高效搜索与散列技术 二分搜索、哈希函数、冲突解决（线性探测与链接法） 第六周 基础排序算法与稳定性 选择排序、冒泡排序、插入排序、希尔排序、增量序列 第七周 分支策略与高级排序 归并排序、快速排序、主定理复杂度推导 第八周 树形结构与解析 树的定义与ADT、节点引用实现、前/中/后序遍历、解析树求值 第九周 优先队列与二叉堆 完全二叉树的数组映射、上浮/下沉操作、建堆复杂度 第十周 二叉搜索树与平衡树 BST的增删改查、AVL树的左旋/右旋机制 第十一周 图模型与拓扑遍历 邻接矩阵、邻接表、广度优先、深度优先 第十二周 图的高级应用 拓扑排序、有向无环图、强连通单元 第十三周 最短路径与最小生成树 Dijkstra算法、Prim算法的实现与堆优化 第十四周 算法扩展一 Python列表的CPython实现原理、欧几里得算法、RSA加密 第十五周 算法扩展二 跳表、八叉树图像量化、DFA与KMP字符串匹配 第十六周 总结与复习 课程知识体系串讲
