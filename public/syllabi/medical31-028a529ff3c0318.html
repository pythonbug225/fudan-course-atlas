1. 课程简介 /Course Description

课程简介（中文） Course Description ( in Chinese ) | 基础护理学是护理专业的基础课程，具有丰富的科学内涵和实践特点。在基础护理学的课程中，护生将学习从事护理工作所必需的护理基本理论、基本知识和基本技能。本学期的主要学习内容包括：饮食与营养、排泄、给药、静脉输液与输血、标本采集、病情观察及危重病人的管理、临终护理。

课程简介（英文） Course Description ( in English ) | This is a foundational course for nursing majors, featuring rich scientific connotations and practical characteristics. In this course, nursing students will learn the essential basic theories, fundamental knowledge and core skills required for nursing practice. The main content to be covered in this semester includes: diet and nutrition, elimination, medication administration, intravenous infusion and blood transfusion, specimen collection, patient condition observation, critical care management, and end-of-life care.

2. 教学目标 /Course Objectives （结合本校办学定位、学生情况、专业人才培养要求，应体现价值引领、知识传授、能力培养等方面的内容。）

知识目标 —掌握临床护理工作中最常用的基本理论、基本知识和基本技能。掌握常用护理操作以及健康教育内容和方法。 能力目标 —针对患者生理层面的健康问题，实施科学有效的护理措施；具备良好的人际沟通；发展独立思考、分析、解决护理问题的能力。 思政目标 —提升护理职业认同感和专业自信，开拓国际视野，培养人文关怀和奉献精神。

3 . 教学方式 /Teaching Methods （应体现实现教学目标所采用的具体策略、方法和组织形式）

授课方式主要有线上、线下讲授和技能演示，线下技能练习、综合情景模拟练习等。课程采用理论授课--技能学习—综合运用的方式进行。 1 、理论知识讲授 课堂讲授可帮助学生系统地学习课程体系和主要内容，各章节的基本理论和基本知识采用线上线下理论讲授。课堂教学中，结合教学内容，将护理学科的新进展和优秀护士的先进事迹纳入其中，鼓励学生刻苦学习，勇于探索，乐于奉献。 2 、单项技能演示和练习 本学期要求学生熟练掌握的技能是鼻饲法、留置导尿术、皮内注射、皮下注射、肌内注射、静脉注射、静脉输液、静脉采血法等。示教课讲采用线上教学的方式，方便学生反复观看，示教将基于案例进行操作演示，将沟通技能、人文关怀融入规范的技能操作之中。学生进行技能练习和考核同样是基于案例，在练习技能操作的同时练习和提高人文关怀能力。 3 、综合情景模拟练习 学生以小组为单位,每组3～4人，根据案例评估个案的护理需求，执行正确的临床技术，展示关怀的行为，运用治疗性人际关系与沟通技巧，与同伴和病人互动。表现出自信,参与决策和修正错误的能力。
