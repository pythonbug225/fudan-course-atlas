课程简介（中文）

Fortran语言是大气与海洋科学数值模拟的核心工具，其高效计算特性至关重要。本课程基于Fortran 90/95标准，培养学生处理气象格点数据、开发数值算法和优化模式性能的能力。学生将掌握多维数组运算、NetCDF数据处理及并行计算技术，为气候模式开发和海气相互作用研究奠定基础，提升学生解决大气海洋科学问题的计算能力。

课程简介（英文）

Fortran is a key tool for numerical simulations in atmospheric and oceanic sciences, known for its efficient computational capabilities. This course, based on Fortran 90/95 standards, focuses on developing students' skills in handling meteorological grid data, creating numerical algorithms, and optimizing model performance. Students will learn multidimensional array operations, NetCDF data processing, and parallel computing techniques, providing a solid foundation for climate model development and air-sea interaction research. This training enhances their computational abilities to tackle challenges in atmospheric and oceanic sciences.

教学目标

结合我校"服务国家战略、培养应用型创新人才"的办学定位，针对大气科学、物理海洋学等专业学生的数理基础特点，本课程旨在：1）价值引领：通过数值天气预报、气候模式等国家重大需求案例，培养学生"数值模拟服务社会"的使命感和科学严谨精神；2）知识体系：系统掌握Fortran 90/95核心语法，重点强化数组运算、模块化编程及NetCDF数据接口技术，夯实大气海洋数值模拟的编程基础；3）能力培养：通过WRF模式参数优化等实践项目，提升学生解决复杂地学问题的计算思维能力和并行程序开发技能，为参与国家超算中心科研项目储备技术能力。课程最终实现"用Fortran讲好地球系统科学故事"的教学价值。

教学方式

本课程采用"理论-实践-创新"三维融合的教学模式： 分层教学：针对学生数理基础差异，设置基础语法（循环/数组）、中级应用（模块化设计）、高阶专题（MPI并行化）三级教学模块，通过课前诊断测试动态分组； 案例驱动：以ECMWF数值预报模式代码片段为教学案例，开展"代码手术室"实景教学，引导学生解析WRF模式中的动力框架Fortran实现； 项目式学习：设计"台风路径集合预报""海浪模式参数敏感度分析"等小组项目，依托学校超算平台开展从算法设计到性能优化的全流程训练； 前沿创新：邀请一线编程工程师参与实验课教学，将业务系统中Fortran代码优化经验融入课堂。通过GitLab代码评审、HPC资源使用量竞赛等创新考核方式，强化工程实践能力培养。

教学内容与进度安排

教学内容安排 （具体到每节课内容，明确每节课要达到的教学目标）： 第一章：计算机概论（3学时） 1.1 计算机简史与操作系统 掌握：计算机发展史 1.2 计算机语言简介 掌握：了解当今计算机语言发展 本章重点：了解计算机语言发展 第二章：编译器的使用和Fortran程序设计基础（9学时） 2.1 编译器简介 了解：编译器类型 2.2 Linux下使用Fortran 掌握：Linux 命令行使用 2.3 字符集和书面格式 掌握：Fortran 基本表达 2.4 Fortran的数据类型和数学表达 掌握：Fortran编写简单数学公式 本章重点：Fortran的基本编写格式 本章难点：Fortran 编写基本数值方程 第三章：输入输出及声明（6学时） 3.1 输入和输出命令 掌握：两种命令的编写 3.2 声明、输入和格式化输入输出 掌握：这几种命令书写 3.3 混合运算 了解：复杂计算过程编写入门 3.4 Fortran 的自定义数据类型 了解：其它数据类型 重点：进一步完善Fortran 的格式书写 难点：对较复杂数值公式的对应编写 第四章：流程控制与逻辑运算（6学时） 4.1 IF\SELECT CASE语句 掌握：这两种语句的书写 4.2 浮点数及字符的逻辑运算 了解：进一步的算法法则 重点：逻辑运算的编写 难点：灵活运用逻辑运算解决数值问题 第五章：循环（6课时） 5.1 DO和DO WHILE循环 掌握：循环语句的基本格式 5.2 循环的流程和应用 掌握：熟练循环语句的使用 本章重点：循环语句的编写 本章难点：将上述过程熟练掌握编写较复杂的Fortran程序 期中考试 第六章：Fortran在大气数值模式研究中应用简介（3课时） 了解：Fortran语言在大气数值模式的应用 本章重点、难点：讲座形式，对Fortran加深了解 第七章：数组与函数（9课时） 7.1 数组基本使用 掌握：数组的内容设置和保存规则 7.2 数组的应用 掌握：数组的应用 7.3 子程序的使用 了解：子程序编写格式 7.4 函数的应用 了解：函数中的变量、类型 本章重点：了解数组函数的使用 本章难点：掌握子程序的写法 第八章：Fortran语言在大气化学传输模式中简介（3课时） 了解：Fortran 在CTMs中的应用 16周：程序设计练习 17 周：期末复习与答疑 说明：上面列出的是本课程的基本教学内容，任课教师将根据课时和需要进行调整。
