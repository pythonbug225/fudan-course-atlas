课程简介（中文）

本课程以 C 语言为程序的描述语言，介绍程序设计基本概念、结构化程序设计 方法、C 语言的基本知识；基本数据类型、运算符和表达式的书写规则，基本的数据输入输 出方法；控制结构、函数基础知识和正文文件的简单用法；数组、字符串、指针及其应用； 函数各类参数的设定和应用、函数指针的用法、递归函数的基本知识、作用域规则和编译预 处理命令简介；结构和动态数据结构基础及链表的应用；数据文件的基本处理技术。结合语 言基本设施介绍程序设计的基本原理、技巧和方法。

课程简介（英文）

This course uses the C language as the programming description language to introduce fundamental programming concepts, structured programming methods, and essential knowledge of the C language. It covers basic data types, the syntax rules for operators and expressions, and fundamental data input/output methods. The course also includes control structures, the basics of functions, and simple usage of text files; arrays, strings, pointers, and their applications; the definition and application of various function parameters, the use of function pointers, basic knowledge of recursive functions, scope rules, and an introduction to preprocessor directives. Additionally, it covers structures, the basics of dynamic data structures, and the application of linked lists, as well as fundamental techniques for processing data files. Alongside the language’s basic constructs, the course introduces essential programming principles, techniques, and methodologies.

教学目标

通过本课程的教学，了解程序设计的基本原理、技巧和方法。结合上机实践，让学生初具独立构造算法、开发程序及程序调试能力。 要求学生经本课程的学习后，能熟练使用结构化程序设计方法开发算法和编写程 序，具有一定的程序调试能力，并为以后进一步自习其它程序语言和提高程序设计能力打下 坚实的基础。

教学方式

以课堂讲解为主，并且通过课程作业和上机训练让学生巩固和运用课堂上所学的知识。

教学内容与进度安排

一、 程序设计基础 教学内容：程序设计的基本概念、C 语言基础知识、C 语言的编译和运行环境 教学要求：了解程序设计基本概念、Ｃ语言的基础知识；掌握Ｃ程序的上机过程。 二、 基本数据及其运算和输入输出 教学内容：基本数据类型、数据运算、数据输出和输入 教学要求：掌握Ｃ语言的基本类型的概念、使用方法；掌握各种数据运算的意义、了解运算符的优先 级和运算符的结合性；了解数种据输入输出方法，熟练使用常用的输入输出格式。 三、 结构化程序开发 教学内容：顺序结构、选择结构、循环结构 教学要求：掌握Ｃ语言各种语句的语义和使用方法；能编写简单的C程序。 四、 数组和字符串 教学内容：数组的基本概念、二维数组、字符数组和字符串 教学要求：掌握数组的基本概念，掌握数组的输入、输出、排序等处理的程序设计方法等技巧，能熟 练应用数组编写应用数组的小程序。 五、 函数的设计方法 教学内容：函数基础知识、递归函数的基础知识、作用域规则和编译预处理命令简 教学要求：掌握函数的基本概念；具有编写函数的基本能力、能正确为函数设定形参、能正确调用函 数；掌握递归函数的执行过程，能编写简单的递归函数。了解变量作用域规则，能正确阅读使用全局变量和局部变量的程序、能正确使用静态变量； 能熟练应用宏定义；了解文件包含在程序组装中的作用。 六、 指针及其应用 教学内容：指针基础知识、指针和数组 教学要求：了解地址和指针的基本概念，掌握指针定义和通过指针进行函数传参的过程。 七、 结构和动态数据结构基础 教学内容：结构数据类型的基本概念、结构类型的定义方法、动态数据结构——链表及其应用 教学要求：了解程序设计基本概念、Ｃ语言的基础知识；掌握Ｃ程序的上机过程。 八、 数据文件处理技术 教学内容：文件的基本概念、C 程序文件处理技术、常用文件处理库函数 教学要求：掌握文件的基本概念，能熟练编写使用文件的小程序。
