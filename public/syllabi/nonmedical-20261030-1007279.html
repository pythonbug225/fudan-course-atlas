回归分析

课程简介（中文）

近年来，随着科技和互联网的发展，越来越多的各类数据生成，这对数据的分析提出了更高的要求。回归分析是对数据进行分析的基本方法。本课程从最基础的简单线性回归模型讲起，覆盖多元线性回归、正则化回归、稀疏回归、主成分回归等线性回归模型及逻辑回归等广义线性回归模型。从理论和实践两方面介绍所讲方法的应用背景、范围等等。

课程简介（英文）

In recent years, with the advancement of technology and internet, an increasing amount of diverse data has been generated, placing higher demands on data analysis. Regression analysis is fundamental for analyzing data. This course begins with the most basic simple linear regression model and covers linear regression models such as multiple linear regression, regularized regression, sparse regression, and principal component regression, as well as generalized linear regression models like logistic regression. It introduces the application contexts and scopes of these methods from both theoretical and practical perspectives.

教学目标

通过对本课程的学习，掌握数据分析中常用的回归分析方法，加深对方法的理解，丰富同学们的统计知识，能针对具体问题正确地应用所掌握的方法进行数据分析，并合理地解释所得结果。在引领学生学习基础理论的基础上，学会应用所学知识对具体数据进行分析。
